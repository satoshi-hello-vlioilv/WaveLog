今回そろえたUI/UXの直し（5案共通）

  1. 「このあと: ○○・○○・○○」の列挙をやめ、10段階を10個の目盛りにした。 済み／いま／これから が数えずに読める（§CLAUDE 2・8。文字は「完了 4/10」だけ）。
  2. 更新中は「あとどれくらいか」を書く——「ふだんより長くかかります（目安30〜60秒）」。 待たされる理由と見込みを出す（§CLAUDE 6。推測させない）。
  3. 更新の中身はラベル列を固定幅の2列にした（変わった点／いまの作業）。幅はいちばん長いラベルから決める—— 値の左端がそろう（§CLAUDE 9）。
  4. 状態の札（更新なし／更新を反映中）を字でも出す。色だけで伝えない（§CLAUDE 3）。
  5. 失敗したときは「次の一手」を1つだけ太字にし、残りは「ほかに調べること」へ畳む。 同時に3つ指さない（§CLAUDE 2）。
  6. いまの段のすぐ下に、その段の詳しい一言を置いた（離れていると別の話に見える）。
