起動モーダル v7 — 標準形は S4（流れる帯）で固定。動きの案を6つ

骨格・配色・文字・ステータスバー・更新の札は S4 のまま1pxも動かしていません。 違うのは動きの層だけで、どれも被せて外せる作りです（動きを外すと標準形に戻る）。 波紋を「どこに置くか」で6通り振りました。

動きを足すときに守ったこと

  • 動きだけで伝えない。どの案も、動きが言っていることは必ず字でも書いてある（§CLAUDE 3）。 prefers-reduced-motion で全部止めても、読めるものは1つも減らない。
  • 骨格に触らない。動きは .m1〜.m6 を器に足すだけ。 帯・バー・札のHTMLは共通の1本（意匠を選んでも作りは分岐しない）。
  • 失敗したら動きは止まる。「動いている＝進んでいる」を崩さない。
  • ふだんの起動は約3秒で10段＝1段0.3秒。動きの長さはこれに収まる範囲で選んだ。
