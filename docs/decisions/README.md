# 決定記録（§9）

WaveLog の画面まわりは実装の順に積み上がった。**なぜそうしたか・実測値・
撤回した案・踏んだ罠**をここに1節1ファイルで残す。

- **規則そのもの**（いま守ること）は [`CLAUDE.md`](../../CLAUDE.md) の表にある。
  コードを触る前に読むのはそちら。
- **ここ**は、その規則が「なぜその形なのか」を確かめたいときに開く。
  CLAUDE.md の各行の「くわしく」からここへ来る。
- スケジュール機能そのものの設計（§1〜§8・§10〜§13）は
  [`../SCHEDULE_MODE_DESIGN.md`](../SCHEDULE_MODE_DESIGN.md)。

**§番号は振り直さない**——コード・テスト・CLAUDE.md から番号で参照されて
いるため（実測 11,764 箇所）。並べ替えの代わりに、下の主題別の入口を置く。

印の意味: **仕様**＝今どう動くか（実装を変えるときに読む） / 
**経緯**＝なぜそうしたか（同じ直し方を繰り返さないために読む）
