# §9.512 表示列の編集をアクセス権限マスタで決める（利用者の指示）

索引: [決定記録](README.md)

## 利用者の言葉

「表示列の編集権限もマスタのアクセス権限のところに管理できる内容として組み込んでください。」

## 測った（評価関数・直す前）

| 物差し | 前 | 後 |
| --- | --- | --- |
| 表示列の編集を端末・人ごとに決められる項目（アクセス権限マスタ） | **0**（決めているのはモードだけ——編集・スケジュールなら誰でも、閲覧なら誰も） | 1（「表示列の編集」3段） |
| みんなと同じ表示列を、自分の分だけにしたい人が変えられるか | 変えると**全員に効く**（止める手が無い） | 「自分の分だけ」なら自分だけへ切り替えて保存（全員の分は変えない） |
| 閲覧モードで列幅を変えたとき | 403の決まり文句（「現在のモードでは…」）で理由が分からない | 変更不可なら**送らず**、理由と直す場所を字で1回だけ言う |

## 決めたこと
- 段は3つ（`master_repo.COLUMN_EDIT_LEVELS`）: **変更不可**／**自分の分だけ**／**編集可**。
  **既定は編集可**（§9.132——この列を持たない既存の行・登録の無い端末の見え方を1つも変えない）。
- **マスタ編集とは別の軸**。マスタ編集はマスタ管理の画面の段で、画面の見せ方は対象外のまま（§9.322）。
  見せ方を絞る口はこの1列だけ。区分の上限（キャップ）は掛けない（依頼に無い・設備作業者も今までどおり）。
- 判定は`column_edit_check()`の1箇所。ルート（列レイアウトの保存・切り替え、作業スケジュールの設備の列・内容）は
  段と保存先（''＝みんなと同じ）を渡すだけ。作業スケジュールの設備の列・内容は**みんなで1つ**なので「編集可」だけ。
- **帳票の紙（`report:<設備>`）には掛けない**（`COLUMN_EDIT_EXEMPT_PREFIXES`）。同じ列レイアウトマスタに住むが
  表示列ではない（帳票レイアウト・帳票ブロックと組で決めるもの）。住まいが同じだけで絞ると帳票を直す人が止まる。
- 画面は**サーバーの答えを受け取るだけ**: 列レイアウトの応答に`columnEdit`／`canEditOwnColumns`／`canEditCommonColumns`
  （対象ごと）。`WL.columnLayout`が保存の行き先を決める——変更不可＝送らない（1回だけ字で言う）、
  自分の分だけ＝みんなと同じを見ていたら**自分だけへ切り替えてから**保存（断って行き止まりにしない）。
  列の設定パネルは押せない物を押せなくし、理由を字で書く。
- プリセット・表示ルール・絞り込みは名前を付けて残す別の物で、この段では絞らない（決めたら書く・§9.510と同じ書き方）。

## 踏んだ罠
- 保存の前に「行き先を決める」`await`を1つ挟んだだけで、**保存中の札が出る前・保存済みへ当てる前に描き直しが走り**、
  掴んで離した列幅が一瞬もとへ戻った（test_sctimecols 2件・test_lcpanel 1件）。行き先が待たずに決まるいつもの場合は
  `routeNow()`が同期で答え、切り替え・読み込みが要るときだけ待つ。**いつもの保存を1手も遅らせない。**

## 固定する網
- `test_roleperm.py` ⑩ … 3段・既定・別の軸・帳票の紙は対象外・ルートが実際に断る／自分だけへ切り替えれば保存できる
- `test_roleui.js` ⑥ … 変更不可は送らず字で言う／自分の分だけは切り替えてから保存／編集可は今までどおり
- `test_sctimecols.js`・`test_lcpanel.js` … いつもの保存が遅れない（列幅・保存中の札）
