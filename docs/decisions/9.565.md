# §9.565 読ませる字は 12px 以上——段2（マスタ管理のほかのタブ・ダッシュボード・カレンダー）

索引: [決定記録](README.md)｜前: [§9.564](9.564.md)｜関係: [§9.560](9.560.md)・[§9.562](9.562.md)

## 経緯

利用者の指示「残りの小さな字の修正を進めてください」。§9.560（段1）で全画面に出る字と共通設定の 8 画面を直し、
残り（マスタ管理のほかのタブ・ダッシュボード・カレンダー）を段2とした。

## 測った（前）

- 28 のマスタのタブ・ダッシュボード・カレンダー・品質データを巡回して、12px 未満の読ませる字が **626**（操業データ項目 107・
  帳票レイアウト 94・不要ファイル掃除 75・記録した値の配置 69・選択肢の値 54…）。
- 省略記号で切れている字: 109。
- 小さな大きさを決めている CSS の規則を**画面から逆にたどった**（字ごとに祖先へ上り、`--fs-micro`／`--fs-tiny`／`--fs-badge` を
  持つ規則のうち当たる物）: **108本**。ほぼ全部が `50-master.css`（83本）。

## 直したこと

1. 107本の規則の大きさを `--fs-sm` へ（図の目盛り `.op-ruler-cell`・`.shift-bar-scale` の2本は「図の中の字」なので残す）。
2. **`<small>` は土台で `--fs-sm`**: ブラウザの既定は「親より1段小さく」で、12px の中では 10px になっていた。部品ごとに直さず
   土台の1行で止める（部品の規則が大きさを決めれば勝つ）。
3. 刃組の一覧の2行目（`.bk-tx small`・何に効くか）は**切らずに折り返す**。12px にしたら「刃の重なりと屑条（開いたときの初…」と
   切れた。あわせてその1行を「刃の重なりと屑条の初期値」に短くした（「開いたときの」は初期値の意味に含まれる。折り返すと
   「値）」だけが2行目に落ちた）。

4. 操業データ項目の「役割の一覧」ボタン（`#opRoleMore`）は高さを「最低 26px」とだけ決めていたので、字を 12px にしたら中身なりに
   32px へ伸び、決めた高さ（19/26/30/36/40）から外れた（`test_scale` が見つけた）。表の中・タグの役割と同じく高さを 26px に決め、
   上下の余白を 0 にした。

## 測った（後）

- 12px 未満の読ませる字: 626 → **17**（残りは図の目盛りだけ）。
- 省略記号で切れている字: 109 → 109（増やしていない）。
- 目で確かめた: 刃組基準値・操業データ項目・帳票レイアウト（盤の札・一覧の副題・表の頭が 12px になり、作りは崩れていない）。

## 網

- `test_smalltext.js` の巡回に、マスタ管理の 25 タブ・ダッシュボード・カレンダーを足した（計 36 画面）。HTML で描いた図の目盛りは
  名前で除く。欠陥注入（帳票レイアウトの札を 11px に戻す）で 40 件の赤になることを確かめた。
- 同じ巡回で、太さ（§9.562）と灰色（§9.564）の見張りも 36 画面へ広がった。
