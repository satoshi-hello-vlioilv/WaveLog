# §9.567 境界の約束を1つの定義に——画面とサーバーが同じ定義（サーバーのコード）を読む

索引: [決定記録](README.md)｜前: [§9.566](9.566.md)｜関係: [§9.563](9.563.md)・[§9.330](9.330.md)・[§9.82](rules-misc.md)

## 経緯

§9.563（言語の住み分け）の「次の段」3。利用者の判断「３．境界の約束を1つの定義に：実施」。
実際に起きた不具合のうち 9件が**言語の境界**で起きていた——画面が送った字をサーバーが`None`へ落とした（§9.205）、
画面がサーバーの返した鍵を捨てた（§9.381）、`/update`が無くて 404 の HTML がトーストに出た（`MASTER_DEFS`）、
同じ判定を2つの言語で持った（§9.378・§9.44）、同じ設定ファイルを2つの言語で書いた（§9.561）。

## 測った（前）

物差しは2つ。

1. **いまの食い違い**（静的に数える）: 画面の`api()`・`fetch()`の呼び出し 254本を、サーバーのルート 242本と
   本文の宣言（`body({...})`）に突き合わせた。当たる道が無い 0・メソッド違い 0・宣言に無い鍵を送る 0・
   字面の値の種類が宣言と違う 0。**送る側はすでに`body(spec)`（§9.330）が1つの定義になっていた**。
   - 突き合わせを作る途中で、照合の誤りで3件を食い違いと数えた（`'/api/x'+q` の`q`が空のときを外していた・
     計算で決まる鍵`[fld]`を字面の鍵と数えた）。直してから 0。
2. **過去の形を注いで止まるか**（評価関数）: 下の表の6つ。**今の網（eslint・型の網）は 0件**。
   `test_crudroutes` は`MASTER_DEFS`の汎用 CRUD だけを、サーバーを起こして HTTP で見る（字面で呼ぶ所は見ない）。

**返す側には定義がどこにも無かった**——応答にどの鍵が入るかは、ルートの`return`の中にしか書かれていない。

## 決めたこと

### 約束の定義はサーバーのコードの1か所。網と画面の型はそれを読むだけ

`tests/lib/api_contract.py` が**読み出すだけ**（写しを持たない）:

| 約束 | 定義（サーバーのコード） |
|---|---|
| 道とメソッド | Flask のルート表（`app.url_map`） |
| 受け取る本文の鍵と型 | ルートの中の`body({...})`の字面（§9.330） |
| 返す応答の鍵 | ルートの`return`の字面（`jsonify(a=…)`・`{'a': …}`・`(本体, 状態)`）。400 以上の状態で返す物は数えない（`api()`が投げるので画面は読まない） |

読めないもの（`return 関数(...)`）は「分からない」として返し、推して埋めない。いまは 242本のうち
**応答の鍵が字面で読める 138・一部（`**x`を含む）43・分からない 61**。

### 画面の側: `api('/api/…')` の戻りの型にする（§9.566 の型の検査へ流す）

`tests/lib/js_types.js --contract` が、道が字面だけの呼び出しに**その道の応答の鍵を持つ型**を返す。
画面がサーバーの返さない鍵を読むと、書いた時点で型の検査で止まる。

- 同じ道の GET と POST は鍵を合わせる（`api()` の型は道でしか分けられない）。
- `{*}` を含む道・応答が分からない道・`'/api/x'+q` のように式で組む道は any のまま。
- `(await api(…)) || {}`・`.catch(e => ({error}))` は「応答の型 | 別の形」になり、応答に在る鍵でも 2339 が出る。
  **どれかの形がその鍵を持つ（または何でも持てる）なら数えない**。どの形も持たないなら本物として数える。
- `base.js` の中の`api`は自分の注記（`@type`）の型のまま（約束の型は他のファイルから見た公開の型）。

### 送る側: 呼び出しを約束に突き合わせる（0件に固定）

`test_tscheck.py` が、画面の呼び出しの道・メソッド・`JSON.stringify({…})`の鍵と字面の値の種類を、
ルート表と`body(spec)`に照らす: 当たる道が無い／メソッドが違う／宣言に無い鍵を送る／値の種類が宣言と違う、の4つが 0件。
「誰が・どの端末で」の鍵（`IDENTITY_KEYS`）はどの道でも通す（`body.py`の同じ定義を読む）。

## 止められないもの（この段の外）

- §9.381「画面が受け取った鍵を自分で選り分けて捨てる」: 捨てるのは画面の中の判断で、約束の食い違いではない。
- §9.378・§9.44「同じ判定を2つの言語で持つ」・§9.561「同じファイルを2つの言語で書く」: 作りの決まり
  （答えは1か所・書き手は1言語・§9.563）で防ぐ。
- §9.438・§9.545（二重の追加・行き違い）: 時間の順の問題で、形では捕まらない。
- 応答の鍵が字面で読めない 61本の道と、式で組む道は型にならない。応答の鍵を`return`の字面に寄せるほど届く範囲が広がる。
