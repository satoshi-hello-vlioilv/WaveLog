# §9.439 行間の差し込み案内は「どこへ入るか」だけ／やめるは持たない／3段でON/OFF

索引: [決定記録](README.md)

利用者の指示:

> 作業スケジュールのロットや設備停止挿入用の過剰なコメントは控えて、
> ユーザーのカーソルの邪魔にならないようにしたい。やめるボタンも不要。
> 表示自体もONOFFできるようにしたいです。

---

## ① 測った（評価関数）

「邪魔」を数で言えるようにする。**カーソルの周りに出る物**を4つの物差しで測る:

| 物差し | 直す前（未固定） | 直す前（固定後） | 直したあと（未固定） | 直したあと（固定後） |
| --- | --- | --- | --- | --- |
| 札の字数 | **40字** | **47字** | **12字** | **13字** |
| 札の寸法 | 461×18px | **576×28px** | 145×18px | 157×18px |
| 覆う行数（行の高さ28pxで割る） | 0.65行 | **1.01行** | 0.65行 | 0.65行 |
| 押せる面積（下の行のクリックを食う量） | **8,381px²** | **16,128px²** | **0** | **0** |
| 「やめる」ボタン | — | あり | — | **無し** |
| 設定の段階 | **2段** | | **3段** | |

**固定後の札は、行をちょうど1つぶん覆っていた**（1.01行）。「やめる」ボタンの
高さ（`--ctl-h-xs`）が札の高さを決めていたためで、押そうとした行が札の下に
隠れる。カーソルの邪魔そのものだった。

---

## ② 札が書くのは「どこへ入るか」だけ

以前の札は2つのことを書いていた:

```
＋ ここへ入れる（L0004の前）  クリック: 設備停止／ダブルクリック: 仕掛から選ぶ
   └ どこへ入るか            └ 何ができるか
```

**「何ができるか」は境目ごとに変わらない事実**なので、境目ごとに書き直す
理由が無い（§CLAUDE 8「同じ情報を2箇所に出さない」）。しかも**すでに
2箇所に出ていた**——一覧の下の案内（`#scSplitHint`）が同じことを言っている。

「どこへ入るか」だけが**カーソルの位置で変わる**ので、札はそれだけを言う:

```
＋ L0004の前へ入れる      （これから・水色）
▼ L0004の前へ入ります    （決まった・緑）
```

**「入れる」と「入ります」の言い分けで状態も字に出す**（§CLAUDE 3「状態は
色だけで伝えない」）——緑にしただけでは、決まったのかまだ選べるのかが読めない。

### 落ちた「何ができるか」の行き先

**消さずに、落ちない置き場を1つ持つ**（§9.434 と同じ作法）:

| 何 | どこ |
| --- | --- |
| クリック／ダブルクリックの使い分け | **線そのものの `title`**（素のツールチップ） |
| 行間から入れられること・行の中央は掴めること | 一覧の下の案内（`#scSplitHint`）——**以前からここに在った** |

素のツールチップを選んだのは、**手が止まってから出て、当たり判定を持たない**
から。カーソルの邪魔をしないまま「推測させない」を守れる。

## ③ 札は当たり判定を持たない

以前の札は `pointer-events:auto` ＋ `cursor:pointer` で、**押せる箱**だった。
押せる箱が2つ（線と札）重なっていたので、札の下に入った行のボタンが押せない。

**押せるのは線だけ**にした（`pointer-events:none`）。札は「線が何を指して
いるか」を言うだけの読み物になる。実測で押せる面積は 8,381px² → **0**。

同じ理屈が§CLAUDE 10（読み取り専用の値に押せる見た目を付けない）にある。

## ④ 「やめる」は持たない——外す道は元から在った

`insertPinned`（位置の固定）が立つのは `openInsertPicker()` の中だけで、
そこは**必ず仕掛一覧か設備停止の窓を開く**。そして
`closeListModal()` と `closeStopModal()` は**どちらも `clearInsertPin()` を通る**。

つまり「窓を閉じる＝位置の固定が外れる」が既に成り立っており、
**「やめる」は2本目の外す道**だった（§CLAUDE「同じ役目の物を2つ作らない」）。
消しても外せなくなる場面は無い。

消したことで札の高さが 28px → 18px（1.01行 → 0.65行）に戻った——
**器（ボタン）を消すと、中身だけでなく器が決めていた寸法も一緒に消える。**

## ⑤ 表示は3段（`SC_INSERT_GUIDES`）

| 値 | 何が出るか |
| --- | --- |
| `tip`（既定） | 線＋「どこへ入るか」の札 |
| `line` | 線だけ（慣れた人向け） |
| `off` | **出さない**——行間をカーソルで狙う道そのものを閉じる |

### 決めたこと

- **`off` でも、掴んで運んでいる間の線は出す**（`insertByDrag`）。掴んでいる手は
  すでに行き先を決めているので**線が邪魔をしようがなく**、どこへ落ちるか
  分からないほうがずっと困る。「出さない」が閉じるのは
  **カーソルで狙う道**（`mousemove`）だけ。
- **`off` を選んだら「できない」と書く**（§CLAUDE 4）。一覧の下の案内が
  「いまは行間からは入れられません——左端の帯を押して仕掛一覧を開き、
  ドラッグで入れてください」に変わる。**押しても何も出ない道を、
  できるかのように書き残さない。**
- **位置を固定したあとは、`line` でも札を出す。** 決まった位置を字で言うのは
  ここだけで、緑色だけで伝えてはいけない（§CLAUDE 3）。
- **古い保存値（`tip`: 真偽）も読む。** `false` は `line` へ移す——切って
  いた人の設定を黙って既定へ戻さない。

## ⑥ 網（`test_scinsert.js` 36件）

**絵ではなく数で見る**——「短くなった気がする」は測ったことにならない:

- 札の字数が20字以内（実測 40字→12字）
- 札の `pointer-events` が `none`（押せるのは線だけ）
- 札の高さが1行未満（実測 1.01行→0.65行）
- 位置を決めた札に `.sc-insert-cancel` が無い
- 操作の仕方は線の `title` が持つ
- 3段（`tip,line,off`）を選べ、端末に覚える
- `off` ではカーソルで線も札も出ず、案内が「できない」と書く
