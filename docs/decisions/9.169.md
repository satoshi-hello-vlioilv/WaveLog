# §9.169 帳票の塊（ブロック）と配置の組み換え（利用者の指示）

利用者の指示は「帳票表示について、データの塊ごとに(カードのように扱い)表示非表示を
修正できるように。リアルタイムでその表示状況を確認しながら帳票の配置(グリッド化)も
組み換えできるようにしたい。汎用的な構造に」。

`reportHtml()`が「ゾーン(3列/2列…)」をHTMLへ直接書いており、載せる・載せないも幅も
**コードを直さないと変えられなかった**。

1塊＝1ブロックとして登録し（`RP_BLOCKS`）、並び・出す/出さない・幅を
**列レイアウトマスタ**（対象`report:lot`）に載せる。**新しいマスタを作らない**
——同じ「見せ方の設定」なので、保存（全置換）・staging（保存せずに当てる）の作りを
そのまま使える。`widths`はpxではなく**12分割の何マスぶんか**を持つ。

- 紙は**12マスの粗いグリッド**、選べる幅は5つだけ（1/4・1/3・1/2・2/3・全幅）。
  細かくするほど左端の候補が増えてそろって見えなくなる（§9.135）。
- `html(x)`が`''`を返したら**このロットには中身が無い**。紙には出さず、組み換え中
  だけ「中身なし」と分かる形で置く——黙って消えると、自分で隠したのかデータが
  無いのかが分からない。
- **操作帯は組み換え中しか組み立てない。** CSSで隠すやり方だと、隠し忘れがそのまま
  紙に出る。「やめる/保存」の帯は**紙の外**（印刷物に混ざらない・A4の割り付けを
  崩さない）。
- **保存せずに当てる**（`stage()`。§9.90と同じ）。触った結果がそのまま紙に出るのが
  分かりやすく、「やめる」で開いた時点へ必ず戻せる。**画面を離れるときも戻す**
  ——列レイアウトマスタのキャッシュは画面をまたいで共有なので、当てたまま抜けると
  他の画面が触った覚えの無い設定で描かれる。
- **帳票の頭（設備名・作業年月日・ロット番号）はブロックにしない。** この紙がどれかを
  決める鍵で、隠せると配ったあとで区別が付かなくなる。

固定は`tests/test_rpblocks.js`。

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **帳票の中身は「塊（ブロック）の並び」**（§9.169、`RP_BLOCKS`／対象`report:lot`）:
  並び・出す/出さない・幅を**列レイアウトマスタ**に載せる（新しいマスタを作らない）。
  紙は**12マスの粗いグリッド**で、選べる幅は5つだけ（1/4・1/3・1/2・2/3・全幅）。
  **`widths`はpxとして40〜900へ丸められる**（`normalize_column_width`）ので、
  マスの数をそのまま入れると全部40になり**保存した幅が黙って既定へ戻る**
  ——`マス数×RP_SPAN_UNIT(60)`で入れて読むときに割り戻す（一覧の幅の決まりは
  緩めない。あちらは実際にpxとして使う）。`html(x)`が`''`＝**このロットには中身が
  無い**で、紙には出さず組み換え中だけ「中身なし」と分かる形で置く。
  **操作帯は組み換え中しか組み立てない**（CSSで隠すと隠し忘れが紙に出る）。
  **保存せずに当て、画面を離れるときも開いた時点へ戻す**——列レイアウトマスタの
  キャッシュは画面をまたいで共有なので、当てたまま抜けると他の画面が触った覚えの
  無い設定で描かれる。**帳票の頭はブロックにしない**（この紙がどれかを決める鍵）。
  固定は`tests/test_rpblocks.js`。
