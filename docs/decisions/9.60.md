# §9.60 ヘッダーの「今どこを見ているか」

`#fileName`はlist-view.jsの`applyTableData()`だけが書いており、他の画面へ
移っても消していなかった。そのため「データ一覧を見ているのにヘッダーは
SIKALOTNOW.sqlite3」という、直前に見たDBの名残が残り続けていた。

`setHeaderContext(画面名, データの出どころ)`をbase.jsに置き、画面を開く
関数が必ず呼ぶ。主が画面名、副がファイル名や範囲。

| 画面 | 主 | 副 |
|---|---|---|
| データ一覧 | データ一覧 | この端末に保存された測定データ |
| 仕掛(現在)/品質データ | 仕掛一覧/品質データ | 実ファイル名 |
| 作業スケジュール | 作業スケジュール | 設備ごとの作業予定と実績 |
| ダッシュボード | ダッシュボード | 作業予定と測定実績の集計 |
| 実績カレンダー | 実績カレンダー | この端末に保存された測定データ |
| マスタ管理 | マスタ管理 | master.sqlite3 |

**スケジュールの分割表示中(`body.sc-mode`)は`applyTableData()`から書き換え
ない**。仕掛一覧はスケジュール画面の中の一区画にすぎず、書き換えると
作業スケジュールを見ているのにヘッダーだけ「仕掛一覧」になる。鮮度表示
(`#listFreshness`)も同じ理由でsc-mode中は出さない。

あわせて画面文言の「Access」を実態(`db/records.sqlite3`)へ改めた。
マスタ・測定バックアップはSQLite化済みで、Accessのままなのは仕掛・品質
データだけ。
