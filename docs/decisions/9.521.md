# §9.521 ロット問い合わせの拡張を単独のアプリ LotData-Link へ切り出す——WaveLog は合図だけを持つ（利用者の指示）

索引: [決定記録](README.md)｜前: [§9.520](9.520.md)

## 経緯

利用者の指示「拡張機能だけを切り離し、１つの拡張専用アプリとして、新しいリポジトリに LotData-Link として登録し、
WaveLog の付属品的な扱いから切り離し、ロット問い合わせとアプリとのリンクを扱うデータリレー的な立ち位置の単独アプリ
開発にしたいです」。

同梱の拡張（`program/lotdsp-ext`・版 1.1.1）は、WaveLog の自動ログイン（§9.485）と転写計算アプリへの取込（§9.519・
§9.520）の2つの道を持ち、WaveLog の外のアプリ（転写計算アプリ）のための仕事が半分を占めていた。同じ回に、VPN の
一体型の画面（ロット番号とログインが同じ枠・「検索」1つ）で取込が止まる報告があり、その直しも拡張の中の話だった。

移す範囲は利用者が選んだ「拡張をまるごと移す」（自動ログインも取込も LotData-Link が持つ。Edge に入れる拡張は1つの
まま、ログインを2つの拡張が取り合わない）。VPN の直しは WaveLog には入れず、LotData-Link の最初の版（2.0.0）に含めた。

## 決めたこと

- 拡張の中身・拡張の試験（`test_lotdspext.js` の拡張の部分・`test_tpaext.js`）・見本ページ（`lotdsp_login.html`・
  `lotdsp_progress.html`）は LotData-Link（`https://github.com/satoshi-hello-vlioilv/LotData-Link`）へ移し、WaveLog から消す。
  設計の経緯（§9.485・§9.519・§9.520）は LotData-Link の `docs/DESIGN.md` へ要約して移した（こちらの記録は残す）。
- **WaveLog に残すのは画面の約束だけ**: 拡張が `<html data-lotdsp-ext="版">` で名乗る／WaveLog が `wl:lotdsp-options`
  で登録画面を頼む。名前は変えない（LotData-Link も同じ名前で名乗る）。**WaveLog は ID・パスワードを受け取りも渡しもしない**
  （§9.485 のまま）。
- 同梱の拡張の置き場を答えていた `GET /api/lotdsp/ext` は消す（置き場は WaveLog のフォルダではなくなった）。
- 使用設備の設定③は形を3つにする。
  - LotData-Link（版 2 以上）: 「LotData-Link: 入っています（版）」と、登録・修正を開くボタン。
  - 以前の同梱の拡張（版 1.x）: 「入れ替えが要ります」（設定要の色）。**古い拡張を先に消す**手順を、入れ方より前に書く
    ——2つ入っていると同じログイン画面で2つが動き、ログインを二重に押すおそれがある。ID・パスワードは拡張ごとに
    保存されるので、1度だけ登録し直すことも書く。
  - 入っていない: LotData-Link の入れ方（リポジトリ・`edge://extensions`・展開して読み込み・`extension` フォルダ）。
- WaveLog の画面が拡張の版で分けるのは「2 以上か」だけ（LotData-Link の版の付け方は LotData-Link が決める）。

## 撤回した案

- **取込だけを LotData-Link へ移し、自動ログインは WaveLog に残す**——拡張が2つになり、同じ LotDsp の画面で2つが動く。
  VPN の一体型の画面のようにログインと検索がからむ画面で、互いの待ち合わせが2つの拡張をまたぐ（利用者が選ばなかった）。
- **WaveLog の設定に LotData-Link のフォルダの場所を持ち、「場所をコピー」を残す**——置き場は端末ごとに違い、
  WaveLog が他のアプリの置き場を覚える理由が無い。手順とリポジトリの場所を書くだけにした。
