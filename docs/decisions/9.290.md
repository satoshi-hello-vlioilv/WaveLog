# §9.290 帳票を刷ると異常位置判定の条が消える——背景色を紙にも刷る（利用者の報告）

利用者の報告:

> 帳票ブロックマスタの異常位置判定結果の表示について、実際に印刷をすると、
> **条の表示が消えたり見た目に変化があります**。紙のレイアウトで表示している
> 見た目通りの印刷結果にしたいので修正をお願いします。

### この図は「面」だけで出来ている

`WL.defect.reportSectionHtml()` が組む図の中身は、**全部が背景**である。

| 部品 | 何で描いているか |
| --- | --- |
| 条（`.rp-defect-lane`） | `background-color:var(--defect-lane-bg)` |
| 屑（`.rp-defect-scrap`） | `repeating-linear-gradient` の縞 |
| 欠陥の帯（`.rp-defect-mark::before`） | `background:#a32424;opacity:.32` |
| 位置の旗（`.rp-defect-flag b`） | `background:#a32424` ＋ `color:#fff` |
| 帯の地（`.rp-defect-strip`） | `background:#eef2f4` |

ブラウザは印刷のとき背景色を落とすのが既定（`print-color-adjust:economy`）
なので、**条がまるごと消え**、しかも条の番号と旗の文字は `color:#fff` なので
**白地に白**で残る。線（枠・目盛・センターライン）は`border`なので残る
——だから「消えた」だけでなく「見た目に変化」にも見える。

### 直したのは1行。ただし**説明だけが先にあった**

§9.237 ② で作業予定表について「**`print-color-adjust:exact`を`.sp-page`へ
必ず付けること**」と決めてある。ところが帳票側は付いておらず、しかも
`60-report.css` の `.rp-field-head` の注記には

> `print-color-adjust:exact`は`.rp-page`が持っている（§9.237 ②）ので、
> ここでは面を置くだけでよい

と書いてあった——**説明だけが先にあって実物が無い**状態で、後から面を足した人
（軸の見出し・ピボットの表・バッジ）はその注記を読んで「もう効いている」と
判断できてしまう。いまは `.rp-page` と `.df-page`（判定書）の両方が持つ。

**`:root`／`body`へは付けないこと**（§9.237 ②）——`<html style="background:#0d2029">`
の濃紺が紙全面に刷られる。**紙の器にだけ**付ける。

**判定書（`.df-page`）も一緒に直す**——載るのは`visualHtml()`の**同じ図**なので、
片方だけ直すと「帳票は直ったのに判定書だけ条が消える」が残る。

### 網は「指定が在る」で終わらせない

`print-color-adjust`は**塗るときの振る舞い**なので、宣言を見るだけの網は
「付いているのに効かない」（後から`economy`で上書きされた等）を素通りする。
2枚で守る:

- `tests/test_rpprint.js` … 刷る書類の`.rp-page`の**解決値**が`exact`で、
  **`body`は`exact`でない**こと（紙にだけ付ける）
- `tests/test_rbsample.js` … **実際に刷って中身を見る**。
  `page.pdf({printBackground:false})`（＝印刷ダイアログで「背景のグラフィック」を
  切った状態＝既定）でPDFにし、**条の色の塗りつぶしが content stream に在るか**を
  数える。色は画面から引く（`--defect-lane-bg`）ので、配色を変えても網は古びない。

実測（見本のロット・A4縦1枚）:

| | 条 `#5b8f88` | 欠陥/旗 `#a32424` | 帯の地 `#eef2f4` |
| --- | --- | --- | --- |
| 直す前 | **0** | 4 | 43 |
| 直したあと | **12** | 6 | 70 |

直す前に残っている赤と地は**線と文字**（`border`・`color`）なので、
「枠と目盛だけが刷られ、色の付いた条は1本も出ない」という見え方になる。

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **紙にだけ`print-color-adjust:exact`を付ける。説明を先に書かない**（§9.290、
  利用者の報告「帳票ブロックマスタの異常位置判定結果の表示について、実際に
  印刷をすると、条の表示が消えたり見た目に変化があります」）: 異常位置判定の図は
  **全部が背景**（条＝`background-color`／屑＝縞のグラデーション／欠陥の帯と旗＝
  赤い面／帯の地）なので、既定（`economy`）のままだと**条がまるごと消え**、
  条の番号と旗の文字（どちらも`color:#fff`）が**白地に白**で残る。線は`border`
  なので残り、「枠と目盛だけ刷られる」という見え方になる。§9.237 ②で
  `.sp-page`について決めたのと同じ約束なのに、**帳票（`.rp-page`）と判定書
  （`.df-page`）には付いていなかった**——しかも`.rp-field-head`の注記には
  「`.rp-page`が持っている」と書いてあり、**説明だけが先にあって実物が無い**
  状態だった（後から面を足す人はそれを読んで「もう効いている」と判断できる）。
  **`:root`／`body`へは付けないこと**（`<html>`の濃紺が紙全面に刷られる）。
  **同じ図が載る紙は一緒に直す**（片方だけだと「帳票は直ったのに判定書だけ
  条が消える」が残る）。**網は宣言を見ないこと**——`print-color-adjust`は
  塗るときの振る舞いなので、`page.pdf({printBackground:false})`で**実際に刷って
  content streamの塗りつぶしを数える**（色は画面から引く。実測で条は0→12）。
  固定は`tests/test_rpprint.js`（解決値）・`tests/test_rbsample.js`（刷り上がり）。
