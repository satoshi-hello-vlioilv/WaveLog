# §9.265 畳んだ左メニューの行き先を浮き出しで示す（利用者の指示）

> メインのメニュー(左サイドバー)の部分も折りたたんだときはわかりにくいので、
> ポップオーバーでの説明はきれいにわかりやすく表示が出るように、小さな
> アイコンでも区別しやすいように内容と合っているか再考して再設計して
> ください。

畳むとラベルが消え、行き先は素の`title`だけになっていた。**出るまで1秒近く
かかり、見た目も揃わず、触る画面では読めない**（§4）。

**器はbody直下に1つだけ**（`aside`は幅54pxで`overflow`を持つので、中に置くと
切り落とされる・§9.201）。中身は**行き先の名前が主、説明は従**——アイコン
だけでは何の画面か分からないのが畳んだときの問題なので、まず名前を出す。

**畳んだら`title`は外す**（浮き出しと二重に出る・§8）。ただし**説明は
`data-navTitle`に残して浮き出しが出す**——消さない。

**委譲で受ける。** 行き先は後から足される（カレンダー・ダッシュボード）ので、
1つずつ配線すると足された項目だけ浮き出しが出ない。
**`pointer-events:none`**（下の行き先を押せなくしない）。**画面の外へ
出さない**（上下端で押し戻す）。

**アイコンは「畳んだときに見分けが付くか」で選ぶ。** 作業スケジュールが
**箱＋横線＝表**に、実績データが**3本線＝一覧**に見えており、隣の仕掛と
区別が付かなかった。前者は工程の帯（ガント）、後者は記録した紙＋チェックへ
描き直した。

固定は`tests/test_nav.js`。
