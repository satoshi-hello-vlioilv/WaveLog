# §9.431 update.bat の画面は「結果」と「次にすること」だけ

索引: [決定記録](README.md)

利用者の指示「update.batは起動した際にユーザーが読んで知っておくべき情報を
もっとわかりやすく表示するようにしてください。一般的には不要な情報が多いので
わかりにくいです」。

## ① いちばん多かったのは「記録」だった

`setup_app.py` は `launcher_logger()` を使っていて、**これは既定で画面にも出す**
（`get_logger(..., to_console=True)`）。しかも `log_environment()` が Python の
道・版・配置・プロセスID・ログの置き場を**毎回6行**出す。さらに `say()` が
記録と画面の両方へ同じ文を出すので、**同じ内容が2回**並んでいた。

そのうえで画面に出ていたのは、**毎回同じで打つ手が変わらない道**——
バイトコードの置き場・刻印の道・起動画面の写しの道。

## ② 直し方

| これまで | これから |
| --- | --- |
| 時刻つきの記録が画面に流れる | **`launcher_logger(to_console=False)`**。記録は `launcher.log` に全部残る |
| 置き場の道を画面に出す | `say(..., quiet=True)`＝**記録だけ**。画面には出さない |
| 「確認できました」等の言葉が `update.bat` にも `setup_app.py` にもある | **言葉は `setup_app.py` の1箇所**。`update.bat` が自分で言うのは「python が通っていない」ときだけ（そのときは `setup_app.py` が動かない） |
| 手順の行が文章 | **`[OK]`／`[NG]` の付いた短い1行**（何を確かめたか） |
| ログの道をいつも出す | **うまくいかなかった回だけ**出す（§CLAUDE 2 次にすることを1つだけ指す） |

出るのはこうなった（正常時・20行）:

```
============================================================
  WaveLog  起動の準備
============================================================
  アプリの置き場所   \\srv\WaveLog
  この端末の作業場所 C:\Users\...\AppData\Local\WaveLog

  [OK] 必要な部品（flask）
  [OK] 起動を速くする準備（事前コンパイル）

------------------------------------------------------------
  準備ができました。

  次にすること
    デスクトップの「WaveLog」から起動してください。

  覚えておくこと
    アプリを更新したら、この update.bat をもう一度実行してください。
    （忘れても起動はできます。その1回だけ起動が遅くなります）
============================================================
```

**「変わったこと」は出す。** 部品を導入した・古いDBを取り込んだ・置き場が
変わった古いファイルを片付けた・起動画面を新しくした——どれも稀で、
知らないと次に困る。いつも同じことだけを畳んだ。

## ③ `say` の作法が1つ増えた

`setup_check.run(say)` を呼ぶ道は**2つ**ある（`update.bat` と、刻印が
食い違ったときの起動）。`say` は `(message, bad=False, quiet=False)` を
受けること——**受けないと、そこを通った起動が TypeError で止まる**
（実際に網の `say` スタブが先に落ちて分かった）。

## ④ 網

`test_faststart.py`（サーバー不要の1段目）:

- **実際に `setup_app.py` を動かして出た字で見る**——呼び方ではなく出力。
  ①時刻つきの記録が1行も無い ②「準備ができました」「次にすること」が在る
  ③`ready.json`／`pycache`／`loading.html` の道が**出ていない**
- `setup_app.py` と `start_app.py` の `say` が `quiet` を受けること
- `update.bat` が結果の言い分けを持たないこと（言葉は1箇所）
