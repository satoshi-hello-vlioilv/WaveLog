# §9.383 作業スケジュールを刃組スケジュール一覧に切り替える（利用者の指示）

利用者の言葉:

> 作業スケジュールを切り替えて刃組スケジュール一覧としても出せるようにして
> ください。その場合、使用台車、使用刃、板押さえ種類、ゴムリングまたは
> フィンガーの使用種類と使用数、スペーサー使用種類と使用数、クリアランス設定、
> ラップ設定値、刃組後1本目に切る材料(材質、板厚、板幅、用途名)、そのスケジュール
> で対象の刃組で切る予定本数。

段（全体／個別）へ「刃組」を足した。**同じ予定を段取りの側から見る**もので、
行は予定の中の刃組の停止1つずつ。挙げられた項目は全部列にある（網で固定）。

## 値の出どころを必ず書く

| 出どころ | 出るもの |
| --- | --- |
| 記録済み | 刃組完了で残した1件（§9.382）がそのまま出る |
| これから | 予定から数えられるぶん（本数・1本目の材料）だけ。部材は「未記録」 |

**空欄と0を区別する**（§9.231）——記録が無い段取りの部材欄を空にすると
「0本」と見分けがつかない。「未記録」と字で書く。

記録と予定の行は `detail.stopId` で結ぶ。**時刻で当てない**——同じ日に2回組むと
どちらか分からない。古い記録（idを持たないもの）は結ばない＝「未記録」として
出す（嘘の結び付けを作らない）。

段の器は**常に出す**（「全体」のボタンだけ設備を選べるときに出す）——器ごと
消すと、自設備固定の端末から刃組一覧へ行けなくなる。

## 部材は大きい寸法から並べる

`Object.keys` は数字の鍵を**小さい順**で返すので、そのまま先頭3つを出すと
**いちばん大きい寸法が「ほかN種」へ隠れて**いた（実測で 100 が隠れた）。
用意する側は大きいものから積むので、隠れてよいのは小さいほうである。
網を書いていて気づいた。

「種類×数」は**種類の数と本数の両方**を言う（`100×2 50×1 …（4種 8本）`）
——1種10本と10種1本ずつでは、段取りの手間がまるで違う。

## 網は「実際に描かせて」見る

列の定義だけ見ても、切り替わらなければ意味が無い（§9.306）。切り替わる・
タイムラインは伏せる・行が出る・「これから」「未記録」と書く・個別へ戻せる、
までを画面で見る。実際に描かれた行:

```
2026-09-17 ／ 2直 ／ BS1601刃組み ／ これから ／ 未記録×9 ／ — ／ —
```
