# §9.155 子ロットが最新データから消えただけのときは差異表を出さない

利用者の指示:「データ取得失敗(元データなし)の場合は結局適用自体できないので、
元データがない場合は差異表示はなくてよいです。最新データから消えているので
作業済みである可能性を示唆してくれるだけでよいです。」

差異が**すべて `removed`** のときは、表ではなく1行の知らせにする。
適用できるものが1つも無いのに表を出すと、読んで比べる手間だけが残る。
残す操作は「確認した」の1つ（＝もう知らせなくてよい）。
