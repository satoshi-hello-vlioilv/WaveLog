# §9.295 作業以外の行の題名は「色・札・帯」と「位置・揃え」を選べる

設計書（`SCHEDULE_MODE_DESIGN.md`）に節が書かれないまま、`CLAUDE.md` の
規則としてだけ残っていた回。本文は下の「守ること」。

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **作業以外の行の題名は「色・札・帯」と「位置・揃え」を選べる**（§9.295 ①、
  利用者の指示「作業スケジュールの設備停止の部分に色やバッジみたいなデザインを
  付けたいのと、左寄せにしたり文字の位置を変更できるようにしてほしいです」）:
  **新しいマスタを作らない**——`行表示マスタ`に`[題名の見せ方]`（文字だけ／
  バッジ／帯）・`[題名の位置]`（内容の列／行いっぱい）・`[題名の揃え]`
  （左／中央／右）・`[題名に時間]`を足しただけ。**色は既にある`[色キー]`を
  そのまま読む**（`--rs-fg`/`--rs-bg`/`--rs-line`）——札のために色表をもう1つ
  作らない。効く順も今までどおり「分類 → 区分 → 既定」で、答えるのは
  `rowStyleOf()`の1箇所（§9.163。紙で判定をやり直すと画面と食い違う）。
  **語彙はサーバーが答える**（`ROW_TITLE_*`＋`/api/schedule/row-style-master`の
  `titleLooks`等）。**作業の区分には欄を出さない**（束ねた題名のマスが無いので、
  出しておいて何も起きないのは押せないボタンと同じ・§4）。
  **札／帯にしたら行の地は塗らない**（同じ色が2箇所に出ると、どちらが印なのか
  読めなくなる・§3）——印は行に貼り、地を消すのはCSSが受ける。
  **画面の揃えは`@layer utility`の`.al-*`で当てる**（§9.239 ④）——
  `WL.columnAlign.applyCells()`があとから`.al-l`を貼るので、素のCSSで
  `text-align`を書いても**必ず負ける**（実測: 紙は中央なのに画面だけ左）。
  **保存は触っていない設定も必ず運ぶ**（§9.212 ②／§9.113。同じ形で5度目）。
- **区切りの行間は「日付が変わる行」に効く**（§9.295 ②、利用者の報告
  「区切りの行間の余白は変更しても変化がない」「行間（上下）に変更で区切りの
  行間の方も一緒に変化してしまう」）: §9.294 ③は**まとまりの帯にだけ**
  効かせていたが、帯が出るのは「まとめ」を日付にしているときだけで、
  **既定（まとめない・日付ごとにページを分ける）の紙には帯が1本も無い**
  ——選べるのに一度も効かない設定だった（§4）。印（`is-day-start`）は
  **行そのもの**に付け、日付は**紙のページ分けと同じ`workDayKey()`**で数える
  （別に数えると「区切りの空きは入ったのに、その行は前の日の紙に載る」）。
  **効く場面が無いときはそう書く**（`dayBreaks===0`。日付ごとにページを
  分けていれば1枚＝1日なので変わり目が無い）。**網はまとめない紙で見ること**
  ——帯がある紙で測ると、直す前でも通る。
- **枠線なしでも「区切り」と「設備停止」を見分けられるようにする**（§9.295 ③、
  利用者の報告「枠線なしの時に日付の区切りの色と設備停止の色が一緒になって
  しまう…差をつけてわかりやすくしたい」）: どちらも`--surface-2`だったので、
  格子を消すと同じ帯に見えた。区切りは**一段濃い面＋上の太い罫**、設備停止は
  **ふつうのロットとほぼ同じ地**（利用者の指示）。**区切りの罫は枠線を消しても
  残す**——消しているのは格子であって区切りではない（§9.237 ①でも面と記入欄の
  下線は残すと決めてある）。設備停止の見分けは**区分の札と題名の見せ方**が
  持つ（§3。色だけで伝えない）。**網は設備停止の行が在る場所で比べること**
  ——無い時点で比べると空同士が一致して何も確かめない（実際に踏んだ）。
