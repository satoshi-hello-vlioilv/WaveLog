# §9.484 並べ替えを持たない表でも「④並べ替え」の段は出し、持たない理由を書く（利用者の指示）

索引: [決定記録](README.md)

## 経緯

利用者の指示「作業スケジュール一覧側も、並び替えは使わせない・見せない理由を答えてもらいたい」。
§9.187 以来、並べ替えを持たない表（`features.sort:false`＝作業スケジュール表・データ一覧・実績データ・操業データの
紙）では④の段を**黙って消していた**。仕掛一覧と見比べると「足りない」に見え、理由はどこにも書いていなかった
（CLAUDE.md 画面の基準4「できないことは、できないと書く」に反する）。

## 理由（作業スケジュール表）

作業スケジュールの行の並びは**作業する順＝時刻の一本道**で、開始・終了の時刻は上の行から順に積んで決まる
（§9.176）。列の値で並べ替えると、どれから作業するかも、表に出ている時刻の意味も崩れる。順番は行を掴んで
動かす（`reorderableEntry()`・§9.201）——こちらは時刻も一緒に積み直す。

## 決めたこと

- `features.sort:false`でも④の段は出し、**操作の欄は置かず理由の1文だけ**を書く（`sortOffHtml()`）。
- 理由は表ごとに違うので**口が言う**（`sortOff`）。作業スケジュール表とデータ一覧（見出しで並べ替える作りを
  持たない）は理由を書いた。実績データ・操業データの紙は理由をコードから確かめられなかったので、決め付けず
  既定の1文（「並びは画面が決めています」）のまま。

## 網
