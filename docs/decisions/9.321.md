# §9.321 見本（デモ）は「いまの入力の決まり」に乗せる

設計書（`SCHEDULE_MODE_DESIGN.md`）に節が書かれないまま、`CLAUDE.md` の
規則としてだけ残っていた回。本文は下の「守ること」。

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **見本（デモ）は「いまの入力の決まり」に乗せる**（§9.321、利用者の指示
  「デモデータを最新のデータのパターンに合わせてアップデートしてください。
  ステップ刻みのあるデータや、小数点の桁数が変わるものを想定しています」）:
  決まりを1つ足したら**見本も一緒に直す**——見本は「紙に入るか」を確かめる
  道具なので、現場では絶対に出ない値が並ぶと確かめる意味が無くなる
  （§CLAUDE 6「見本が嘘をつく」）。効くのは2つで、**どちらも見本が破っていた**:
  **刻み**（`MEASURE_ROUND`。ラテラルボー・テレスコープ・巻ずれ・揃いの値が
  0.5刻み・切り上げ）と、**器で決まる桁**（`MEASURE_DEVICE_DIGITS`。
  `settings.deviceOf`を持たせないと、器で桁が決まることを見本では一度も
  通らない）。**器は準備の「板厚測定器／板幅測定器」と揃える**——ここだけ
  別の器にすると「ノギスで測ったのに3桁」と見本が言う。
  **統計（`stat.*`）は見本の測定値から数える**（`_fill_stat_samples()`）——
  手で書いた表を別に持つと、測定値を直したときに**同じロットの統計が2通り**
  になる（実測: 板厚MINが候補の見本`0.298`／紙`0.296`）。
  **`sample_for()`はその項目の刻み・上下限・小数桁に乗せる**——「見本の値を
  入れる」は**そのまま欄へ入る**ので、外れた値だと欄を離れた瞬間に丸められ、
  見本と記録される値が食い違う。**範囲と刻みが両立しないときは範囲を優先**
  （欄は範囲の外を受け付けないが、刻みは丸めるだけ）。
  固定は`tests/test_rbsample.js`（**数を網へ書き写さず`WL.measureRound`／
  `WL.measureDevice`に聞く**——写すと決まりを直したときに網だけが古い約束の
  まま残る）と`tests/test_rbcells.py`（統計の導出・`sample_for()`）。
  **網は「値が入っている」を見ないこと**——刻みから外れた値でも通る。
  **丸めを実際に当てて値が1つも変わらないこと**で見る。
