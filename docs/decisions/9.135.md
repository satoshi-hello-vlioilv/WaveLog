# §9.135 カードの規格は「可能な限り粗いグリッド」

> 「グリッドが細かいと整列感を出しにくいはずです。…可能な限り粗いグリッドで
> 組む思想とし、必要な範囲で細かいグリッドにしなければいけないという考え方で
> あれば問題ありません」

**最初に横12×縦4を提案したが、これは誤りだった。** 12列だと左端の候補が12通り
できる。カードがそろって見えるかどうかは「候補が何通りあるか」で決まるので、
これは整列感を捨てて余白の少なさを買う設計になっていた。

**外側（カードの配置）は 横4 × 縦3**（1マス 437×307px）。左端の候補は4通り、
上端は3通りだけ。実測に当てると割り切れる:

| 画面 | 割り付け |
|---|---|
| ② | 根拠 `1×3` ＋ 項目リスト `1×3` ＋ 測定表 `2×3` |
| ① | 基本情報 `1×1` ＋ 品質規格(タブ) `1×1` ＋ 幅分割の図 `2×1` ＋ 設定 `2×2` |
| ③ | 確認シート `4×1` ＋ 記録の壁 `4×2` |

**カードの形は6種類だけ**: `1×1` / `2×1` / `1×2` / `2×2` / `4×1` / `2×3`
（主役は `4×3`）。

**細かくするのはカードの内側だけ。** ①の設定カードの中が5列でも、外から
見えるのは`2×2`のカード1枚なので画面はがたつかない——**器の枠が視線を止める**。

**マスが余ったとき**は、① タブの裏の情報を出して埋める → ② カードを1段小さく
する（`2×2`→`2×1`）→ ③ それでも無理なら余らせたままにする、の順。
**列を増やして詰めるのは禁止**（今回の反省そのもの）。

固定するのは3つ: カードの形が規格6種の外に無いこと・左端が4通り以内かつ
上端が3通り以内であること（これが「そろって見える」の実体）・空きマスが
無いこと。
