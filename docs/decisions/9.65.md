# §9.65 ボタンの基本作法を全体の土台に置く

「押しても反応が無いように見える」との指摘を実測で確認したところ、
- 左ナビ7項目に`cursor:pointer`が無い(押せるように見えない)
- **押した瞬間の反応(`:active`)が全画面のほぼ全ボタンで未定義**
  (作業スケジュールだけで606個)

部品ごとに書くと必ず漏れるため、リセット部で全ボタン共通に宣言する。

```css
button{cursor:pointer}
button:disabled,button[aria-disabled="true"]{cursor:not-allowed;opacity:.5}
button:not(:disabled):not([aria-disabled="true"]):active{filter:brightness(.92)}
button:focus-visible{outline:2px solid var(--focus);outline-offset:2px}
```

**押下フィードバックに`transform`を使わないこと**。
`.sc-split-collapse-btn`のように既に`transform`で位置合わせしている部品の
配置を壊す。`filter`なら配置に影響しない。

記号だけのボタン(説明が無いと用途が分からないもの)は全画面で0件になる
まで`title`を補った。判定は「表示文字に日本語・英数字を含まない」で行う
(「開く」「前へ」のような短いが自明なラベルまで機械的に拾わない)。
