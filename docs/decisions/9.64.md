# §9.64 ダッシュボードの既定を「稼働状況」にする

開いた直後は集計条件が未設定で「対象データがありません」になりがちで、
何のための画面か分からなかった。既定を**いまの稼働状況**にする。

- **稼働状況**(既定): KPI4枚(稼働中の設備/残っている予定/遅れている設備/
  本日の完了)、設備ごとの状況表、直近の実績。データ源は
  `/api/schedule/overview`(俯瞰ボードと同じ1往復)と端末内の測定データ
  (`ensureData()`と共用)。見るべきものが上に来るよう、遅れ→稼働中→
  残り件数の順に並べる。
- **自由集計**: 従来の期間・軸・系列・指標の集計をそのまま残す。
