# §9.487 刃組ガイダンスの両端（OS端・DS端）も押せば拡大図——シートの側の残りは「隙間」でなく押さえる量（利用者の指示）

索引: [決定記録](README.md)

## 経緯

利用者の指示「刃組ガイダンスで、クリックしたら拡大図が出て非常にわかりやすいのですが、両端の部分については
出せてなかったので同じように拡大図を搭載して表示できるようにしてください。」

§9.463 で端の区間を重ねる的（右の端部の表と一緒に光る）にしたとき、「押しても拡大図は開かない」と決めていた。
理由は記録に無く、拡大図の側（`zoomFigure()`）には端の区間の作り（刃が片側だけ・反対は有効幅の端）が
§9.413 から在った——**描ける物を押せなくしていただけ**だった。§9.463 の「開かない」を撤回する。

## 決めたこと

- 模式図の端の的（`bs-ehit`）も、断面図の端の面（`.bs-t3z[data-end]`）も、押せば拡大図。指のカーソルも出す。
  `bs-ehit`の名は「連動先が右の端部の表」の印として残す（光らせる先が違うだけで、押す道は同じ）。
- **行は記号と軸の2つで引く**（`zoomRow()`の1箇所）。端の行は上下軸で組み方が違うと記号が
  `OS上`／`OS下`へ分かれる（`endRows()`）が、的は右の端部の表と連動するため`OS`のまま名乗る。記号だけで引くと
  分かれた端では1つも当たらない。
- 端の字は呼び方（`sideWord()`・§9.472）で出す。鍵の`OS`／`DS`は素のまま。
- **シートの側の端の残りは「隙間」ではない**（§9.456）。スペーサーを基準面から敷き詰め、反対の端は
  フローティングシートが押さえるので、残りは**押さえる量**——拡大図では**塗らず破線の枠だけ**、
  **軸の端の側**（刃から遠い側）へ置き、「シートが押さえる」と書く。足元の一言は「フローティングシートが
  押さえる端（押さえる量・押さえ代まで）」。基準面の側の残りは今までどおり「隙間」（0が正・§9.441）。
