# §9.593 マスタ管理を全幅の画面にする——左のメニューを伏せ、ヘッダーの左端に「◯◯へ戻る」、マスタの一覧は平らな行と「マスタを探す」（7案→組合せ7案から C4・利用者の指示）

索引: [決定記録](README.md)｜前: [§9.592](9.592.md)｜関係: [§9.264](9.264.md)・[§9.250](9.250.md)・[§9.266](9.266.md)・[§9.122](9.122.md)・[§9.471](9.471.md)

## 経緯（利用者の言葉）

> マスタ画面はマスタ画面だけで2ペインの左にマスタのリストを持ってこないとかなり使いづらい状態なので、狭くなっている印象で
> 表示のみだも感じます。マスタボタンを押したら、「戻る」ことができるボタンをメニューにつけてマスタリストもわかりやすく再構成して
> 表示し、測定メイン画面が出るときのようにマスタ編集中に不要なメニューは出ないような工夫を入れてエリア全体を活かせるように
> マスタ画面の全体画面をわかりやすく使いやすい形に作り変えてください。

## 4. 決めたこと

1. **全幅と戻るは画面が名乗る**（`registerView({focus:true,back:true})`）。答えるのは`enterView()`の1箇所（`base.js`）——
   `focus`は`body.view-focus`を立て、左のメニュー・つまみ・使用設備の案内を伏せる（`90-state.css`の mode 層）。
   `back`はヘッダーの`#viewBack`に「◯◯へ戻る」を出す。戻る先は**入る直前に選ばれていた左メニューの行き先**
   （`enterView`が選択を外す前に控える・`paintViewBack()`）。同じ画面へ入り直しても（例: 更新者IDから接続状況）控えは変えない。
   控えが無いとき（起動の直後に開いた）は左メニューの先頭。左のメニューを伏せた画面から出る道はこの1つなので、必ず出す。
2. マスタ管理で伏せる札は**現場段取り**と**使用設備**（ラインの段取りの話でマスタの編集に効かない）。**モードの札は残す**
   （書けるか・書けないかを言う）。
3. マスタの一覧は**平らな行**（30px・`--ctl-h-sm`）。群は細い線で区切るだけで、行に枠を付けない（枠の中に枠を作らない）。
   選んでいる行は左の帯（青緑）と淡い面と太字。**1文字の印（「設」「刃」…）は外した**——名前の頭の字の繰り返しで
   同じ情報を2つ出していた。印を持たせていた定義の`icon`も消した（`master-defs.js`の30本・内部データの定義）。
4. **マスタを探す**（`#masterMaintFind`）: 名前の一部で、**畳んだ群（内部データ20・移行済み）の中まで**探す（探している間は畳みを効かせない）。
   字の畳み方は`NFKC`＋小文字。Enter で1つ目を開く。Esc は**探す字だけ**消す（1回の Esc で閉じるのは1枚・§9.471）。
   当たらないときは「『◯◯』に当たるマスタはありません」と字で言う。打つたびの描き直しは`WL.base.onTyped()`（変換中は待つ）。
5. 一覧の器の幅の式は印のぶんを引いた（`8.4em + 56px`）。足りなければ今までどおり`fitMaintNav()`が測って広げる（§9.250 ⑨）。
6. `.mm-panel`は外の余白と枠を持たない（ヘッダーの下からそのまま始める）。狭い窓（900px 以下）の決まりは`@media screen and`へ。

## 5. 踏んだ罠

- 撮影の見本で左を伏せたとき、`grid-template-columns:0 0 1fr`のまま`aside`を`display:none`にすると、**本文が幅0の
  1列目へ入る**（格子は消えた子の席を詰める）。列は`minmax(0,1fr)`の1本にする（実装も同じ）。
- 戻るの字は帯の部品（30px）で題の`#fileName`は基準線そろえなので、並べると題が上へずれて見えた。戻るが出ているときだけ
  `.hd-context`を縦の中心でそろえる（`:has(>.hd-back:not([hidden]))`）。
- `.mm-nav button`の寸法は`10-roles.css`の「標準」の束（36px）から配られていた。行の高さを変えるために束から外し、
  寸法は`50-master.css`の1箇所で書く（同じセレクタの同じプロパティを2つのファイルに書かない・`test_csslint`）。
- **網が左メニューを直に押していた**（通しで16本・`page.click('#openSchedule')`など）。全幅の画面の中からは押せない（人も押せない）。
  `tests/lib/wait.js`の`nav(page,sel)`／`leaveFocus(page)`で「戻る」を通してから押す。出た先の画面も読み込みを始めるので、
  読み込み中の表示を見張る網（`test_waiting`）は**見張る前に**出ておく。置き換えは正規表現で行い、`[data-db-key="…"]`
  （中に二重引用符）と`'#'+nav`（組み立てた名前）を1回目で取りこぼした——通しで残りを拾った。
