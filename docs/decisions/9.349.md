# §9.349 文書が指す名前と撮る道具の選択子は実在させる。関数の中の import は増やさない

`docs/REVIEW_2026-09.md` §6.3 の 3-20「文書と道具の腐りを網へ」と
3-21「関数の中の import に上限を」。どちらも**振る舞いを変えない**。

## 何が起きていたか

3-11（§9.335）で「規則」と「経緯」は分けたが、**構成の説明
（`docs/ARCHITECTURE.md`）と撮る道具（`tests/visual/capture.js`）は誰も
見ていなかった**。

- `ARCHITECTURE.md` が `名前` で指すファイルのうち、リポジトリに無いものが
  **11**。内訳は、`/` で始まる URL（`/css/app.css`・`/api/ready.js`）3、
  実行時に作る物（`boot_status.js`・`instance.json`・`config/local.json`）3、
  旧名の経緯（`masters.py`・`launch_guard.py`）2、scratchpad の道具 2、
  連結した束の名前（`app.css`）1。**本当に腐っていたものは無かった**が、
  「無い」と「無くてよい」を見分ける物差しが無かった。
- `capture.js` の押せない選択子は **6**（`#openSplit`・`data-infotab`×3・
  `data-lefttab`×2）。測定画面が3段（§9.123）になり条の設計がカード
  （`#splitCard`。§9.215）になったときに消えた札を、道具はそのまま押して
  いた。REVIEW の「14」は撮った回の「(押せず)」の数で、**時間切れと実在しない
  を混ぜた数**——静的に見ると 6。
- `pick_tests.py` の説明文に「コミット前は通しを回すこと」が撤回後も残っていた
  （CLAUDE.md「作業の進め方」A と食い違う）。
- 関数の中の `import` は 3-2（§9.329）で読み込み時の輪を 28→0 にしたあと、
  3-10 で **210→230 に増えた**。関数の中の import は輪を**隠す**道なので、
  増えるほど 3-2 が戻る。

## 決めたこと

1. **文書が指す名前は実在する**（`test_docindex`）。`ARCHITECTURE.md` の
   `` `名前.拡張子` `` を全部拾い、リポジトリ（パスでも basename でも）に
   無ければ落とす。`/` で始まるものは URL なので見ない。**無くてよい名前は
   `ARCH_ALLOW` に理由つきで**（`test_dblayer` の `DEEP_ALLOW` と同じ作法。
   8件）。除外した名前が実在するようになったら「除外を外せる」と注で言う。
2. **撮る道具の選択子は実在する**（同じ網）。`'#…'`／`'[data-…="値"]'` の
   文字列を拾い、`#id` は `id="…"`・`id:'…'`・`.id='…'`・`getElementById`
   のどれかで、`data-x="値"` はその文字列そのもので、`static/js`＋
   `templates` に無ければ落とす。`${…}` を含む（実行時に決まる）ものと
   `data-db-key`（値はマスタの行）は見ない。**押す口（`click(`）の引数だけ
   拾うと、配列に並べて回す形の 2 件が素通りした**——文字列そのものを拾う。
3. **関数の中の `import` は上限固定・下げる方向だけ**（`test_importlint`。
   `tests/fixtures/import_baseline.json` にファイルごとの件数。230箇所／43本）。
   減ったら `--update` で下げる。上げる更新は断る。**理由が書けるものは
   その行に `# 遅延: 理由`** と書けば数えない——数から外す理由が行に無いと、
   次に読む人が消してよいか判断できない。
4. `capture.js` は3段の札（`#measureSteps [data-mstep]`）と作業の札
   （`[data-worktab]`）を押し、条の設計はカードをスクロールして撮る。
5. テストが作業ツリーの根へ置く画像（`sched_balanced.png`・`sched_cat2.png`）は
   `os.tmpdir()` へ。`git status` に置き土産が出ていた。

## 網が素通りしないこと

- `ARCHITECTURE.md` に無い名前を1つ注ぐと1件で落ちる。HEAD の `capture.js` を
  渡すと 6 件で落ちる（直したあとは 0）。どちらも網の中に自己検査として持つ。
- `test_importlint` は関数の中の import を1つ注いだ仮ファイルで「数える／
  印の行は数えない」を毎回確かめる。

## 触っていないもの

- `measure-view.js` の `bindInfoTabs()` は `[data-infotab]` を探すが、その札は
  もう無い（呼び出しは残る）。**製品側の死んだ関数は 3-22 の対象**で、
  ここ（文書と道具）では触らない。
- `設備停止分類マスタ` の網の屑 39 行（§9.348 で記録）も同じく別。
