# §9.411 起動モーダルで「更新を当てているか」を言い分ける（利用者の指示）

## 利用者の言葉

> start.vbsから起動したときに、起動モーダルが出ますが、**アップデートなども
> 実施してくれると思うので、実施しているときとしていないときの違いも分かる
> ように**、改良してほしいです。**デザインも新たにゼロから一新したいので
> モーダルのデザイン案を5案出してください。**

## 起きていること（利用者の読みは当たっている）

毎日の起動は**刻印**（`ready.json`・§9.225）を見て、合っていれば確認を飛ばす。
合わなければ `update.bat` と**同じ処理**（`setup_check.run()`）をその起動で
まとめて行う——部品の導入・**バイトコードの作り直し**・旧DBの取り込み・
待機画面の写し・刻印の書き直し。バイトコードの有無は実測で
**app読み込み 1,168ms ⇔ 211ms（5.5倍）**なので、当たっている起動は目に見えて
長い。

ところが待機画面に出ていたのは段の名前だけで、しかも言い方が逆だった:

| そのときの実際 | 出ていた字 |
| --- | --- |
| 更新を当てている（数秒かかる） | 「必要な部品が揃っているか確認しています」 |
| 何もしない（飛ばす） | 「確認済みです（update.batで確認しました）」 |

**どちらも「確認」としか言っていない。** 待たされている人には、遅いのが更新の
せいなのか、共有が遅いのか、固まったのかが読めない。

## 直した形

進捗（`boot_status`）に**3つしかない状態**を足した。分からないうちは空——
**推測して「していない」と言わない**。

| 値 | 意味 |
| --- | --- |
| `''` | まだ分からない／その段は更新と関係ない |
| `skip` | 前回の確認のままで済んだ（飛ばした） |
| `update` | いま確認・導入・作り直しをしている |

`update` のときは**何が変わったから確認するのか**も一緒に渡す。材料は
`ready.mismatch()` が既に人の言葉で持っていた（「アプリの版（2.305.0 →
2.306.0）」「Pythonの場所（… → …）」）ので、**書き足さずにそのまま運ぶ**。

さらに、確認の途中経過（`setup_check.run()` の `say()`）を**ログと同じ言葉で**
画面へも流す。ここは何秒もかかる段なので、黙っていると止まって見える。

待機画面は**同じ場所で言い分ける**（出たり消えたりする帯を2つ持つと、
どちらが今の話か分からない）:

| 状態 | 帯 |
| --- | --- |
| `update` | **更新を反映中**（琥珀）／`変わったもの: アプリの版（2.305.0 → 2.306.0）` |
| `skip` | **更新なし**（中立）／`前回の確認（update.bat）のまま起動します` |

色だけで伝えず、**字にも分類名を書く**（§CLAUDE 3）。

## デザイン5案

作り替えの案は [`docs/mockups/boot-modal-5.html`](../mockups/boot-modal-5.html)
に**実物と同じ配色・同じ10段階**で描いた（見本なので製品には載らない）。
上の切り替えで **更新なし／更新を反映中／起動できなかった** を全案いっぺんに
見比べられる。

| 案 | 骨格 | 向いている場面 |
| --- | --- | --- |
| 1 | ステータスカード（今の作りの正統進化） | 見え方を大きく変えたくない |
| 2 | タイムライン（**済んだ段は1行に畳む**・更新は節として挿し込む） | どこで待たされているかを最短で読ませたい |
| 3 | 2ペイン（左＝アプリの顔／右＝進み具合） | 起動が数秒かかる端末 |
| 4 | ミニマル（既定は1行・「詳しく」で開く・更新時は自分から開く） | 起動が1〜2秒で終わる端末 |
| 5 | ダッシュボード（版・更新・経過・ポート＋**所要秒つきの表**） | 起動の遅さを追いかけたい |

どの案も次の3つを必ず満たす形で描いてある（採用案の実装もこれを守る）:

1. 10段階の進み具合（サーバー6＋ブラウザ4）が読める
2. **更新を当てているか／当てていないか**が同じ場所で読み分けられる
3. 失敗したときに「次に何をすればよいか」がその場に出る

**採用が決まるまで、いまの意匠のまま①の機能だけ載せてある**——選ぶのを
待つあいだ「どちらか分からない」状態を続けないため。
