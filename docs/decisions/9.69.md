# §9.69 「内容」欄の既定の組み立てが取りこぼす・二重空白になる

タイムラインの「内容」欄は、設備ごとに項目を選んでいればその順で並べ、
選んでいなければ既定の組み立て(ロット№ + 用途名 + 材質-調質)を使う。
この**既定側だけ**に2つの取りこぼしがあった。

- **alias名しか見ていなかった**。`e.detail?.purposeName`を直接読んでいたため、
  生カラム名「用途名」でしか持っていない予定では空欄になる。項目を選んだ
  ときの経路は`contentValueOf()`(alias名・生カラム名の相互読み替え、§9.22)を
  通っており、既定だけが同じ取りこぼしをしていた。
- **欠けた項目の分が二重空白になる**。テンプレート文字列
  `` `${lotNo} ${purposeName||''} ${material}` `` は、用途名が空でも空白を
  2つ残す。`.trim()`は両端しか削らないので「L0001␣␣A5052」と出ていた。

値の取り出しを`contentValueOf()`へ揃え、空の項目は詰めて繋ぐようにした。
