# §9.157 ②の条の設計カードを最適化し、帯の注意書きで基本情報を潰さない

#### カードの中の見出しは題の1つだけ

利用者の指示:「2枚目の条の設計（幅の割り付け）の部分も表示を最適化して
ください。」

実測すると、カードの題「条の設計（幅の割り付け）」の下に群の見出し
「条の並び（母材幅比率表示）」があり、**カードの中に図は1つしかない**のに
題が2段あった。さらに条数が `#splitGrid` の状態行（「3ロット / 9条に分割」）と
`.split-visual-count`（「9条」）の**2箇所**にあった。
群の見出し（`.split-visual-head`）ごと廃止し、「母材幅の比率」という但し書きは
**操作の案内と1文にまとめて図の下**へ置く——読むのは図を見たあとなので、
上に置くと図より先に目へ入る。

#### 余りは図へ渡す

カードの下に**45pxの空き**が残り、掴んだ条の説明欄（`#splitVisualDetail`）が
**空のまま16px**場所を取っていた。説明欄は中身が無ければ畳み、
`#splitCard` を縦のflexにして `.split-visual` が余りを使い切る
（帯 88px→186px）。**掴む的は大きいほどよい。**

**`.split-visual-row` の `margin-top` は残すこと**——目盛りの数字
（`.split-visual-tick-label` が `top:-15px`）の置き場で、詰めると
1000/1250/1500 の数字が図の上で切れる。

**網は器でなく中身の下端で測る**——`.split-visual` は `flex:1` で必ず器の
底まで伸びるので、直下の子の下端を見ると「余り0」と出て**素通りする**
（この網を書いたときに実際に素通りし、88px固定を注ぎ込んでも1件しか
落ちなかった）。

#### 帯の注意書きは件数だけにする

利用者の指摘:「進捗フロー表示欄の部分で警告表示(未測定が 9項目あります
（母材・揃い/肉厚/長さ・板厚 ほか）。)が載ると、基本情報が幅が圧縮され
見切れます。」

帯（`.measure-bar`）は1本しかなく、注意書きと文脈（ロット・製品・測定表の形・
判定公差）が場所を分け合う。**どの項目が未測定かは③の確認表が1行ずつ
出している**ので、帯は件数だけ（「未測定 9項目」）にして名前は `title` へ回す。

**縮む順番も決める。** 以前は両方とも `flex-shrink:1` で等しく縮んだ。
文脈は「この画面が何を測っているか」そのもので、見切れると別のロットと
取り違える。ただし **`flex:0 0 auto` で固定してはいけない**——狭い窓では帯
そのものが溢れる（1600px幅で横+52px、表示サイズ大で+142px。`test_fit` が
検出）。`flex-shrink` の比（注意書き100 : 文脈1）で優先順位を付ける。

固定は `tests/test_splitlive.js`・`tests/test_msteps.js`。
