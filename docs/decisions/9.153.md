# §9.153 子ロットデータの更新表示を「子ロットの内訳」カードへ移す

利用者の指示:「子ロットデータに更新がある場合の表示は、条の設計 —
子ロットの内訳の方のカードに表示させて。」

更新の知らせ（差異表・履歴）は「条の設計（幅の割り付け）」カードの
`#splitGrid` に出ていた。あのカードは**図と操作の面**で、状態は1行しか
持たない。差異表が載ると図が押し下げられ、並べ替えの最中に器が動く。

置き場は `#splitDetailCard` の先頭へ新設した `#splitDataSections`。
`refreshSplitDataSections()` が「更新あり」と「履歴」の2本を組み立て、
**中身が無ければ器ごと畳む**（`hidden`）。

`refreshSplitStatusPanel()` は**状態の帯より前**にこれを呼ぶ——`#splitGrid`
が無い経路（読み込み中など）でも必ず描き直されるようにするため。
