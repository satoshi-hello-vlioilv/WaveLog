# §9.436 読み込みの見せ方は29種・選ぶのは共通設定の広い盤（利用者の指示）

索引: [決定記録](README.md)

利用者の指示:

> 読み込みの見せ方をマスタに持ってきて、広いエリアでわかりやすく選べるように
> してください。https://connoratherton.com/loaders
> ここから移植しているので元は28種類くらいあるはずです。水の波紋のような
> ものも使いたいです。

添付は「表示」バッジの3つめの節（6種が縦1列・見本は18px四方）。

---

## ① 先に測る——「狭い器に29種は入らない」が数で言えた

直す前に**選びやすさの物差し**を作って、いまの値を測った
（`scratchpad/eval_loader.js`。利用者の常用環境に合わせて 2160×1440 の
125% ＝ 1728×1152 で測る）。

| 測ったもの | 前（「表示」バッジの節） |
| --- | --- |
| 選べる種類 | **6** |
| 選び場の寸法 | 210 × 651 px |
| 1種あたりの札 | 9,698 px²（210×46） |
| **見本そのもの** | **330 px²**（約18×18） |
| **札に占める見本の割合** | **3.4 %** |

**3.4 %** がこの画面の急所だった。§9.200「選ばせるものは選ぶ前に見える」で
札へ見本を置いたのに、**置いた見本は札の 1/30 しかない**。名前（「球が3つ
（順に）」）のほうが 20 倍大きく、実際には名前で選んでいた。

さらに、**29種はこの器に入らない**。実測で1種あたり 50.4px（6種で 651px の
メニューが、1種に減らすと 399px になった＝252px ÷ 5行）。29種なら

```
399 − 50.4 + 50.4 × 29 = 1,810 px   ＞ 画面の高さ 1,152 px
```

**658px はみ出す。** 器を変えずに種類だけ増やすと、29種を縦スクロールで
数えることになる（探させない・CLAUDE §2 に反する）。
**だから「マスタに持ってきて」は、好みではなく寸法の要求**だった。

## ② 移植は28種すべて。写さなかった2種は理由を書く

loaders.css（Connor Atherton／MIT）の配布物には 30 のクラスが在るが、
**公開ページに並ぶのは 28 種**（利用者の「28種類くらい」はこれ）。
その 28 種を全部写した。残り2つは写していない:

| 写さなかったもの | 理由 |
| --- | --- |
| `ball-spin-loader` | 元のCSSが `> span` に位置を書き `> div` に玉を描いており、**配布物のままでは何も出ない**（しかも `background:green`） |
| `ball-scale-random` | `ball-scale-multiple` と見分けが付かない（同じ輪が3つ広がるだけで、違いは数pxのずれ） |

**水の波紋**（利用者の指示）は `ball-scale-ripple`（輪が1つ）と
`ball-scale-ripple-multiple`（輪が4つ次々に）。族「波紋」の先頭へ置いた。

### 写すときに直した4点

1. **色は `currentColor`**（元は `#fff` 固定で、地が白の器では消える）。
2. **寸法は `--wl-ld` の1つから作る。px は1つも写していない。**
   元は 15px/35px/50px の決め打ちで、13px の小さな器にも 44px の見本にも
   同じ物を置けない。すべて `--wl-ld` に対する比へ直した
   （例: `ball-spin-fade-loader` の半径は `--wl-ld * .36`、
   45°の位置は `.36 × cos45° = .2546`）。
3. **`@keyframes` の名前に `wl-ld-` の印**。元は `scale`／`rotate` という
   短い名前を**別々の中身で何度も**定義しており、1枚に束ねると後の定義が
   前を上書きする（§9.421 で踏んだ）。
4. **動きが `transform` を使う種類では、置き場所に `transform` を使わない。**
   元は器ごと `transform:translate(...)` で寄せている（`ball-triangle-path` は
   `translate(-29.994px, -37.509px)`）。中で `transform` を動かす種類と
   食い違うので、**寄せるのは `margin-left`／`margin-top`**（`left`/`top` は
   中央寄せに使い切っている）。

## ③ 踏んだ罠——祖先に型を付けると、見本を並べた盤で全部が化ける

§9.421 では型を `html[data-loader]` の**子孫**として当てていた。

```css
[data-loader="ring"]   .wl-ld > i:nth-child(1){ … }   /* 詳細度 (0,3,1) */
[data-loader="pacman"] .wl-ld > i:nth-child(1){ … }   /* 詳細度 (0,3,1) */
```

盤は `html[data-loader="pacman"]` の中に `[data-loader="ring"]` の見本を置く。
すると**1つの `<i>` に両方の規則が当たり、詳細度が同じなので後に書いたほうが
勝つ**——29種を並べると、どの札も「ファイルの最後に書いた種類」になる。
6種のときも同じ欠陥は在ったが、`ring` を先頭に書いていたため**たまたま
札のほうが勝っていて**、症状として出ていなかった。

詳細度で勝たせる（`.ld-scope[data-loader=x]` を足す）だけでは直らない。
**局所の型が値を書いていないプロパティ**（`ring` が触らない5枚目の `<i>` の
`position` など）は、祖先の型の値がそのまま残るため。

**直し方: 型の当て先を器そのものへ移した。**

```css
.wl-ld[data-ld="ring"]   > i:nth-child(1){ … }
.wl-ld[data-ld="pacman"] > i:nth-child(1){ … }
```

1つの器に当たる型は**必ず1つ**なので、入れ子でも混ざらない。型を変えたとき、
前の型しか書いていなかったプロパティは（前の型が当たらなくなるので）
`.wl-ld > i` の初期値へ正しく戻る。

器へ型を書くのは `WL.loader` の1箇所:

- `WL.loader.html()` … 作るときに**いまの型**を焼き込む。
- `applyLoader()` … `.wl-ld:not([data-ld-fixed])` を塗り直す。
- `data-ld-fixed` … 盤の見本。**いまの設定に引きずられない**。

`html[data-loader]` は**残してある**（画面全体の状態として読めるほうが
便利で、実害が無い）。ただし**見た目を決める鍵ではなくなった。**

### `<i>` は5つ→9つ

格子（`ball-grid-pulse`／`ball-grid-beat`）が 3×3 を要る。いちばん多い種類に
合わせて **9** にし、**数の答えは `WL.loader.SLOTS` の1箇所**が持つ。
使わない `<i>` はその型の規則が伏せるので、**型を変えても DOM は作り直さない**
（動いている最中に切り替えても飛ばない）。
`templates/index.html` が持つ静的な器（`#saveOverlay`）も9つへそろえた
——`applyLoader()` はDOMが組み上がる前に一度走るので、**「表示」の配線が
終わったところでもう一度当てる**（でないと静的な器だけ型が空になる）。

## ④ 盤の作り——29回の見比べを「族＋4〜5枚」に減らす

平らに29枚並べると、選ぶ側は29回見比べる。**形の族で束ねた**:

| 族 | 中身 | 一言 |
| --- | --- | --- |
| 輪・弧 | 5 | 回り続ける。いちばん静か |
| 波紋 | 4 | 中心から広がって消える |
| 球が並ぶ | 4 | 横1列で上下・伸び縮み |
| 球が集まる | 4 | 格子や円周に散る |
| 棒が並ぶ | 5 | 等幅の棒が伸び縮み |
| 道を描く | 4 | 決まった道筋をまわる |
| 形が変わる | 3 | 面そのものが裏返る |

どの族も 5 以下（短期記憶の範囲）。族の見出しには一言を添え、
**族を1つ選んでから4〜5枚を見比べる**形にした。
順は「静か → にぎやか」——業務画面に置いても落ち着いて見える族が先。

- **札の幅は中身から決めて規格へ**（CLAUDE §11）。いちばん長い名前
  「棒が5本（中から外へ・速い）」が1行で入る **168px** 固定。`1fr` で
  伸ばすと族ごとに幅が変わって列がそろわない。**余りは空白のまま**
  （列を増やして詰めない・CLAUDE §13）。
- **見本は 44px**（席は52pxで固定）。種類ごとに中身の高さが違うので、
  席を揃えないと名前の行がガタつく。
- **使用中は枠の色＋「使用中」の字の両方**（色だけで言わない・CLAUDE §3）。
  字は絶対配置なので、選び直しても札の寸法は**1pxも動かない**（§9.227）。
- `hint` には**元の綴り**（`ball-scale-ripple-multiple`）を出す。
  loaders.css のどれを写したかを画面から辿れる（CLAUDE §6 出どころ）。

## ⑤ 設定の持ち主は1つ、面は2つ——印を付ける役も1箇所

§9.421 の「入口は1つ」と §9.433 の「行き先を置く」は、**設定の持ち主を
1つにする**ための規則であって、面の数を1つに縛るものではない。
いま持ち主は `WL.loader` の1箇所のままで、面が2つある:

| 面 | 受け持ち |
| --- | --- |
| 「表示」バッジの3つめの節 | **行き先といまの値だけ**（押すと盤まで連れて行く） |
| 共通設定＞この端末 | **29種の盤**（実際に選ぶ） |

どちらの面も `WL.loader.setStyle()` を呼び、`wl:look-change`（§9.433）で
もう一方のいまの値が塗り直る。

**面が2つになると、印を付ける役も分かれたがる。** 分けると「盤では選んだ
ことになっているのに、バッジでは前のまま」が起きる。**`WL.loader.mark()` の
1箇所**にまとめ、`applyLoader()` からも、盤を描いた直後からも同じ関数を呼ぶ。

行き先の実体（マスタ画面のどの段へ飛ぶか）は**マスタ画面が名乗る**
（`WL.openLookSettings`）。`base.js` は口だけ持つ——土台に画面の知識を
書かない（§9.373 と同じ作法）。

## ⑥ 直したあとの値

| 測ったもの | 前 | 後 | 比 |
| --- | --- | --- | --- |
| 選べる種類 | 6 | **29** | ×4.8 |
| 1種あたりの札 | 9,698 px² | 17,763 px² | ×1.83 |
| **見本そのもの** | 330 px² | **2,073 px²** | **×6.3** |
| **札に占める見本の割合** | 3.4 % | **11.7 %** | ×3.4 |
| 一度に見える種類 | 6／6 | 26／29 | — |
| 「表示」の器の高さ | 651 px | **399 px** | −252 px |

**29種を入れたのに、狭いほうの器はむしろ 252px 縮んだ**——入らないものを
入れようとせず、置き場所を変えたため。

29種すべてについて「見える `<i>` が1つ以上ある／動きが止まっていない／
墨が 8px 角以上ある／見本の席からはみ出さない」を機械で確かめた
（`scratchpad/check_loaders.js`。`semi-circle-spin` だけは回転した正方形の
外接箱が席より大きく出るが、器が `overflow:hidden` で切るので見た目は収まる）。

網は `tests/test_uisize.js`（49件）。
