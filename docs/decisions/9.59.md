# §9.59 hidden属性が効いていなかった(表示崩れの共通原因)

「未同期0件なのに同期バナーが出続ける」等の表示崩れを調べたところ、
**hidden属性そのものが効いていない要素が7つ**あった。

原因はカスケードの出所。`[hidden]{display:none}`は**UAスタイルシート**に
あるため、作者スタイルで`.record-sync-bar{display:flex}`と書いた時点で
詳細度に関係なく常に負ける。該当は
`#recordSyncBar` `#homeDraftSyncWarn` `#filterQuickRow` `#listJoinChip`
`#dbBucketWrap` `#splitTabBadge` `#measureTypeChips`。

個別に`.foo[hidden]{display:none}`を足して回るのは必ず漏れるため、
リセット部で一度だけ`[hidden]{display:none!important}`を宣言する。
**本アプリは表示/非表示をhidden属性で切り替える**約束なので、この1行が
その約束を担保する。
