「\\nlmsrvngy03\工場内共有\検査データ\Records\アプリメンテナンス\WaveLog」から「\\nlmsrvngy03\工場内共有\検査データ\Apps\WaveLog」に
変更してください。
２）測定データ一覧の…改善したい案を5案程度出して検討させてください。」（２は案を出して選んでもらう・この記録では扱わない）
続けて「できるところから改善を進めていってください。」

B7〜9 は §9.556 で利用者へ渡した残件の一覧の番号:
- B7 共通設定の足元「更新者IDは画面右上の入力欄を使用します」——更新者IDは §9.276 ③ から入力欄ではない（押せる札）
- B8 図とタブのあいだの中身の無い灰色の帯（再起動待ちの札1つだけを入れる器・札が無いときも帯が残る）
- B9 保存する欄の無い段（アプリの更新）でも「共通設定を保存」が出る

## 決めたこと

1. **置き場の決め方は3段**（Python の`app_update.dir_choice()`・窓の`update.rs`の`update_dir()`が同じ順）:
   ① この PC の`config/local.json`の`update_dir`（この PC だけの上書き）→ ② 共有の設定（パス設定マスタの`update_dir`・
   画面「アプリの更新」の「置き場」の欄）→ ③ 既定（`DEFAULT_DIR`＝`\\nlmsrvngy03\工場内共有\検査データ\Apps\WaveLog`）。
2. ② は共有のマスタにあるので**1台で変えれば全 PC に効く**。窓は Python を起こす前に置き場を知る必要があり、SQLite は読まないので、
   Python が`config/update.json`へ控える（`remember()`・**変わったときだけ書く**・覚えることが無ければ作らない）。
   控えるのは段を開いたとき（`status()`）とハートビート（10分に1回・`remember_soon()`）。開いている PC は10分以内に控え、
   次の起動から新しい置き場を見る。`config`は版に入れない（入れ替えで消えない）。`config/update.json`は git に入れない。
3. 置き場の欄は**描き直さない**器に置く（状態の並びは届くたびに描き直すが、欄は打っている途中の字を消さない）。
   欄の添え書きに既定の字と、いま効いている置き場の出どころ（共有の設定／既定／この PC だけの上書き）を出す。
4. **B7**: 「保存すると、右上の 👤 のIDを更新者として記録します。」
5. **B8**: 帯に出ている札が1つも無いときは帯ごと伏せる（CSS の`:has()`の1行。JS の長い関数を伸ばさない）。
6. **B9**: 段の切り替えを器へ知らせる（`bindMaintTabs`が`mm-tab`を出す）。共通設定は、いまの段に`[data-pc-field]`が
   1つも無ければ保存の帯を伏せる。置き場の欄を足したので「アプリの更新」の段にも保存の帯が出る（欄が在るから）。
7. **届くかを見るだけで置き場を作らない**（`reachable()`）。まだ無ければ、親に届くなら「届く」と答え、置き場は版を置くときに作る。

## 撤回した案

- **置き場を`config/local.json`だけで変える**（§9.555 のまま）: PC ごとに書き換えが要る。全 PC が見る共有の設定にした。
- **窓がパス設定マスタ（SQLite）を読む**: 窓に SQLite を持ち込むことになる。Python が控えを書く形にした。

## 網

- `tests/test_appupdate.py`（38項目）: 置き場の順（local → 共有 → 既定）・控えは変わったときだけ書く／空に戻せる／覚えることが
  無ければ作らない・窓と同じ控えの名と順・保存の鍵（パス設定マスタと受け側）・見るだけで置き場を作らない・
  **この網を回しても UNC の字のフォルダが作業フォルダに生まれない**。
- Rust（`reads_version_and_place`）: 既定・控え・local.json が控えより先・控えが空なら既定。

## 踏んだ罠

- **網が既定の置き場（UNC の字）へ書いていた**。Windows 以外では`\\nlmsrvngy03\…`がただのフォルダ名になり、
  `test_appupdate.py`の「同時に2本」の確かめ（置き場を渡していなかった）と、画面の網が開いたときの`reachable()`の`mkdir`が、
  リポジトリ直下と`tests/`に字のとおりのフォルダを作っていた（§9.555 の分も残っていた。`.gitignore`の`[\\]*`で git には
  入っていなかった）。網は一時の置き場を渡し、`reachable()`は作らないようにし、生まれないことを網で見張る。

## 分からないこと

- 置き場を変えた直後に起動した PC は、まだ前の控えを読む（前の置き場を見る）。10分以内に控えが書き直され、その次の起動から新しい
  置き場を見る。前の置き場が無くなっていれば、その1回は「届きません」でいまの版のまま起動する。実機で確かめていない。
