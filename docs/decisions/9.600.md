# §9.600 窓を閉じた瞬間に問い合わせが途中でも、入口と本物の Python を止める——`stop()`は写しの数を問わず止める

索引: [決定記録](README.md)｜前: [§9.599](9.599.md)｜関係: [§9.571](9.571.md)・[§9.556](9.556.md)・[§9.544](9.544.md)

## 経緯

PR #183（ステップ2・マスタの画面だけの変更）で、CI の`desktop`／`windows`の自己診断の最後の確かめ「入口役が残っています」が落ちた。
5回の自己診断はどれも PASS・版の入れ替え（`-ci2`）も本物の PID の見分けも通っていた。落ちたのは「5回目（入口役を挟んだ起動）で
窓が閉じた後に、入口役の`python.exe`が残っている」の1点だけ。PR の差分は`desktop/`にも起動の道にも触れていない。
再実行は権限が無く断られた（403）ので、ログとコードで原因を探した。

## 測った（前）

同じ確かめの main の緑の回と、PR の赤の回の窓の記録（`desktop.log`）と Python の記録（`launcher.log`）を並べた:

| | main（緑・febe21f） | PR #183（赤） |
| --- | --- | --- |
| 窓を閉じた（`EXIT`） | 21:47:30 | 00:10:28 |
| 本物の Python の「終了理由」 | 21:47:30.195（同じ秒） | 出ていない |
| 入口役 | 止まった | 10秒後にランナーの片付けが止めた（`Terminate orphan process: pid (2108) (python)`） |

`EXIT`は`stop()`が返った後に書く。緑の回は`Drop`が走った（待つ → 入口役を止める → 本物が入力の終わりを見て終わる）。
赤の回は`Drop`が入口役を止めていない。

## 原因

- 窓を閉じたとき（`RunEvent::Exit`）、`Supervisor::stop()`は手元の`Arc<Sidecar>`を1つ捨てる**だけ**だった。止める処理
  （入力を閉じる → 待つ → 入口を止める → 本物を待つ・§9.571）は`Drop`にあった。
- 問い合わせは1件ごとに`Arc<Sidecar>`の写しを持って答えを待つ（`router.rs`の`self.get()`）。窓を閉じた瞬間に問い合わせが1件でも
  途中だと`Drop`が後回しになり、その前に窓のプロセスが終わる。入口役（§9.571 の網の`pyshim`・利用者の PC では
  `WindowsApps\python.exe`）は入力の終わりを本物へ伝えないので、入口と本物の Python が残る。
- 利用者の PC でも起き得る: 残った本物が`program`を掴み、次の起動の版の入れ替えが断られる（§9.571 の症状に戻る）。
- 網で再現した（`cargo test`の`stop_ends_python_even_while_a_request_holds_it`）: 「準備できた」を言って入力の終わりまで待つだけの
  偽の中身を起こし、写しを1つ持ったまま`stop()`する。前の作りでは3秒たっても Python が残る（落ちる）。

## 決めたこと

- 止める処理を`Sidecar::shutdown(&self)`の1箇所へ移した（**1回だけ**——`stopped`の印）。`Drop`と`Supervisor::stop()`の両方から呼ぶ。
- `stop()`は取り出した中身を**写しの数を問わずその場で止める**。途中の問い合わせは、相手が止まったことを`Died`として受け取る
  （読み手の糸が終わり、待っている問い合わせへ知らせる・前からの作り）。
- 版の入れ替えの前の止め方（`main.rs`の`drop(started); sup.stop()`）も同じ1本を通る。

## 確かめた

- `cargo test`: 29/29（足した網は直す前の作りで落ち、直した後に通る）。
- `cargo clippy --all-targets -- -D warnings`（Linux）と`--target x86_64-pc-windows-msvc`: 警告0。
- `cargo fmt --check`: 前から3ファイル（`install.rs`・`proc.rs`・`update.rs`）に整形の差があった（main でも同じ・CI は fmt を回さない）。
  決まり（CLAUDE.md の F）どおり緑にするため、空白と改行だけを整えた（動きは変えない）。
- 本物の WebView2 と入口役を挟んだ終わり方は CI の`windows`の自己診断が見る（この端末では回せない）。
