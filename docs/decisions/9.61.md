# §9.61 作業スケジュールの履歴(実績)を消せるようにする

「データ一覧には何も無いのに、スケジュールには作業中が居座って消せない」。
§9.52で端末側の削除経路は直したが、**残る経路がもう1つあった**。

計画外実績(§9.33)は`build_actual_index()`＝バックアップ(`records.sqlite3`)の
行から合成される。一方データ一覧が見せるのは端末内(IndexedDB+ミラー)。
別PCで測定した行や、端末側だけ消えた行はバックアップにだけ残り、
**その端末からは消す手段が無かった**。スケジュール投入済みロットは仕掛一覧
の表示から除外される(§9.44)ので、画面上で確かめようも無い。

履歴行(作業中・完了)に実績削除ボタンを出す。押すと確認モーダルで
「測定データそのものを消す」「元に戻せない」ことを箇条書きで示す。
消す先は2つあり、**端末内にあれば`reliableDelete()`(端末＋バックアップ)、
無ければバックアップ行だけを直接消す**。

権限は`edit`と`schedule`の両方に開く(`_ENDPOINT_EXTRA_MODES`の
`measurement.backup_delete`)。計画盤を整えるのは計画端末の役目のため。
閲覧モードには開かない。**フロントの`scState.canDeleteHistory`と
サーバー側の許可は必ず揃えること**。
