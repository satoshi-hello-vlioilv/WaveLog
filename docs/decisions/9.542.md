# §9.542 設備の使い分けの表と効き先の図——多数派と違うセルを光らせ、外したら何が起きるかを図で（利用者の選択 G-2＋G-4）

索引: [決定記録](README.md)

## 利用者の言葉と選んだ経緯

マスタの視覚化の候補 G「設備の機能表」。G-1〜G-5（スクラッチの `mockG.js`・製品のコードではない）を見て
**「G-2とG-4の組み合わせでお願いします。」**

- G-2: 2枚目のタブ「使い分けの表」——設備×使う機能・入力内容の○。多数派と違うセルだけ光る。
- G-4: 効き先の図——選んだ設備の設定が、どの画面のどこに効くか。

組み合わせ方の解釈: 表を上、選んだ設備の効き先の図を下に置く。設備名を押すと図がその設備になり、表のセルに乗せると
「外すと何が起き、何が残るか」が浮く（G-2 の案にあった浮き出し）。乗せたセルが図に出している設備のものなら、図の同じ所も光る。

## 測った（評価関数）

物差しはスクラッチの `eval_equse.js`。検証用の設備A〜Dの「使う機能・入力内容」を一時的に変えて測り、終わったら丸ごと戻す
（設備マスタの削除は無効化で行が残るので、見本の設備は作らない）。見本: A＝すべて、B・C＝テレスコープ・巻ずれを外す、
D＝作業予定と板幅・ラテラルボー・バリ・テレスコープ・巻ずれを外す。**正解は画面と独立に**作る。

| 物差し | 前（VER2.428.0） | 後 |
| --- | --- | --- |
| 外した設定を画面が「外した」と名指しする数 | 0/10 | 10/10 |
| 多数派との違いを正しく数える設備 | 0/4 | 4/4 |
| 選んだ設備の効き先（機能3つの使う／外した） | 0/3 | 3/3 |
| 1か所を切り替えるのに押す回数（保存されたか） | 3回（行→札→保存）・保存された | 1回・保存された |
| 主役の一覧（行数・見出し） | 4行・8列 | 4行・8列（変えない） |

前の一覧の「使う入力内容」の欄は、使う側の名前を並べるだけで、外した側は引き算しないと分からない。しかも B・C・D の3行とも
**字が末尾で切れて**違いが読めなかった。

網: `test_equse.js`（20件）。欠陥を入れて確かめた:
- 多数派の「同数は使う側」をやめる → **最初は網が素通りした**（見本に同数の列が無かった）。同数になる見本を足して、落ちることを確かめた。
- 浮き出しを乗せたセルの上へ置く → 「被らない」と「図の同じ所が光る」の2件が落ちる。
- 押した瞬間の焦点で浮き出しを開く → 単独では落ちない（下の「上に置く」守りだけで被りは起きない）。鍵盤の焦点で開くことは網が見る。

## 決めたこと

- **答えは `WL.equipUse.useMatrix()` の1箇所**（画面を知らない）。多数派＝その列で半分以上の設備がしている側（同数は「使う」＝既定の側）。
  機能はどこにも出ない設備（機能を全部外した設備）を除いて数え、入力内容はそのうち測定を使う設備だけで数える。
  測定を使わない設備の入力内容は「効かない」（`null`・押せない「—」）。どこにも出ない設備は違いに数えない（わざと外している）。
- **主役は1枚目の一覧のまま**。2枚目のタブの札が違いの合計を言い、行の頭が「Nか所」を字で言う（色だけで伝えない）。
  同じ組み合わせの設備は「＝◯と同じ」と名指しする。
- **セルを押すとその場で保存**（1回ずつ）。更新の口は全欄を書くので、行の値をそのまま添える。入力内容を全部外す形はサーバーが断る（§9.392）。
- 「外したら何が起き、何が残るか」は**サーバーの語彙**（`EQUIPMENT_FEATURE_EFFECTS`・`MEASURE_ITEM_EFFECT`・入力内容が効く機能
  `MEASURE_ITEM_FEATURE`）。浮き出しと効き先の図が同じ字を読む。
- タブの面に押す・乗せるを持たせるため、拡張点 `registerListView` に **`wire(section,ctx)`** を足した（盤は中身を知らないまま）。
  `ctx.writable`（このタブを保存できるか）も渡す——読むだけの端末ではセルを押す形にしない。
- **乗せると浮く面は `WL.popMenu.peek()` の1箇所**へ移した（§9.540 のスペーサーの札が自前で持っていた開け閉めの待ちを共有）。

## 踏んだ罠

右端のセルを押しても保存されなかった。押した瞬間（mousedown）にボタンへ焦点が移り、その焦点で浮き出しが**すぐ**開く。
右へ出した浮き出しは画面に入らず左へ寄せられ、押したセルの上に被さる——指を離した所が浮き出しになり、`click` がセルに届かない。
直し方は2つ: 焦点で開くのは**鍵盤で来たとき（`:focus-visible`）だけ**／浮き出しは乗せた物の**上か下**に置き、横へ出さない
（使い分けの表は下に効き先の図があるので上）。`elementFromPoint` はセル自身を返していた（被るのは押した後）ので、
「押せない」は押したあとの面まで見ないと分からない。

## 分からないこと

- 多数派を「半分以上」で決めたが、設備が2台だけの工場では1台ずつが互いに「違い」になり得る（同数は使う側なので、外した側だけが光る）。
  台数が少ないときに光らせ方を変えるべきかは、使ってみないと分からない。
