# §9.552 窓（exe）の版を中身へ渡す・ショートカットは窓が直に作る——Rust の得意な所へ移す（利用者の選んだ候補 1-C と ショートカット）

## 経緯

利用者の問い「Rustにした方が良い部分はまだ残っていますか？」に、設計書 §6 の分け方（Rust＝OS の窓・プロセス・ファイルを
直に扱う仕事／Python＝共有DB・画面の API・計算）を物差しに、Python が OS へ直に触っている所を全部（8ファイル）拾って
仕分けた。移す価値があるのは **デスクトップの起動ショートカット**（`cscript`＋補助VBScript）の1つ、小さく足すのは
**窓の版を中身へ渡す**（候補 1-C）の1つ。共有DB・Navigator の DLL・部品の導入・速さ目的の書き換えは移さない（下の「撤回した案」）。

利用者の言葉: 「1と2を進めて」。

### 1-C で困っていたこと

- 窓は Python を起こすとき `WAVELOG_SHELL=desktop` しか渡しておらず、**Python はそれすら読んでいなかった**。
  窓の名乗り（`CARGO_PKG_VERSION`）は `1.0.0` のままで、配った exe 3本を見分けられなかった。
- **窓だけ古い**ことが起こる: 窓は中身（Python）が止まると起こし直す（`sidecar.rs`）。ZIP で更新が届いたあとに
  起こし直された Python は新しく、窓は古い exe のまま。`.py` の更新時刻（§9.200）では「再起動が要る」と言えない
  （Python は更新の後に起きている）。

### ショートカットで困っていたこと

`.lnk` は Windows の部品（COM の `IShellLinkW`）でしか作れず、Python からは WSH（`cscript`）経由だった。そのための回り道が4つ:
英数字だけの補助スクリプト（WSH は日本語を読み違える）・空の引数の身代わり `NO_ICON`（WSH は空を数えない・§9.486）・
読めない字の置き換え（`errors=replace`）・補助スクリプトを「ほかのプログラムの置き場」へ（Store 版の Python・§9.496）。
しかも Windows で本当に作って読み戻す網が無かった（Linux の網は `cscript` の並びを組み立てて突き合わせるだけ）。

## 決めたこと

### 窓の版（1-C）

- **窓の版＝exe を作ったコミット**。`build.rs` が `WAVELOG_BUILD_COMMIT` を埋める（CI の `desktop.yml` が `github.sha` を渡す。
  publish が `WaveLog.build.json` に書く `commit` と同じ値）。手元で作った exe は空＝「分からない」。
- 窓は Python へ `WAVELOG_SHELL_COMMIT`（作ったコミット）と `WAVELOG_SHELL_EXE`（いま動いている exe）を渡す。
- **答えは `backend/desktop_shell.py` の1箇所**: `running()`（この Python を起こした窓）・`placed()`（`WaveLog.build.json`・
  読むたびに読み直す）・`stale()`（違う＝True／同じ＝False／比べられない＝None）。
- **再起動の知らせ**（`/api/build` の `restartNeeded`）は「中身の `.py` が新しい」か「窓が配ってある exe と違う」のどちらかで出し、
  理由（`restartWhy`＝`python`／`window`）で字を言い分ける（窓だけのときは「窓（exe）だけが古い版のまま・中身は新しい」）。
  中身を確かめられなければ「分からない」のまま（窓の側の「比べられない」は不要と同じ）。
- **在席と接続の記録**に窓の版（`shell`: 窓の外は空・名乗らない古い窓は `?`・窓は短いコミット）。接続状況は版の横に「窓 3e1b43e」、
  配ってある exe と違う窓は**要更新**に数える（理由は `shellOutdated` と `title`）。判定は `fleet_summary()` の1箇所のまま、
  配ってある窓は呼ぶ側（`routes/presence.py`）が `placed_shell` で渡す。開発者の端末は判定の外（§9.516 と同じ）。

### ショートカット

- **作る・読むは窓の副コマンド `WaveLog.exe --lnk`**（`desktop/src/lnk.rs`）。頼みは標準入力の JSON 1つ（`op`＝`make`／`read`・
  名前の付いた欄・UTF-8）、答えは標準出力の JSON 1つ。**位置で読まない**ので §9.486 のずれは起こりようがない。
  副コマンドは `main()` の先頭で分ける（窓・1つだけ起動の仕組みより前）。
- **決めるのは Python のまま**（`desktop_shortcut.py`: どこへ・どの名前で・上書きしてよいか・前の名前を片付けるか・名前と絵を残す）。
  窓は頼まれた1件を作る／読むだけ。
- 起こす exe は**いま動いている窓**（`WAVELOG_SHELL_EXE`＝手元へ写した版ごとのフォルダ）。Box の上の exe は起こさない（掴んで
  更新を止める・設計書 §7）。窓の外（開発の入口）では `program/WaveLog.exe`。
- 窓が断ったら**窓の言った理由**をそのまま画面へ（「終了コード 1」だけにしない）。答えが読めなければ読めないと言う。
- 補助スクリプトは作らなくなったので、端末の手元に残った `make_shortcut.vbs` は `setup_check.RETIRED_LOCAL` で片付ける
  （`file_cleanup` の「作り直せる起動の部品」からは外し、そこは書きかけ `.tmp` だけになった）。
- 絵（`.ico`）は今までどおり `paths.browser_dir()` に置く（読むのはエクスプローラー＝別のプログラム・§9.496 はここでは残る）。

## 撤回した案

- **ショートカットの判断ごと Rust へ移す**——上書きの確認・名前の付け替え・共通設定へ残す、は網で固めた Python の判断で、
  移すと同じ判断が2箇所になる。Rust には OS の部品を呼ぶ所だけを渡した。
- **窓の中の Python から窓へ問い合わせ直す**（窓口の枠を逆向きにも使う）——枠の約束（`protocol`）を変えることになり、
  1件の `.lnk` のために大きい。exe を副コマンドで起こすほうが小さく、網からも確かめやすい。
- **窓の版を `CARGO_PKG_VERSION` で上げていく**——人が上げ忘れる。作ったコミットなら CI が必ず埋め、`WaveLog.build.json` と同じ物差しで比べられる。
- **窓だけ古いことを「新しい版あり」（§9.515）で知らせる**——あちらは運用中の最新版（数えた最大）との比較で、打つ手は「配る」。
  窓だけ古いときの打つ手は「開き直す」なので、再起動の知らせ（§9.200）に入れた。
- **共有DB・Navigator の DLL・部品の導入（pip）・速さ目的の書き換えを Rust へ**——共有の手順は1バイト違わない作法で錠を取り合う
  必要がある（設計書 §6）／DLL は 32/64bit の判定と子プロセスでの時間切れが Python で揃っている／pip は Python 自身の仕事／
  API の平均は 3〜4ms で、遅さの正体は意図した待ち。

## 測った（評価関数・前→後）

物差しは `scratchpad` の評価関数（ソースを読んで数える）と網。

| 物差し | 前 | 後 |
| --- | --- | --- |
| C1 窓が中身へ渡す「窓の版」 | 0（`desktop` だけ・Python は読んでいない） | 1（`WAVELOG_SHELL_COMMIT`＋`WAVELOG_SHELL_EXE`） |
| C2 在席・接続の記録に窓の版 | 0 | 1 |
| C3 窓だけ古いときに「開き直して」と言える | 0 | 1（理由を言い分ける） |
| C4 窓の名乗りが作り直すたびに変わる | 0（配った3本とも `1.0.0`） | 1（作ったコミット） |
| S1 外のスクリプト（`cscript`）を起こす道 | 2（作る・読む） | 0 |
| S2 WSH のための回り道 | 4 | 0 |
| S3 Windows の実機で作って読み戻す網 | 0 | 3（`cargo test` の `make_then_read_gives_same_target`・自己診断の「ショートカット」・`test_shortcut.py`の短い名前） |

欠陥注入は4件（窓の比べ方を反転・絵の番号を分けない・窓の違いを要更新に入れない・窓の理由を言わない）——どれも網が落ちた。

## 網

- `test_presence.py`（＋8項目）: 窓の版の比べ方・比べられないときは「分からない」・在席へ書く印（空／?／短いコミット）・
  接続状況の要更新・配布の名乗りが無ければ比べない・開発者は判定の外・再起動の知らせの理由・中身が分からなければ「分からない」。
- `test_shortcut.py`（作り直し）: 窓の副コマンド1つ（make／read）・頼みの形（名前付き・絵の番号を分ける・UTF-8）・断りの理由を
  そのまま返す・答えが読めなくても落ちない・`cscript` の道が残っていない・起こす exe（窓の中＝いまの窓／外＝配ってある exe）・
  補助スクリプトを片付ける。
- `desktop/src/lnk.rs` の `cargo test`（Windows の CI で本物の COM）と、自己診断の「窓の版」「ショートカット」（本物の WebView2・
  Python→exe→COM の往復）。

## 踏んだ罠

- **網の通しの出力が固まった**（`run_all.sh … | tail`が25分戻らない）。網そのものは99秒で終わっていた。
  ランナーがサーバーを裏へ回す1行 `( cd "$ROOT" && nohup python3 … & )` は「cd と nohup の組」ごとを裏の子シェルにする。
  その子シェルはサーバーの終わりを待ち続け、しかも後片付け（`restart_server >/dev/null 2>&1`）で bash が退避した元の出力
  （fd 10/11＝管）を握っていた——サーバーが動く限り管が閉じない。§9.551 で「分からない」と書いた`with_fixture.sh`の固まりも同じ。
  再現: 同じ形の台本で、古い書き方は裏の命令が終わるまで（6秒）戻らず、`( cd … || exit 1; nohup … & )`（裏へ回すのは単純な命令1つ）は
  0.005秒で戻る。両方のランナーを直した。
- **`test_scsave.js`が赤いままだった**（§9.548 から）。「打つ手を書く（再起動）」が字の「再起動」を探していたが、§9.548 で打つ手を
  「開き直して」へ言い換えていた（`WL.RESTART_HOW`）。通しを回していなかったので気づかなかった。網は字ではなく
  `WL.RESTART_HOW`そのものが入っているかで見るように直した。
- **Windows の CI で`cargo test`の往復が落ちた**——作って読み戻すこと自体は日本語の名前も含めて通っていたが、一時フォルダが
  8.3 の短い名前（`RUNNER~1`）で来て、読み戻した行き先は長い名前（`runneradmin`）だった。網は実際の場所（`canonicalize`）で比べ、
  製品の`_same_path()`も`realpath`（実際の場所）で比べるようにした（短い名前で渡った道を「自分の物ではない」と取り違えない）。
  短い名前と長い名前を同じと見ることは`test_shortcut.py`が Windows の CI（`desktop.yml`の Python の網）で確かめる。
- **フルスイート（利用者の指示）で1本だけ赤**——`test_listbar.js`「帯の字は1つの大きさ」が 11px と 12px の2種（単独でも落ちる）。
  §9.552 の変更ではなく、**§9.543（VER2.430.0）から main で赤いままだった**: 換算係数の凡例に付けた`.lf-key`が、一覧の帯の
  「元データ」の札（§9.505・同じ名前）にも当たり、`--fs-micro`で小さくしていた。後から来た凡例の側を`.lf-legend`へ改名
  （凡例の見た目は変えない——元は`:is(…,.lf-key)`の字の太さ500も当たっていたので書き写した）。網は落ちたとき
  「どの字が何px か」を名指すようにした。CSS の網（同じセレクタの同じプロパティを2つのファイルに書かない）は`:is()`の中の
  名前を見ていないので、この重なりを捕まえられなかった。
- 走っていたサーバーを`pkill -f "program/app.py"`で止めようとして、**自分のシェルの命令行にも当たって落ちた**（前にも踏んだ）。
  止めるのは`pgrep -fx`で名前を丸ごと当てたものだけ。

## 分からないこと・実機で確かめること

- Microsoft Store 版の Python から起こした exe は、Store のアプリの中（パッケージの文脈）で動く見込み。`.lnk` を置くのは
  デスクトップ（`AppData` ではない）なので写しへ回らない見込みだが、**Store 版の Python の端末では確かめていない**。
- 古い exe（コミットを名乗らない）の窓では、窓の版は「?」で、窓だけ古いことは言えない（新しい exe が届いた後から効く）。
- 窓の外・古い窓（`WAVELOG_SHELL_EXE`を渡さない）では`program/WaveLog.exe`を起こす。main へ入ってから CI が新しい exe を置くまでの
  あいだ（十数分）に取った ZIP では、そこに古い exe（`--lnk`を知らない）が入っていることがある。そのときは作れず「窓の答えを
  読めません」と出る見込み（古い窓が動いていれば1つだけ起動の仕組みが前の窓へ渡して終わる）。**実機では確かめていない。**
