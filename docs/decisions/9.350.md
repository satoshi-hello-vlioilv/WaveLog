# §9.350 色のリテラルは「増えない」を機械で固め、トークンと同じ値から置き換える

`docs/REVIEW_2026-09.md` §6.3 3-18「色のリテラルをトークンへ」の**機械置換ぶん**。
振る舞いも見た目も変えない——**変えていないことは画素で確かめた**
（`tests/visual/run.sh base → head → compare`。この道具の本来の用途）。

## 何が起きていたか

規則（CLAUDE.md「色と文字サイズは`:root`のトークンから選ぶ」）はあったが
**網が無かった**。実測: トークン定義でない宣言の中の色リテラルは
**1,110箇所**（白 `#fff` を除く。含めると 1,505）、**種類は 480**。
`:root` には 94 の色トークンがあるのに、`--muted`（`#60747b`）と同じ値が
75箇所、`--bg`（`#eef2f4`）が 59箇所、素のまま書かれていた。

480種は「同じ意味に違う色」が既に混ざっていることの現れ
（4-1 ①で「色が逆に付いていた」のはこの形の1例）。

## 決めたこと

1. **上限を固めて、下げる方向だけ動かす**（`test_csslint`。
   `tests/fixtures/color_baseline.json` にファイルごとの件数。
   `python3 tests/test_csslint.py --update` で下げる。上げる更新は断る）。
   数えるのは**トークン定義（`--x:`）でない宣言**の中の `#hex`／`rgb()`／`hsl()`。
   白（`#fff`／`#ffffff`）は数えない。コメントは潰してから数える。
   網の中に「同じ形を注ぐと2件数える」の自己検査を持つ。
2. **値がトークンと同じもの**は機械で置く。ただし**役割の無いトークンへは
   置かない**——`#173842` は `--ink` と `--nav` の両方の値だが、地の文字の色
   なので `--ink`。`#075e67`（`--computed-fg`）のように**役割の狭い**トークンと
   値が同じものは置かない（役割が違えば、次に色を変えたとき巻き添えになる）。
   置いたのは13トークン・352件（`--muted` 73・`--bg` 59・`--surface-2` 49・
   `--ink` 46・`--ink-2` 35・`--line-soft` 28・`--ink-soft` 13・`--surface-3` 13・
   `--line-mid` 10・`--line-strong` 8・`--line` 7・`--danger` 6・`--ink-3` 5）。
3. **触らないもの**: 8桁（α付き `#087c8926` 等。`var()` に α を足せない）、
   コメントの中、トークン定義行、JS の中の色（44件）。
4. 残り（758件・トークンと値の合わない色）は**役割名を足してから**置く
   （`--sc-…`／`--rp-…`）。これは色の意味を決める作業なので機械ではできない。
   上限は固まったので、増えることはない。

## 画素で確かめた

`tests/visual/run.sh base`（置換前）→ 置換 → `head` → `compare`:
- 1回目: **47枚中47枚が相違**（最大63%）。原因は上の罠（トークン定義を自己参照に
  した）。画素の対が `f7fafb→ffffff`・`d6e0e3→ffffff` と**一様**で、色そのものが
  消えていることが読めた。
- 2回目（直したあと）: **一致37枚・相違10枚**。相違はすべて作業スケジュールの
  「(翌)」の印と日付の点線が**隣の行へ1つ移った**もの（0.06〜0.09%。画素の対は
  `ffffff→60747b` のような「文字が現れた／消えた」で、一様な色の入れ替わりでは
  ない）。基準を撮ってから2時間近く経ち、直の境目が行をまたいだ——サーバー
  時刻の揺れで、`capture.js` の均し（経過分を0へ）が覆っていない種類。ほかは
  端の2〜3画素（`51-マスタ-05`・`71-②測定`）。**色の差は0。**
- 揺れの見分け方: 一様な色の対なら CSS、文字の出入りなら内容。次に撮り比べを
  するときは base と head を**続けて**撮る（あいだに置換だけを挟む）。

## 踏んだ罠

- **置換スクリプトがトークン定義そのものを自己参照に書き換えた。** 「宣言の
  プロパティ名は直前の `;`／`{` から `:` まで」で切り出していたが、`00-base.css`
  の `:root` は定義行のあいだに `/* 例: … */` のような**`:` を含むコメント**を
  持つ。コメントの中の `:` で切ってしまい、`--muted:#60747b` を
  `--muted:var(--muted)` にした（5本。循環参照でトークンが無効＝`initial`）。
  画面は地が白に崩れ、**47枚中47枚が相違**（最大63%）。
  **コメントを潰した写しで宣言を見る**（位置は保つ）形に直した。
  この事故を捕まえたのが画素の比較で、`git diff` の目視では「`#60747b` が
  `var(--muted)` になった行」にしか見えない——**置換の道具は撮り比べで確かめる**。
  網（`test_csslint`）は「`--x:var(--x)` の自己参照が無い」も見る。

- `test_csslint` は末尾で `ng=[…]` を先に数えてから要約を出す。**要約の直前へ
  足すと、落ちても「全部PASS」と数える**（実際に 23/24 の落ちが 24/24 と出た）。
  `ng=` の前へ置く。
- 押す口の引数だけ拾う正規表現では、配列に並べた選択子が素通りする（§9.349）。
  同じ形で、**色も「宣言の中」で数える**——行の先頭が `--` かどうかでは、1行に
  複数の宣言を書く CSS で取りこぼす。
