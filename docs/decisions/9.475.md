# §9.475 断面図・立体図の区間は面ぜんたいが的——記号は札、当たりは座標で決める（利用者の指示）

索引: [決定記録](README.md)

## 利用者の言葉

> 端部の表の強調表示は図の端部にフォーカスがあったときにもできるようにしてください。刃組部分に関しても
> アルファベットは的が小さすぎるので、エリア全体でそれぞれ強調表示できるようにしてください。拡大図は
> そのエリアで指定している場所を拡大できるようにアルファベットをボタンからラベルに変更し、そういった
> エリアの拡張でクリックの的を大きく使いやすくしてください。

## 測った（断面図・1728×1030・`scratchpad/test_zprobezone.js`）

| 物差し | 前 | 後 |
| --- | --- | --- |
| 拡大図を開ける的の面積 | **488px²**（記号の札 22×22） | 25,424px²（区間の面 149×170） |
| 区間の面（札から離れた所）に乗る → 刃組表の行が光る | ✗ | ✓ |
| 端の区間（OS）の面に乗る → 右の端部の表が光る | ✗（小さな OS の札だけ） | ✓ |
| 区間の面を押す → 拡大図 | ✗ | ✓ |
| 区間の上で掴んで動かす → 回る／拡大図は開かない | ✓／✓ | ✓／✓（保った） |
| 記号が押す物（ボタン）か | はい | いいえ（札） |

**なぜ面が効かなかったか**: §9.417 で「区間ぜんたいは光るだけ、押せるのは記号の札だけ」と決めていた
（面の器に当たりを持たせると、立体を掴んで回す手——`canvas`の`pointerdown`——へ届かなくなる）。
模式図は SVG の区間ぜんたいが的なので、断面図・立体図だけ的が小さかった。

## 決めたこと

- **面の器（`.bs-t3z`）は当たりを持たないまま、座標で当てる**（`blade-3d.js`の`zoneAt()`）。`canvas`の
  `pointermove`で乗っている区間を探して画面へ知らせ（`onZone('hover')`→`pickBadge()`）、**ほとんど動かさずに
  離したら押した**（5px 以内・`onZone('click')`→`openZoneZoom()`）。掴んで回す道はそのまま。
- 端の区間（OS・DS）も同じ道で光る（右の端部の表・端の区間の面）。押しても拡大図は開かない（§9.463）。
- 押せる面（端でない区間）の上では指のカーソル。
- **記号は札**: `bs-bhit`を外し、`pointer-events:none`。見た目（色・形）は模式図・刃組表と同じまま。
- 同じ押下の`click`が「外を押したら拡大図を閉じる」に拾われないよう、面で開いた1回だけ印を立てる
  （`zoneClicked`）。
- §9.417 の「押せるのは記号の札だけ」を撤回（的は面、回す道は座標で当てることで守る）。
