# §9.496 ショートカットの補助スクリプトと絵は「ほかのプログラムからも見える置き場」へ（利用者の報告）

索引: [決定記録](README.md)

## 経緯

利用者の報告「ショートカットが作成できない端末が出ています。端末によってできる出来ないがある？」。
画面は「ショートカットを作れませんでした: 入力エラー: スクリプト ファイル
"C:\Users\norio-mori\AppData\Local\WaveLog\runtime\make_shortcut.vbs" が見つかりません。」。

## 原因

**分かれ目は Python が Microsoft Store 版かどうか。** 同じ端末の起動ログは
`...\WindowsApps\PythonSoftwareFoundation.Python.3.12_qbz5n2kfra8p0\pythonw.exe`。Store 版（MSIX）の Python は
`AppData\Local`への書込を**このアプリからしか見えない写し**へ回す（§9.318）。補助スクリプトを`runtime_dir()`
（`AppData\Local\WaveLog\runtime`）へ置いていたので、読む`wscript.exe`（別のプログラム）からは見えなかった。
待機画面は同じ理由で`paths.browser_dir()`（見えない端末でだけ`~\.wavelog\runtime`へ移す）へ移してあったが、
あとから足したショートカット（§9.410）はその答えを使っていなかった。

**絵（`.ico`）も同じ**——読むのはエクスプローラー（別のプログラム）。Store 版の端末では作れても白紙の絵になる。

## 測った（`tests/test_shortcut.py`）

| 物差し | 前 | 後 |
| --- | --- | --- |
| 補助スクリプトの置き場＝`browser_dir()` | `runtime_dir()` | `browser_dir()` |
| 絵の置き場＝`browser_dir()` | `runtime_dir()` | `browser_dir()` |

## 決めたこと

- **ほかのプログラムが読むファイルは`paths.browser_dir()`の1箇所が置き場を答える**（待機画面・進捗・補助スクリプト・絵）。
  名前は変えない（14箇所が使う）。意味は「ブラウザ」から「ほかのプログラム」へ広げ、説明に書いた。
- 通常の Python の端末では`browser_dir()`＝`runtime_dir()`なので、置き場は1バイトも変わらない。
