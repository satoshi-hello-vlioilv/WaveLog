# §9.398 入れ子のメニューは「通り過ぎただけ」では閉じない（利用者の不具合報告）

利用者の報告（原文）:

> ICASコピー機能について、ポップオーバーメニュー設定を確認しようとして、
> **入れ子構造のメニューの子側にカーソルを移した瞬間消える**ので設定が
> できません。修正をお願いします。

## 1. 真因——子のメニューが、自分自身を消していた

`bindRowMenuItems()` は**親のメニューと子のメニューの両方**で使い回している
（§9.368「1項目ぶんのHTMLと配線は1箇所」）。区別は第3引数 `openSub` だけで、
**子を開く口を持たない側＝子のメニュー自身**だった。

```js
// 直す前
const enter=()=>{
 if(it&&it.sub&&openSub)openSub(b,it);
 else closeRowSubMenu();      // ← 子のメニューの中でもここへ来る
};
```

子のメニューの項目は `sub` を持たず `openSub` も `null` なので、**必ず
`else` に落ちる**。つまり**子の項目へカーソルを乗せた瞬間に
`closeRowSubMenu()` が走り、自分自身を消していた**。利用者の言葉
「子側にカーソルを移した瞬間消える」がそのまま書いてある。

## 2. なぜ網が1件も落ちなかったか——**カーソルを1pxも動かしていなかった**

`tests/test_lotcopy.js` には「入れ子のポップオーバーにルールと設定が並ぶ」
「設定モーダルに見本が出る」という節が**元からあった**。ところが子の項目は

```js
await page.evaluate(()=>{const b=[...document.querySelectorAll('.sc-row-submenu button')]
  .find(x=>x.textContent.includes('設定'));if(b)b.click()});
```

という**合成クリック**で押していた。`el.click()` はカーソルを動かさないので
`mouseenter` が1度も飛ばない——**壊れている通り道だけを一度も通らない網**
だった。§9.220 2② で「本物のクリックで押すこと」を学んだのと同じ形で、
**今度は「本物のマウス移動で辿ること」**が要る。

直したあと、`enter` を元の `closeRowSubMenu()` へ戻す欠陥注入で
**3件が赤**になることを確かめた（素通りする網ではない）。

## 3. 直し方——閉じるのは「留まったとき」だけ

子は `document.body` 直下に置いてある（§9.368。親の枠で切られないため）ので、
親の項目から子へ行くには**親のメニューの上を斜めに横切る**ことがある。
`mouseenter` した瞬間に閉じる作りだと、**通り過ぎただけで消える**。

決めごとは1つ:

> **子のメニューを閉じるのは「別の項目の上に留まったとき」か「外を押した
> とき」だけ。通り過ぎただけでは閉じない。**

- 子のメニューの中（`openSub` が無い側）では**何もしない**。むしろ
  「閉じる」の予約を取り消す——子へ辿り着けたのだから。
- 親の別項目へ乗ったら**すぐには閉じず**、`SC_SUB_CLOSE_MS`（260ms）後に
  閉じる予約を置く。子の器へ入れば取り消す（`mouseenter`／`mousemove`）。
- **同じ親項目なら開き直さない**（`__owner` を控える）。子から親の項目へ
  戻ると `mouseenter` がもう一度飛ぶので、作り直すと**その場でちらつき、
  カーソルの下の項目が入れ替わる**。

**居座らせない**ことも同時に固定した——別の項目に留まれば閉じる。開きっぱなし
にすると、押すつもりの無い子を押せる状態が残る（§CLAUDE 4）。

### 「安全な三角形」を作らなかった理由

親の項目と子の器の3点で三角を張り、その中に居るあいだは閉じない、という
作り方もある。**採らなかったのは、閉じる条件が図でしか説明できなくなる**から。
「留まったら閉じる／通り過ぎたら閉じない」は言葉で言い切れて、網も
「斜めに一気に横切る」「別の項目に留まる」の2通りで書ける。

## 4. 固定した網（`tests/test_lotcopy.js` 4b）

| 見るもの | どう動かすか |
| --- | --- |
| 子の1つ目へ移しても消えない | `page.mouse.move` で**本物のカーソル**を12段階で運ぶ |
| いちばん下（コピーの設定…）まで下ろしても消えない | 同上 |
| 親の別項目の上を斜めに横切っても消えない | 親の項目へ戻してから、子の最下段へ24段階で一気に |
| 別の項目に留まれば子は閉じる | 親の別項目へ運び、消えるまで待つ |
