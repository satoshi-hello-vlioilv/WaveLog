# §9.467 立体図の刃組台車の足まわりを組み立てとして成り立たせる／機体は実機の緑（利用者の指示）

索引: [決定記録](README.md)

## 利用者の言葉

> 刃組ガイダンスの立体図の刃組台車について、構造的な破綻がないかもチェックしてください。台車側に
> レールに沿う機構がないのに回転台の部分に入ったり、寧ろレールに干渉しそうなオブジェクトも配置して
> あったり、台車の写真(入側からの見た目でフィンガー使用中でフィンガーの押さえ用のアングルも写っている)
> も添付するので色合いなども含めてわかる部分も少し修正してください。

## 点検した結果（組み立てている寸法から）

| 破綻 | 何が起きていたか |
| --- | --- |
| 回転テーブルの甲板 | 甲板の上面が床から 120mm 突き出し、**レールの頭より 68mm 上**。甲板の上のレールは円盤の中に埋まり、走ってきた車輪が甲板へ沈んでいた |
| 車輪 | 半径 70 で上端が台座の下面へ 4mm 食い込み、台座（奥行き 760）の中に**車輪の幅が 96mm 隠れていた**——「レールに沿う機構が無い」台車に見えた |
| 台座の下の箱（スカート・リブ） | 奥行き 610／600 で、**レールの頭の真上 20〜24mm** にかぶさっていた（当たりそうに見える） |
| 回転の中心のブロック | 甲板の上へ 130mm 突き出し、甲板へ載った台車の下の箱と当たる高さだった |

## 直したこと

- 甲板を**床と面一**にし、甲板の上のレールを床のレールと同じ高さに（走ってきた車輪がそのまま乗り移る）。
  中心のブロックは甲板と面一の薄い蓋。甲板は現場の設備なので鋼の色。
- 車輪の半径を 65 に（台座の下面より下に収まり、車輪が見える）。レールの高さ（図面の 216）は変えない。
- スカート・リブの奥行きを 480／460 に（**車輪の内側**に収め、レールの頭の真上から外す）。
- 機体の塗装を**実機の写真の緑**に、ギヤボックスの上のカバーを黄色に（`PAINT`の1箇所・骨組みと
  現場まわりが同じ値を使う）。照明で明るく飛ぶので写真より一段暗く持つ。
- **フィンガー方式のときだけ**、入側（−Z）の上下にフィンガーの押さえのアングル（L形・有効長いっぱい・緑）を
  渡す。寸法は写真からの概寸（図面に無い）。機械まわりの`rig`に置くので断面図では伏せる。

| 物差し（`view().rig`・どれも0が正・mm） | 前 | 後 |
| --- | --- | --- |
| 甲板がレールの頭より上に出ている量 | 68 | 0 |
| 台座の下の箱が車輪の幅へ食い込んでいる量 | 96 | 0 |
| レールの頭の真上ですき間30mm未満の箱 | 2 | 0 |
| フィンガーの押さえのアングル（フィンガー方式） | 0 | 2 |

### 分からないこと

アングルの本数・高さ・形は写真から読める範囲の概寸で、**図面の寸法ではない**。フィンガーそのものの
形（板状の押さえ）は今までどおり軸の上の輪で描いている（§9.377 の保持層の描き方のまま）。
