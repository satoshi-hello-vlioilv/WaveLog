# §9.335 知識の置き場を「規則」と「経緯」に分ける（REVIEW 3-11）

## 何が問題だったか

同じことを**2つのファイルが別の言葉で**持っていた。

| | 大きさ | 中身 |
| --- | --- | --- |
| `CLAUDE.md` | 698,660 bytes / 6,946行 / 474項目 | 規則＋経緯が1項目に混ざっている |
| `docs/SCHEDULE_MODE_DESIGN.md` | 1,602,422 bytes / 22,341行 | §1〜§8 はスケジュール設計、§9 が287節 |

問題は3つ。

1. **「いま守るべき規則」を探すのに480項目の物語を読むしかない。** 1項目が
   最大63行あり、40行を超えるものが6件。人にもAIにも同じ負担が掛かる。
2. **設計書の名前と中身が食い違っていた。** 「スケジュールモード 詳細設計」の
   §9（287節）は、測定画面・帳票・一覧・起動・共有…と**スケジュールと関係の
   無いもの**が大半で、しかも**164節は §13 未決事項より後ろに積まれていた**
   （章の中にすら入っていない）。
3. **2つを手で同期していた。** 実測すると、CLAUDE.md が参照している §番号のうち
   **30番号は設計書に節が無い**（規則だけ足して節を書かなかった回）。うち7つは
   コードからも参照されており（§9.320 は18ファイル）、番号が解決しない。

## 決めたこと

- **`CLAUDE.md` … 規則の表だけ。** 「守ること／固定する網／くわしく」の3列で、
  触る場所ごとに13の束へ分けた。行は**見出しの1行**——なぜ・実測値・撤回した
  案・踏んだ罠は書かない。
- **`docs/decisions/9.xxx.md` … 経緯。1節1ファイル。** §番号は**振り直さない**
  （コード・テスト・CLAUDE.md から番号で参照されている。実測 11,764箇所）。
- **`docs/SCHEDULE_MODE_DESIGN.md` … スケジュール機能そのものの設計**（§1〜§8・
  §10〜§13）だけを残す。

結果:

| | 前 | 後 |
| --- | --- | --- |
| `CLAUDE.md` | 698,660 bytes / 6,946行 | **80,919 bytes / 759行**（-88%） |
| 40行を超える項目 | 6 | **0**（表の1行は最長125字） |
| `SCHEDULE_MODE_DESIGN.md` | 1,602,422 bytes / 22,341行 | **123,374 bytes / 1,534行** |
| 決定記録 | （無い） | **296ファイル** |
| 索引から辿れない節 | 14番号 | **0** |

## 踏んだ罠（split の作り方）

- **節の境目を「次の `##+` 見出し」で切ると中身が取り残される。** `### 9.x` の
  中には `####` が587箇所あり、`## §9.29x` の中には `### ①` がある。素朴に
  切ると**残る本文が15,423行**（＝12,888行が節から漏れて設計書に居座る）。
  境目は「**次の §9 節の頭**か `#`/`##` の見出し」——素の `###` では切らない。
  それでも §9.288/§9.291 は小見出しが `###` のままなので、レベルだけで切ると
  **その2節が空になる**（実際に空で出た）。
- **コード柵の中の `# ` を見出しと数えない。** 実測5行（§3.3 の中）。いまは
  §9 の外だが、柵の中に `# コメント` を書いた節を足せば静かに切れる。
- **移したあとは「1行も落ちていないこと」を数で確かめる。** 非空行を
  `Counter` で突き合わせ、差は578行——その内訳は「節の見出し287・索引の項目
  271・§0の説明9・章の見出し2」で、**どれも置き換えたもの**だと言い切れる形にする。

## 旧 `test_docindex` は見張れていなかった

索引と本文のずれを見張るテストは以前からあったが、`^### (9...)` しか数えて
おらず、**あとから足された `## §9.29x` 形式の16節を1件も見ていなかった**
（14番号が索引に無いまま放置され、しかも 7/7 PASS）。§9.334 の
`glob('*.js')` と同じ形で、**数え落としは緩む側に壊れる**ので通ったこと自体が
証拠にならない。いまは**ディレクトリの実体と突き合わせる**。

## 網（`tests/test_docindex.py`、`ALWAYS`）

17件。索引と実体の**両方向**（載せ忘れ／実在しない指し先）・題の一致・
戻りリンク・CLAUDE.md の上限と表の形・「くわしく」が全部たどれること・
**表の1行へ本文を書き戻していないこと**（1行90字超で落ちる＝経緯が戻ってきた
合図）・設計書に §9 が戻っていないこと。

欠陥を4つ注いで落ちることを確認した——索引から1件消す／表の行へ本文を書き戻す／
設計書へ §9 の節を戻す／戻りリンクを外す。

## 決定記録の無い§番号は黙らせない

CLAUDE.md や本文が参照しているのに節の無い番号（23件）は、索引の
「決定記録の無い§番号」に並べてある。**辿れないことを黙って放置しない**
（§9.328 と同じ考え方）。うち7番号は CLAUDE.md の規則がその番号の唯一の
出どころだったので、ここで節を起こした。
