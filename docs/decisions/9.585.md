# §9.585 浮き面は「外の」スクロールでだけ閉じる・スピナーは押し続けると続けて動く（利用者の報告と指示）

索引: [決定記録](README.md)｜前: [§9.584](9.584.md)｜関係: [§9.247](9.247.md)・[§9.219](9.219.md)・[§9.250](9.250.md)

## 経緯（利用者の言葉）

> １）操業データ項目マスタの選択肢選び方を「メニュー」にして、スクロールバーを触るとメニューが閉じてしまうバグがあるので修正をお願いします。
> ２）操業データ項目マスタの選択肢選び方のトグルのボタンで、長押しにより連続的に変化する機能も追加してください。

２）は続けて「トグルで無くスピナーの間違いでした」と直された。

## 1. メニューが自分の中のスクロールで閉じていた

**原因**: 浮き面（`メニュー`の`#opfMenu`・数の小窓`.opf-num-pop`・語句の候補）は、開いたまま後ろがスクロールすると
押した欄から離れて浮くので閉じる。その見張りを`window`の`scroll`（**捕捉**）で受けていた。`scroll`は泡立たないが、
捕捉ならどの要素のものも届く——**浮き面の中の一覧をスクロールバーやホイールで送っても閉じていた**。3か所とも同じ書き方。

**物差し**: 浮き面ごとに「中のスクロールで開いたまま（良）」「外のスクロールで閉じる（良）」の2点。設定窓の見本で
メニューと数の小窓（早見ボタン）を開いて数えた。**直す前 2/4 → 直した後 4/4**（中のスクロールで閉じていた2点が直った）。

**直し方**: `closeOnOuterScroll(pop, close)`の1箇所（`measure-opdata.js`）——出どころ（`e.target`）が浮き面の中なら閉じない。
3つの浮き面がここから使う。語句の候補は開くたびに見張りを足していた（打つたびに1本増えていた）ので、前の見張りを外してから付ける。

網: `test_opwidget.js` の 9)（40件のメニューを本物のホイールで送る→開いたまま／外のスクロール→閉じる）。欠陥注入（中の判定を外す）で落ちることを確かめた。

## 2. スピナーは押し続けると続けて動く

**物差し**: ▲を1.5秒押し続けたときに値がいくつ進むか・上限で止まるか・1回押し／鍵盤の Enter が1つずつか。
**直す前 +1（1.5秒でも1つ）→ 直した後 +24**・上限30でちょうど止まる・1回押しと Enter は1つずつ（変わらず）。

**作り**: 押し続けるのは`WL.base.holdRepeat(btn, fn)`の1箇所（`base.js`）。押した瞬間に1回、400ms 待ってから110ms ごと、
続けるほど間が詰まる（40ms まで）。離す・外れる・取り消す・窓を離れると止まり、`fn()`が`false`（動かなかった＝上下限）でも止まる。
鍵盤（Enter／Space）と`el.click()`は1回ずつ（`click`の`detail`が0）。マウスの`click`は押下で済ませてあるので捨てる。

**マスタの数の欄**（`master-maint.js`の − ＋）が同じことを自前（400ms・60ms 一定）で持っていたので、同じ1箇所へ移した
——「押し続ける」を2つの速さで持たない。測定画面・設定窓の`ステッパー`（−／＋）も同じ道（`[data-opstep]`）なので同じく続けて動く。
ボタンの説明（`title`）に「押し続けると続けて増えます／減ります」を添えた（推測させない）。

網: `test_opwidget.js` の 10)（1回押しは1つ・押し続けると5以上・上限12で止まる）。欠陥注入（くり返しを止める）で落ちることを確かめた。
