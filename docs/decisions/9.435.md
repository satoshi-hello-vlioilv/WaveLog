# §9.435 CLAUDE.md は「汎用（利用者の恒久指示）」、`.claude/rules/` は「個別」（利用者の指示）

索引: [決定記録](README.md)

利用者の指示:

> CLAUDE.mdの内容には汎用的なルールで私が指示した内容を置き、個別のルール的な
> 部分はrulesにまとめるようにお願いします。逆にrulesにまとめてしまったが、
> 汎用的なものに関してはClaude.mdへ戻して適用しやすい形に修正してください。

## 何が問題だったか

[§9.414](9.414.md) では **「量」で分けた**——CLAUDE.md が995行まで戻っていたので、
規則の行を `.claude/rules/` の15枚へ移し、入口を111行にした。分け方の軸は
「表かどうか」であって、「汎用か個別か」ではなかった。

その結果、**すべての作業に常時かかる利用者の恒久的な指示までリンクの先へ出て
いた**。効きの差は実際に大きい:

| 置き場 | Claude が読むタイミング |
| --- | --- |
| `CLAUDE.md` 本体 | **毎回・自動** |
| `[...](.claude/rules/x.md)` | **開いたときだけ**（規律で担保・§9.414） |

つまり**「常時かかる」と書いてある基準が、常時は読まれない場所に在った。**
`ui-principles.md` は見出しに「利用者からの恒久的な指示」「すべての画面に
常時かかる」と2度書いてあり（同じ文が5〜7行目と14行目に重複していた）、
それ自体が置き場の誤りの訴えだった。

さらに、利用者が繰り返し言っている恒久的な指示のうち**3つがどこにも書かれて
いなかった**——①直す前に評価関数で測る ②誤りの認め方・「分からない」と書く
③コード設計の基準（汎用的・論理的・共通化・メンテナンス性・速度とPC前提）。
毎回の会話の設定には在っても、**リポジトリ側の記録には無い**ので、
決定記録からも規則からもたどれなかった。

## どう分け直したか

**軸を「量」から「効く範囲」へ変えた。**

- **CLAUDE.md（187行）＝ 汎用。** 利用者からの恒久的な指示で、
  **すべての作業・すべてのコード・すべての画面に常時かかるもの**だけを本文で持つ。
  - 作業の進め方 A〜E（A・B は既存、**C 評価関数で測ってから直す**、
    **D 誤りの認め方と「分からない」**、**E 見た目が変わる変更は都度確認**を足した。
    E は `docs/REVIEW_2026-09.md` の参照文の括弧の中に埋もれていたものを出した）
  - **コードを書くときの基準**（新設）
  - **画面を作るときの基準**（`ui-principles.md` から戻した14項目）
  - 3つの置き場の使い分け（`testing.md` の表にあった3行を戻した）
  - バージョン更新（`misc.md` の1行を戻した。全作業にかかるため）
- **`.claude/rules/`（793件・15枚）＝ 個別。** 領域ごとに「触る前に開く1枚」。
- **`ui-principles.md` は残した**が、中身は
  **「基準をWaveLogの寸法へ落としたもの」だけ**にした——基準1の1/3、
  基準11の `fitControlWidths()`・`--w-*` の丸め・実測19種、基準13の
  横4×縦3・437×307px・形6種、基準12のタブ5枚。
  **判断の基準は CLAUDE.md、当てはめる数はこちら**、という分担にした。

## ついでに直した食い違い

- CLAUDE.md の「726件」は**実際には797件**だった（§9.414 当時の数のまま。
  数え直すと、726 は `style.md` までの途中経過と一致する）。
- `bladeset.md` の見出しが **131件（実際は132）**——[§9.434](9.434.md) で
  1行足したときに見出しを直し忘れていた。
- Git の節に**古いブランチ名**（`claude/report-block-resize-bug-my9cj8`）が
  残っていた。ブランチ名はセッションごとに変わるので**書き写さない**ことにした。
- `ui-principles.md` の「すべての画面に常時かかる」が同じ文で2度出ていた。

## 網（`test_docindex.py`）

**足した条件は無い。** 既存の条件がそのまま効く——CLAUDE.md は200行以下
（187行）、3列の規則表を書き戻していない、入口から15枚すべてへ行ける、
どの1枚からも索引と入口へ戻れる、表の行は「くわしく」つき・90字以内・重複なし。
