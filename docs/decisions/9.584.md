# §9.584 置いてある版を消す——消すのは「版を整理する」の整理中だけ・配っている版は消せない（7案→組合せ7案から C4・利用者の指示）

索引: [決定記録](README.md)｜前: [§9.583](9.583.md)｜関係: [§9.555](9.555.md)・[§9.556](9.556.md)・[§9.559](9.559.md)

## 経緯（利用者の言葉）

> 配布する版の管理を行う画面で版を消すこともできるようにしてください。

画面は マスタ管理 → 共通設定 → 「アプリの更新」（`static/js/master/master-update.js`）。版は置くたびに共有の置き場
（`versions/<版>/`・1版あたり約15MB・200ファイル）へ溜まり、画面から減らす手段が無かった（共有のフォルダを手で消すしか
なかった）。手で消すと**配っている版まで消せてしまい**、そのとき全 PC の更新が止まる。

## 1. 物差し（評価関数）と、直す前の値

**サーバー**（`tests/test_appupdate.py` の 11）: 次の11項目を満たす数。直す前は **0/11**（消す関数が無い）、直した後 **11/11**。
配っている版は消せない（次の一手を言う）・前に配った版は消せる・消した版は置き場と一覧から消え消しかけも残らない・
配る版は変わらない・無い版は断る・置いてある版でない字（道）は断り置き場の外を消さない・消した版は配れない・
**消している間に別の PC が配る版にしたら名前を戻して断る**・消し切れなくても一覧から外れ理由を言う・消しかけは次の片付けで消える。

**画面**（1728×1152 と 1536×864 で撮って数えた）:

| 測るもの | 直す前 | 直した後 |
| --- | --- | --- |
| 画面から消せる版（配っている版のほか） | 0 / 4 | 4 / 4 |
| 「この版を配る」と「消す」が同じ行に並ぶ数 | — | 0（整理中は配るを伏せる） |
| 消すまでの手数 | — | 3（整理する→消す…→確かめの窓の「消す」） |
| 置いてある版の合計の量が見えるか | 見えない | 「置いてある版 5・合計 75.8 MB」 |
| 配っている版が消せない理由を字で言うか | — | 行に「配っている版は消せません」 |

## 2. 7案を撮って2回採点した

採点の基準と重み（撮る前に決めた）: 誤操作の安全25（配ると消すの距離・手数）・見つけやすさ20（探させない・目的を果たせる）・
字で言う情報20（空く量・消せない理由）・既存の作法との一貫15・画面の負荷20。実画面の表へ当てて 1728×1152 で撮った。

1回目（5案＋方向の違う2案）:

| 案 | 中身 | 点 |
| --- | --- | --- |
| A | 行末の「この版を配る」の隣に赤の「消す」 | 55 |
| B | 行末に ⋯ → 浮く面に「版を消す…」 | 78 |
| C | 離れた列に 🗑「消す…」 | 75 |
| D | 印を付けて「選んだ N 版を消す…」（まとめて） | 77 |
| E | 表の頭に「置いてある版 N・合計」＋「版を整理する…」。整理中だけ行に「消す…」、配るは伏せる | 85 |
| F（別方向） | 表の下に「配っている版と前の版のほかに N 版・x MB」＋まとめて消す | 80 |
| G（別方向） | 行を押して選ぶ → 下の帯に「この版を配る」「この版を消す…」 | 81 |

1位 E が85点で2位 G と4点差（5点未満）なので2回目へ（はじめ F だけと比べて「5点差」と読み違えた。G を見落としていた）。

- A は §CLAUDE 5（危ない操作を主要動線に置かない）にそのまま反する。
- D の印（チェックボックス）は、行の印を押す物にしない約束（§9.363）と、データ一覧の「行を押して選ぶ」（§9.558）の両方と食い違う。
- F は「この1版だけ消したい」（例: 不具合のあった前の版）ができない。G は行を押すまで操作が1つも見えない（探させる）。

2回目（組合せ4案＋前の上位3案）:

| 案 | 中身 | 点 |
| --- | --- | --- |
| C1 | E＋整理中の頭に「消せるのは N 版・x MB」＋「消す…」に量を添える | 83 |
| C2 | B＋E の頭（⋯ の面で消す・合計を頭に） | 79 |
| C3 | G＋E の頭（行を選んで下の帯・合計を頭に） | 83 |
| **C4** | **E＋整理中の頭に「消せるのは N 版・x MB」（F の「空く量」）＋表の下に戻す道の一文** | **86** |
| E・G・F | 前の上位 | 85・81・80 |

C1 は「消す…」の量が「中身」の列と同じ数を2度言う（§CLAUDE 8）ので負荷を減点した。C4 に決め、**表の下の一文は外した**——
同じこと（各 PC の手元の版には触らない・同じ版の ZIP で戻せる）を確かめの窓が言うので、2か所に出すことになる（§CLAUDE 8）。

## 3. 決めたこと

- **消すのは整理中だけ。** 表の頭（`.au-list-head`）が「置いてある版 N・合計 x MB」と「版を整理する…」を持つ。整理中の頭は
  「消せるのは N 版・x MB」（配っている版のほか）も言う。押すと
  行の「この版を配る」が伏せられ、代わりに「消す…」（赤の字と縁）が出る。配っている版の行は「配っている版は消せません」。
  消せる版が1つも無いとき（配っている版だけ）・置ける権限が無いとき・版を置いている最中は入口を出さない（§CLAUDE 4）。
  消せる版が尽きたら整理を自分で終える。
- **確かめの窓は消す量・取り消せない・戻す道を言う**（前に配った版なら「選び直して戻せなくなる」、この PC の版なら
  「手元の写しで動くので動き続ける」、どれも「同じ版の ZIP をもう一度置けば戻せる」）。決定のボタンは「消す」で危ない色。
- **消し方**（`app_update.delete_version()`）: ①置いてある版でなければ断る（字は`versions()`の答えと比べる＝道を受けない）
  ②配っている版なら断る ③`versions/.<版>.<pid>.del`へ名前を変える（ここで一覧から外れる）④配る版を読み直し、その間に
  別の PC が配る版にしていたら名前を戻して断る ⑤中身を消す。消し切れなかった残りは一覧に出ず、次に開いたときに
  `sweep_partial()`が片付ける（消しかけは誰も書き足さないので古さを問わない。書きかけ`.tmp`は従来どおり1時間より古い物だけ）。
- 誰がどの版を消したかはサーバーのログに残す（取り消せない操作）。消せるのは置く・配ると同じ`app:release`の区分だけ。
- 各 PC の手元の版には触らない（窓の`update.rs`が置き場から写すのは配る版だけ）。

## 守ること（規則の本文）

- 版を消すのは`app_update.delete_version()`の1箇所。配っている版は断り、名前を変えてから消す（消している間に配る版に
  選ばれたら戻す）。消しかけ（`.del`）は`sweep_partial()`が古さを問わず片付ける。網は`test_appupdate.py`。
- 画面で消すのは「版を整理する」の整理中だけ（ふだんの行は「この版を配る」だけ・整理中は配るを伏せる）。網は`test_appupdateui.js`。
