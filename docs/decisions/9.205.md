# §9.205 帳票の「揃い」は内訳と合否を切り替える／等級はその紙のレコードから引く（利用者の指示）

> 「帳票データの修正も必要です。内訳と合否両方(デフォルト)と内訳のみ、
>  合否のみを切り替えほしいです。」

### 何が問題だったか

§9.203〜§9.204で丈ごとの揃いを6項目（エッジ形状・発生位置・規則性・方向・
ピッチ・値）で記録するようにしたが、**紙に出ていたのは合否(OK/NG)だけ**
だった。のこぎり状なのかテレスコープ状なのか、どこに何mm出たのかが紙からは
分からず、記録した内容の大半が紙に載っていなかった。

### 決めたこと

- **出し方は3つ。** 内訳と合否（既定）／内訳だけ／合否だけ。
- 保存先は**列レイアウトマスタの`formats`**（対象`report:<設備>`）。§9.169で
  「行と列の入れ替え」に使っているのと同じ欄で、丈別データは転置を持たない
  ので競合しない。**新しいマスタもキーも作らない。**
- 切り替えは**塊の編集（組み換え中にダブルクリック）**の中。1回決めるだけの
  設定なので、操作帯には出さない（§1 面積は頻度×重要度）。
- 内訳は**1セルの中**へ「ラベル 値」で並べ、**この欄だけ折り返す**
  （他の列はnowrap＋省略記号だが、「のこぎり…」では形状が読めない）。
  列幅はcolgroupが回す——6等分のままだと1行に2〜3文字しか入らない。
- **空欄は出さない**（異常が無い丈ほど行が高くなる）。ピッチと値は**単位付き**。
- **合否を出すときは根拠の一文も出す**（切断面の等級と基準、客先の個別要求は
  見ていないこと）。**内訳だけのときは出さない**——合否を載せていないのに
  基準の話をしても読む相手が居ない。

### 直した不具合（2件）

1. **等級を`S.measure`から引いていた。** `judgeProductRow()`は
   「いま開いている測定」の`qualityGrades`を見るので、帳票から呼ぶと
   **別のロットの等級で判定**してしまう（一括印刷は複数ロットを続けて
   流し込むので、途中から全部同じ基準になる。§9.174の`rpActiveTarget`と
   同じ壊れ方）。`judgeProductRow(r,grades)`のように**等級を渡せるように**し、
   帳票は`x.qualityGrades`を渡す。既定は今までどおり`S.measure`。
2. **`formats`へ文字列を入れていたので保存されていなかった。**
   サーバーの`normalize_format()`は**辞書以外をNoneへ落とす**ため、
   `formats[k]='転置'`と書くと画面では効くのに保存だけが黙って消える
   ——**「行と列の入れ替え」は一度も保存されていなかった**（押した瞬間は
   変わるので、開き直すまで気づけない）。書式の`pattern`（60字まで）へ
   入れて往復させる。読む側は文字列も受ける（stageは素通しなので、
   保存前の値は文字列のことがある）。

固定は`tests/test_rpblocks.js`。**確かめるときは等級の違う2件を用意する**
——1件だけでは「等級を見ていない（＝どちらも基準なし）」と「1つの等級しか
見ていない」を見分けられない。

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **帳票の`formats`へ文字列を入れないこと**（§9.205）: サーバーの
  `normalize_format()`は**辞書以外をNoneへ落とす**ので、`formats[k]='転置'`と
  書くと画面では効くのに**保存だけが黙って消える**——「行と列の入れ替え」は
  一度も保存されていなかった（押した瞬間は変わるので開き直すまで気づけない）。
  書式の`pattern`（60字まで）へ入れて往復させる（`rpPatternPatch()`）。
  丈別データの「揃い」欄も同じ仕組みで**内訳と合否／内訳だけ／合否だけ**を
  切り替える（既定は両方）。**判定に使う切断面等級はその紙のレコードから引く**
  ——`judgeProductRow(r,grades)`の第2引数を渡し忘れると`S.measure`＝いま開いて
  いる測定の等級で判定し、**一括印刷では途中から全部同じ基準**になる
  （§9.174の`rpActiveTarget`と同じ壊れ方）。**確かめるときは等級の違う2件**を
  用意する（1件では「等級を見ていない」と「1つしか見ていない」を見分けられない）。
  固定は`tests/test_rpblocks.js`。
