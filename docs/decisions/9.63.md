# §9.63 パネル見出し(.rp-head)にスタイルが無かった

ダッシュボード・実績カレンダーの見出し周りが崩れて見えていた原因は
単純で、**`.rp-head` `.rp-sub` `.rp-btn-primary` `.rp-btn-secondary`の
CSS定義が1行も無かった**。`<h2>`のブラウザ既定マージンと素の`<button>`が
そのまま出ていた(calendar-view.jsの冒頭コメントは「ダッシュボードと同じ
視覚語彙(.rp-head, .rp-btn-*)を踏襲」と書いているが、その定義自体が
存在しなかった)。

データ一覧(`.record-dialog>header`)と同じ濃色バンドへ揃え、ボタンは
ヘッダーの`.hd-btn`と同じ寸法トークン(`--ctl-h`)で定義した。
