# §9.500 小計の設定を組み直す——畳む段・決める順の番号付きの節・見出しつきの表・見本（利用者の指示）

索引: [決定記録](README.md)

## 経緯

利用者の指示「小計の表示設定については使いづらいので、UIを再構築し、認知心理学、情報アーキテクチャ、整列して整って
いる感じと統一感も意識してUIUX設計を行い、使いやすいわかりやすいものにしてください」。

## 測った（`tests/test_scsubtotal.js`・集計5つ＋式1つ）

| 物差し | 前 | 後 |
| --- | --- | --- |
| 節の並び | 「小計・出し方・集計の項目」（区切りに名前なし・出し方が集計より前） | 出す→区切り→集計の項目→出し方（番号つき） |
| 集計の項目の見出し | 0（欄は5つ） | 7（名前・列・集計・桁・単位・見本・×） |
| 見出しと欄の左端の差 | 測れない（見出し無し） | 0px（5列とも） |
| 見本の値 | 無い（表を見に行くしかない） | 設定の中に出る（2,001kg*） |
| 「表示」の中で小計が占める高さ | 412px（出していれば常に） | 畳めば49px（見出しにいまの状態） |

## 決めたこと

1. 小計は「表示」の**畳む段**（行の色とアイコンと同じ部品）。見出しに**いまの状態**（「製造調質の値ごと・6項目・行」
   ／「出していません」）を書く（思い出させない）。
2. 中身は**決める順の番号付きの節**（①出す→②区切り→③集計の項目→④出し方）。節の名前の列は固定幅、どの節も同じ部品
   （`.sc-st-step`）。出していないときは①だけ（次にすることを1つだけ指す）。
3. 集計の項目は**見出しつきの表**。見出しと欄は同じ格子（`.sc-st-grid`）に載る。**見本**は数として読めた値がいちばん
   多い区切りでの値（どの区切りかは見出しに書く）。「件数」は読めない区切りでも0を返すので、値の有無では選ばない
   （最初はそれで読める値の無い区切りが選ばれ、見本が「—」になった）。
4. 式の誤りは見本の欄に字で出し、**行の高さを変えない**（選んでも動かない）。
5. 「表示」の畳む段の開け閉めは**`SC_VIEW_ACCS`／`setViewAcc()`の1箇所**。開けたら他を畳む
   （以前は段ごとに別の配線で2つ開けたままにでき、注記の「開くのは常に1つ」と食い違っていた）。
6. 描き直しは1回（`updateViewMenuUi()`が開いた段を描き直す）。描き直しの最中に届いた変更は受けない
   （消える欄のフォーカス外れが変更として入り直し、入れ子の`innerHTML`の差し替えで例外になった）。
