# §9.261 設定ページを段（タブ）と畳みで組み直す（利用者の指示）

> 認知心理学に基づきSPAをベースにわかりやすく使いやすいようにタブと
> アコーディオンを主構成にして再構成して、不具合も修正してください。

共通設定は**縦に1本の長いスクロール**で、実測2768pxを736pxの器で見ていた
（4回ぶんスクロール）。測定データの保存は3段を**横に並べて**いたため、
1366pxの画面では1段が204pxまで痩せ、値が「未設定（…」「08/28 15:2…」と
**切れていた**（利用者の報告「コンテンツのみ切れもある」）。

**章は段（タブ）にする。** 組み立ては`pageTabsHtml()`で、**編集窓と同じ受け皿**
（`.mm-tabbar`/`.mm-tabpanel`/`bindMaintTabs`）を使う——別の作りを持つと、
段の見た目とキーボード操作が画面ごとに違うことになる（§9.163と同じ理由）。
結果、共通設定は**2768px → 736px**（1画面に収まる）。

**よく触らない設定は畳む**（`pageFoldHtml()`）。ただし**畳んだままでも
「いま何が効いているか」を見出しに出す**（§3・§9.125）——`pcNowText()`が
保存値→既定の順に落として名乗る。隠したものを何も書かずに隠すと、設定の
存在ごと忘れられる。

**測定データの保存は1行1段。** 横に並べると矢印2本が240pxを取り、盤が
狭いと値の欄が43〜72pxしか残らない（実測）。縦に積めば値は切れず、
流れも上から下で読める。`.ms-kv dd`の省略記号もやめた——切ると
**打つ手の書いてある側**（「未設定（複製しません）」）が消える。

**踏んだ罠が3つ。どれも1つ直しただけでは絵が変わらない。**
 1. `.mm-form`は**縦積みのflex**（`flex-direction:column`）。段の帯へ
    `flex:1 0 100%`を渡すと`flex-basis:100%`が**高さの100%**を指し、
    札1枚が543pxの空箱になる（§9.253 ①・§9.254 ①と同じ罠）。
    **`flex:0 0 auto`＋`width:100%`**にする。
 2. `is-page`を`.mm-form >`で絞ると**共通設定では当たらない**（あちらは
    `.mm-set-scroll`の中）。この印は段専用なのでクラスだけで当てる。
 3. `.mm-tabpanel.is-page{display:flex}`は`.mm-tabpanel[hidden]{display:none}`と
    **詳細度が同点**で、あとに書いたこちらが勝つ——段を切り替えても
    全部の章が出たままになる（§9.206と同じ形）。
    `.mm-tabpanel.is-page[hidden]{display:none}`を足す。

**確かめるときの落とし穴**: テストは**段の名前で開くこと**（番号だと段が
1つ増えただけで落ちる）。段の中の欄は`waitForSelector`が**見えるまで待つ**
ので、畳んだ段のidを待つと必ずタイムアウトする——器が出ることで見る。
固定は`tests/test_setpage.js`・`tests/test_measstore.js`・`tests/test_pcshare.js`。

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **設定ページは段（タブ）＋畳み（アコーディオン）**（§9.261、利用者の指示
  「認知心理学に基づきSPAをベースに…タブとアコーディオンを主構成にして再構成」）:
  組み立ては`pageTabsHtml()`／`pageFoldHtml()`で、**編集窓と同じ受け皿**
  （`.mm-tabbar`/`.mm-tabpanel`/`bindMaintTabs`）を使う——別の作りを持つと
  段の見た目と動きが画面ごとに違うことになる。共通設定は実測**2768pxが736px**へ
  （1画面に収まる）。**畳んだままでも「いま何が効いているか」を見出しに出す**
  （§3・§9.125。`pcNowText()`が保存値→既定の順に落として名乗る）。
  **`.mm-form`は縦積みのflex**なので、段の帯へ`flex:1 0 100%`を渡すと
  `flex-basis:100%`が**高さの100%**を指し、札1枚が543pxの空箱になる
  （§9.253 ①・§9.254 ①と同じ罠）——**`flex:0 0 auto`＋`width:100%`**にする。
  **`is-page`はクラスだけで当てる**（共通設定は`.mm-set-scroll`の中なので
  `.mm-form >`では当たらない）。**`.mm-tabpanel.is-page[hidden]{display:none}`を
  必ず足す**——`[hidden]`と詳細度が同点で、あとに書いた`.is-page`が勝つと
  段を切り替えても全部の章が出たままになる（§9.206と同じ形）。
  **測定データの保存は1行1段**——3段を横に並べていたため盤が狭いと1段204pxまで
  痩せ、値が「未設定（…」と切れていた（実測1366px窓）。
  **テストは段の名前で開くこと**（番号だと段が1つ増えただけで落ちる）。
  固定は`tests/test_setpage.js`・`tests/test_measstore.js`・`tests/test_pcshare.js`。
