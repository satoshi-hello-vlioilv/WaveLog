# §9.119 列幅: 手で決めた幅が、見出しの文字に押し戻されていた

「列幅を変えられるようにしたが、オートフィットと競合する」という報告。
**推測で直さず実測した**——この種の「効いていない」は原因が複数あり得る。

#### 測って分かったこと

| 測ったもの | 値 |
|---|---|
| colgroupへ入れた指定 | 45px |
| `th`の実測 | **171px** |
| 見出しの文字幅 | 174px |
| `width:min-content`にすると | 45px |
| 見出しを`white-space:normal`にすると | 45px |

犯人は`#grid table{width:max-content}`。`table-layout:fixed`であっても、
**表の幅が`max-content`だと「各列の中身の最大幅」で解かれ**、colgroupの
指定を折り返さない見出しの文字幅が上回る。手で狭くしたつもりが一度も
効いていなかった。

直し方は、`renderGridInner()`が**列幅の合計を表の`style.width`へ入れる**。
指定どおりになり、器より狭いときはCSSの`min-width:100%`が広げるので、
横スクロールの挙動は変わらない。

#### 幅は3つの状態を持つ

```
自動   … 見出しと実データの先頭40行から見積もる（既定）
手動   … 入れた幅にする。**文字の長さによらず狭くできる**
固定   … 手動の幅から動かさない。見出しの取っ手も掴めない
```

以前は「幅の数値が空かどうか」で自動と手動が暗黙に決まっており、画面の
どこにも書いていなかった。**一度触った列を自動へ戻す方法が分からない**
（取っ手のダブルクリックだけ）状態だったので、列の設定パネルと見出しの
右クリックの両方に、いまどれなのかと切り替えを出した。

「自動へ戻す」は**幅の数値も固定も消す**。数値を残すと次に開いたときに
復活して「戻したのに戻っていない」ことになる。逆に「固定」は幅が無ければ
**いま画面に出ている幅**を書き留める——でないと次に開いたとき自動で
別の幅になり、固定した意味が無い。

保存先は列レイアウトマスタの`[幅固定]`（無い古いDBではNULL＝固定なし）。

#### ついでに見つかった実バグ

見出しの右クリックメニューの`persist()`が`formulas`を渡しておらず、
**列を1つ隠しただけで計算式で作った列が全部消えていた**。§9.113で
`bindColumnHeaderTools`の同じ不具合を直したときに、こちらを見落として
いた。全置換の書き漏らしは**同じ形が他にもある**と考えて探すべきだった。

#### 幅を固定して初めて見えた、見積りの数pxの不足

表の幅を合計で固定した途端、**自動で決めた幅の列が4〜5px切れる**ようになった
（用途名70/74・取引先64/69で実測）。`textWidthEm`は字幅の近似なので実測より
わずかに小さく出るが、それまでは`width:max-content`が表を広げて吸収して
いた——つまり**指定した幅で描かれていなかったからこそ、見積りの誤差に
誰も気づけなかった**。自動の見積りは「入り切る」ことが目的なので、
`COL_W_SLACK=6`で誤差ぶんを足す。

固定は`tests/test_collayout.js`（29件）と`tests/test_listperf.js`（22件）。
4つの欠陥（表の幅を入れない／固定した列の取っ手を掴めるままにする／
`formulas`を渡さない／見積りの余裕を0にする）を入れ直して落ちることを
確かめてある。**この不足は通しテストでしか出なかった**——手元で確かめた
のは「狭くできること」だけで、「自動のままの列が切れていないこと」は
見ていなかった。

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **列幅は「自動／手動／固定」の3つ**（§9.119）: 既定は自動（見出しと
  実データの先頭40行から見積もる）。**手動の幅は文字の長さによらず狭くできる**
  ——`#grid table`の幅は`renderGridInner()`が**列幅の合計**を入れる。
  CSSの`width:max-content`のままだと、`table-layout:fixed`でも表の幅を
  「各列の中身の最大幅」で解いてしまい、**colgroupの指定より折り返さない
  見出しの文字幅が勝つ**（45px指定→171px。手で狭くしたつもりが一度も
  効いていなかった）。「自動へ戻す」は**幅の数値も固定も消す**こと（数値を
  残すと次に開いたとき復活する）。「固定」は幅が無ければ**いま出ている幅**を
  書き留める（でないと次に開くと自動で別の幅になり、固定の意味が無い）。
  保存は列レイアウトマスタの`[幅固定]`で、**`save()`へ渡し忘れると解ける**
  （全置換。§9.113）。固定は`tests/test_collayout.js`。
