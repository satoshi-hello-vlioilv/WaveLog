## 1. 物差し（評価関数）と、直す前の値

`master-opdata.js` の設定窓を、選択・数値・組み込みの3つの項目 × 1728×1152／1536×864 で数えた（撮影の道具で実測）。

| 測るもの（1728×1152・選択の項目） | 直す前 | 直した後 |
| --- | --- | --- |
| 常に見えている説明の字数 | 640 | 142 |
| 見えている決めごと／畳んだ決めごと | 25 / 0（同じ重さで平ら） | 11 / 14 |
| 開かずに見える選ばせ方の札 | 0（浮き出しの中） | 15 |
| 削除が決めごとの流れの中にあるか | ある | ない（「外す・消す」の畳み） |
| 欄と見本のつながり（乗せると見本が光る欄） | 0 | 14 |
| 中でスクロールしないと見えない量 | 92px | 0 |

フル HD（1536×864）でスクロールしないと見えない量: 選択 628→3px・数値 510→0px・組み込み 470→31px。数値の項目の常に見えている説明は 543→55字。
12px 未満の字は 21→36 に増えたが、増えたのは選ばせ方の札の中の**絵の字**（見本の数値・図）で、読ませる字ではない（§9.560 の「図の中の字」）。

## 3. 作り

- **列と置き場所の表は`OP_SECS`の1箇所**（`k`・`main`・`more`・`danger`）。行は`data-op-row`で名乗り、組み立て（`opPane*()`）は
  行を作るだけで置き場所を知らない。並べ直すのは`opComposeCols()`（組み立て済みの行を動かすだけ）。表に無い行はその塊の「細かい設定」へ落ちる（載せ忘れても消えない）。
  列の鍵は前と同じ`data`・`look`・`place`（説明の`?`は鍵ごとに積んだ物が出る）。
- **細部の畳みは共通の`pageFoldHtml()`**（§9.583 と同じ器）。見出しは「細かい設定（N）」＋いまの値（`opRowNow()`）。開け閉めは`opState.more`が覚える
  ——押すたびに窓は組み直されるので、覚えないと1回押すごとに畳まれる。危ない操作の畳みは件数も値も言わない。
- **長い説明は ⓘ**（`opTipNotes()`・共通の`tipHtml()`／`WL.popMenu.tips()`）。20字を超える説明だけを畳み、状態の一言と注意の札（`.op-warn-chip`）は見えたまま
  （取り違えを防ぐ事実は畳まない・§9.255）。元の字は伏せて残す（読む網と支援技術のため）。印の「i」は CSS の絵——字にすると行の名前の字に混ざる。
- **選ばせ方の盤は開かずに並べる**（`.op-widget-inline`）。札は絵と名前だけ、説明は札の`title`。行の名前は塊の見出しが持つので伏せる（§CLAUDE 8）。
- **使えそうなまとまり**（名前が似ている・同じ群が使っている）は札1行に（以前は4枚×約75pxの縦の札で、①の主役より背が高かった）。
- **欄に乗せると見本の同じ所が光る**（`OP_HOT`の1箇所・§CLAUDE 15）。選ばせ方・色・大きさ→欄、見せ方→単位、項目名→名前、置き場・幅・群→カード。
- 組み込みの欄の「①『測定画面に出す』へ」は、連れて行く先が畳みの中なら開いてから連れて行く。

網: `test_opui.js`（列の順・盤が開かずに見える・畳みの見出しが値を言う・削除は畳みの中・長い説明が見えたままでない・名前に印が混ざらない・
組み直しても畳みが開いたまま・乗せると見本が光る）。網の「選ばせ方の浮き出しを開く」道具は「盤が見えるまで待つ」へ、細部を触る網は窓を開いたら畳みを開く。
