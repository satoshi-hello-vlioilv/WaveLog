# §9.575 操業データ表は「印刷する／配置を組み替える」のタブで分け、紙の見出しで項目を選ぶ・値のある項目だけ載せる（5案＋複合案から H1・利用者の指示）

索引: [決定記録](README.md)｜前: [§9.574](9.574.md)｜関係: [§9.553](9.553.md)・[§9.186](9.186.md)・[§9.241](9.241.md)・[§9.368](9.368.md)

## 経緯（利用者の指示）

> 操業データ表の印刷機能や操業データ表レイアウト組み替え機能について現状を画像を確認して評価した上で、改良のため更に使いやすくわかりやすく改良して下さい。
> UIUXの改良については、常に改良案を最低5案出し画像を直接比較してスコア化して選択して設計に臨んで下さい。
> 僅差の場合は無理に選ばず、より良さそうな組み合わせ複合案を3つ作り、元案の上位2案を足して再選定をして設計して下さい。

## 1. いまを測る（実画面・A4横・8件・表示列57）

見本の実績8件（操業データ17項目に値）で、測定実績 → 操業データ表 → 配置の盤を撮って数えた。

| 物差し | 前 |
| --- | --- |
| 紙の見出しが…で切れる | 27 / 57 |
| 紙の値が切れる | 7 |
| 空のセル | 60%（399のうち238） |
| 配置の盤の札で名前が切れる | 55 / 57 |
| 使うデータの一覧で名前が切れる | 36 / 73 |
| 盤を開いた間の紙の倍率 | 0.53 |
| 一覧（段組）で値が切れているのに「…」が無い | 84 / 241 |

原因は3つに分かれた。①**全件で値の無い列（34）まで紙と盤に載せていた**（列が細り、見出しと札が切れる）。
②**盤と紙を1枚の窓に積んでいた**（盤が上の320pxを取り、紙が半分の倍率になる）。③一覧のセルが flex の箱で、
字が「…」にならずに切れていた。

訂正: 測る前は「一覧の値が右寄せ（`justify-content:flex-end`）で左から切れる」と見ていたが、数えると左から切れる
セルは0で、本当の問題は③（印の無い切れ）だった。

## 2. 案（5案 → 3点差 → 複合案3つ＋上位2案）

物差し（8項目・重みの合計100）: 項目名が読める15／紙の読みやすさ15／組み替え中の紙の見えやすさ15／1項目を動かす手数10／
真下・幅の正確さ10／作業の分かれ目10／面積10／既存部品の再利用15。2回目は「項目名が読める」「紙の見えやすさ」を
見本の実測（名前の切れた札の割合・紙の倍率）から点にした。

1回目:

| 案 | 中身 | 点 |

| **B 作業でタブを分ける** | 「印刷する」と「配置を組み替える」をタブに。組み替えるタブは盤と紙だけ | **86** |

## 3. 入れたもの

- **タブ**（`#osPvTabs`）: ① 印刷する＝設定と紙（幅と高さに合わせる）。② 配置を組み替える＝左に使うデータ（全高）、
  右に盤 → 帯（件数・できあがり）→ 紙の見本（**幅に合わせる**）。②では印刷の設定と「この内容で印刷」を引っ込める
  （次の一手を1つにする）。盤の器（`.os-pv-board`・`.rcl-wrap`）は`display:contents`で、中の柱を窓の格子へ直に並べる。
- **紙の見出しで選ぶ**: 見出しは`data-k`を名乗り、②で押すと`board.select(k)`。盤が描くたびに`onPaint`で紙の見出しも
  同じ紫で光る（画面だけ・刷る紙には出ない）。選んだ項目の段・位置・幅は**盤の真下の1行**（右の柱は外した）。
- **載せる項目**（①の④）: 「値のある項目だけ」（既定）／「すべて」。答えは`paperKeys()`の1箇所（期間の全件で
  表示の字が空の列を外す・`#`は外さない・件が無ければ外さない）。並び・置いた位置は変えない（外した列のマスは空く）。
  **盤も同じ答え**で載せる項目を決め（`src.skip`）、外した項目は使うデータの一覧に「値なし」と出す。外した名前は畳む。
- **保存していない配置は黙って捨てない**: ②に変更が残っているうちは①へ戻らず、盤の下の1行で「保存」か「やめる」を
  言う（窓の中から窓を開かない・§9.368）。保存すると①へ戻る。
- **段組は最低2段**（`plan()`の`minLines`）: 値の無い項目を外すと1行に入ることがあり、「段組」を押しても1段のままだった。
  段組を選んだとき（`rows:'2'`）と一覧の段組は2段から。既定（`auto`）は今までどおり「紙に入るなら1段」。
- 紙の見出しは**折り返す**（値のセルは1行のまま）。盤の札の名前は**2行まで**。一覧のセルは塊の箱（…が出る）。

## 網（見張り）

- `test_recordlayout.js` 7: ②のタブで印刷の設定と「印刷」を引っ込め紙は0.8倍以上／紙の見出しで盤の同じ項目を選び両方光る／
  保存していない配置があると①へ戻らず字で言う／保存で①へ戻る／載せる項目の既定と、外した数＋載せた数＝表示列の数／
  `minLines:2`なら紙に入っても2段
- `test_opsheet.js`: 段組は値の無い項目を外しても2段以上（`minLines`を外すと落ちる）
- 欠陥注入: 見出しで選ばない・未保存でもタブを移る・`minLines`を無視の3つで網が落ちる（3つを1回に入れたが、落ちた行が
  1対1で対応した）

## 残したもの

- 紙の本文の字（高密度 8.5px）と、表が紙の高さの27%しか使わないこと。字を空きに合わせて大きくするかは、刷った紙を見てから決める。
