# §9.167 屑幅の片寄せを図の上で直す（利用者の指示）

利用者の指示は「屑幅片寄せは、マウス操作で直接屑幅を調節して修正することも
できるように」。§9.160で数値欄（OS側mm）は作ったが、それだけだと**どちらへ
どれだけ寄るのか**を頭の中で図へ翻訳しないと決められない。

条の束の左右の縁につまみを置き、掴んで動かせるようにする。**どちらの縁を右へ
引いてもOS側が広がる**（条の束が右へ寄る＝OS側の屑が増える）ので、覚えることは
「束を動かす」1つだけ。ダブルクリックで均等へ戻る。

- **つまみは作り直さない。** 帯の中身は0.1mm動くたびに`innerHTML`ごと組み直して
  いるので、つまみをそこへ入れると掴んだ拍子に消える（測定の受信欄と同じ罠。§9.122）。
  器（`#splitVisualMeasure`）の子として1度だけ置き、**位置だけ**を毎回書き換える。
- **位置は条の束の実寸から取る。** 屑の帯には`min-width`が効いており、mmの比で
  置くと細い側で境目とずれる。
- **mm/pxも条の束から取る**（`info.slit / stripRect.width`）。指の動きと縁の動きが
  1対1になる。
- 追従は`document`で受ける（列幅の取っ手と同じ。要素の作り直しで切れない）。
- **図が無いロットでは案内も出さない**——屑幅の行は分割の無いロットでも出るが
  （§9.160。器は図の外）、条の帯は分割ありのロットでしか組み立てない。

固定は`tests/test_splitlive.js`。

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **屑幅の片寄せは図の縁を掴んで直せる**（§9.167、`#splitScrapGripOs/Ds`）:
  **つまみは作り直さない**——帯の中身は0.1mm動くたびに`innerHTML`ごと組み直すので、
  そこへ入れると掴んだ拍子に消える（受信欄と同じ罠。§9.122）。器の子として1度だけ
  置き、**位置だけ**を毎回書き換える。位置とmm/pxは**条の束の実寸から取る**
  （屑の帯には`min-width`が効いており、mmの比で置くと細い側でずれる）。追従は
  `document`で受ける。**図が無いロットでは案内も出さない**（屑幅の行は分割の無い
  ロットでも出るが、条の帯は分割ありでしか組み立てない）。
