# §9.213 条の図のロット番号は幅で桁数を変える（利用者の指示）

> 「条の設計のロット番号表示ですが、**条幅が広い場合は、ロット番号全てを
> 表示、幅が狭いものは下2桁表示**としてください。**幅が狭いものかつ異幅
> 切断の場合は下3桁表示**としてください。」

これまで図の中は**下3桁固定**だった（幅が足りなければラベルごと落とす）。
広い条でも下3桁しか出ないので、**余裕があるのに番号を突き合わせる**ことに
なっていた。逆に狭い条では3桁でも入らないことがあった。

段を4つにする（`fitStripLabels()`が**幅ごとにまとめて**決める。同じ幅の条は
必ず同じ段——§9.210 ④の約束はそのまま）:

| 段 | 出るもの |
|---|---|
| `full` | ロット番号（全部）＋幅 |
| `long` | ロット番号（全部） |
| `short` | 末尾だけ（**異幅切断=3桁／等幅=2桁**） |
| `none` | 出さない |

**桁数は描くときに決める。** 異幅切断はロットの種類が増えるので、下2桁だと
違うロットが同じに見える。判定は「その図に条幅が2種類以上あるか」の1点で、
**幅の分からない条は数に入れない**（空欄を1種類として数えると、等幅の
ロットまで異幅扱いになる）。

**両方の書き方をDOMへ置いて、あとで選ぶ。** 片方だけ描いて後から差し替えると
差し替えるたびに測り直しが要る（`fitStripLabels()`が1回で決められない）。
**測る前に前回の段を外すこと**——付いたまま測ると、前回`short`だった条では
全部表示のほうが`display:none`のままで幅0になり、**一度短くなった条は
二度と長くならない**（窓を広げても戻らない）。

固定は`tests/test_splitlive.js`。**2桁と3桁の両方の道を通すこと**——
検証用フィクスチャの分割ロットは切断巾500/480の**異幅**で条は2本しか無く
（子ロットで決まるので横割数を触っても増えない。実際に30を入れても2本の
ままだった）、そこだけでは等幅の道を一度も通らない。等幅は**分割なしの
ロット**（条幅が1種類）を横割数24で狭くして見る。**実際に狭くなっている
ことまで見る**——広いままだと「全部出す」で通ってしまい、短縮の道を
一度も通らない。

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **条の図のロット番号は幅で桁数を変える**（§9.213、利用者の指示）: 段は4つ
  ——全部＋幅／全部／末尾だけ（**異幅切断=3桁・等幅=2桁**）／出さない。
  **入るなら全部出す**のが原則（以前は図の中だけ下3桁固定で、余裕のある広い条でも
  番号を突き合わせることになっていた）。桁数は描くときに決め、判定は「その図に
  条幅が2種類以上あるか」の1点——**幅の分からない条は数に入れない**（空欄を
  1種類として数えると等幅のロットまで異幅扱いになる）。**両方の書き方をDOMへ
  置いてあとで選ぶ**（片方だけ描くと差し替えのたびに測り直しが要る）。
  **測る前に前回の段を外すこと**——付いたまま測ると全部表示のほうが幅0になり、
  **一度短くなった条は二度と長くならない**。固定は`tests/test_splitlive.js`
  （**2桁と3桁の両方の道を通す**。分割フィクスチャは異幅・条2本しか無く、
