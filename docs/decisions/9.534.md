## 2. 当たり得ない条件

### 測った（評価関数）

前は VER2.420.0。物差しはスクラッチの `eval_dead.js`: 20通りのセル（数10・字10）について、**総当たりの正解**
（条件に出てくる値・その前後・あいだ・つなぎ合わせた字を全部試し、1つも当たらなければ「当たり得ない」）と突き合わせ、
画面（保持方式の表の1行目に書く）が何を出すかを数える。

| 物差し | 前 | 後 |
| --- | --- | --- |
| 当たり得ないセル（正解は 12/20） を見分けた | **0/12** | 12/12 |
| 当たり得るセルを誤って「当たらない」と言った | 0 | 0 |
| 直す案を出した ／ 案が当たり得ない・字で読み直すと別の条件になる | 0/12 ／ — | 12/12 ／ 0 |
| 画面: セルに「当たらない」と字で出る | 0/12 | 12/12 |
| 画面: 図（数直線・輪の図） | 0/12 | 12/12 |
| 画面: 「このまま保存すると」 | 0/12 | 12/12 |
| 画面: 押せる直す案 | 0/12 | 12/12 |
| 図の字の重なり・はみ出し | — | 0 |

一部の組だけ当たらないセル（`<0.6 かつ >0.9 または 1.2`）は「一部当たらない」と言い分ける（セルは 1.2 で当たる）。
網: `test_holdpick.js` ⑧（判じる9＋6通り・案・一部・盤・保存前の確かめ・案で置き換わる）。判じる側を壊すと⑧が落ちることを確かめた。

### 決めたこと

- **判じるのは`blade-core.js`の`cellDead()`の1箇所**。判定（`condHits()`）と同じ意味で見る:
  - 数（数の列・値がみな数の仕掛の列）: 条件を区間の並び（`numSet()`）にして、「かつ」の組ごとに重ねる（`meet()`）。空なら当たらない。
  - 字: 値が決まっている組は、その値を残りの条件に当てて見る（`condHits()`そのもの）。決まっていない組は「始まり／終わりが食い違う」
    「含む・始まる・終わる がその否定を抱える」を見る（`textClash()`）。空の欄は「空」「空でない」にしか当たらない（`condHits()`と同じ）。
  - 正規表現は値が決まっていないと判じない（当たり得る側へ倒す。言い過ぎない）。
- **直す案**は当たらない最初の組を置き換えたセル（多くて2つ）: ①「かつ」を「または」に（それで何でも当たるなら「空欄＝問わない」と
  言い換える）②数の上限と下限が逆さなら、そのあいだ（`＜0.6 かつ ＞0.9` → `0.6〜0.9`）。どちらが意図かは画面には分からないので、
  **選ぶのは人**（案ごとに当たる範囲を描いて並べる）。
- **画面**（`rule-table.js`）: セルに「当たらない」／「一部当たらない」を字で出し（色は橙＝直せる注意・§9.338）、頭に「当たらない決まり n行」。
  表の下の盤は左から **いまの条件 → このまま保存すると → 直す案**（する順・§CLAUDE 14）:
  - いまの条件: 数は数直線（条件ごとの帯＋「両方: 重なり無し」・端の●は含む／○は含まない）、字は輪の図（輪が離れて重ならない）。
  - このまま保存すると: その行から下の行の並びを描き、その行を取り消し線で「素通り」させる。答えが**使われない**ことを字で言う。
  - 直す案: 案の字・何をしたか・**同じ目盛りの数直線で当たる範囲**（字は輪の図）・行の読み。押すとセルが置き換わる。
- **保存は止めない**（書いた本人の意図かもしれない）。保存の前に、当たらない行と使われない答えを言って確かめる（「やめて直す」で戻れる）。

## 分からないこと・残したこと

- 3つ以上の条件の組み合わせで、2つずつなら重なるが3つ同時には重ならない字の組（例: 長い前方一致と後方一致と否定の組み合わせ）は、
  `textClash()`が2つずつしか見ないので見逃し得る（数は区間で全部を重ねるので見逃さない）。
- 列をまたいだ当たり得なさ（例: 「板厚 < 0.6」の列と、板厚から決まる別の列の値が両立しない）は見ていない。列どうしの関係を画面は知らない。
