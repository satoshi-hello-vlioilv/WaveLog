# §9.597 UI/UX の改良の手順を改める——5案以上・評価は別のエージェントが画面を撮って現物で・加点と減点の採点表・95点以上になるまで案出しからやり直す（利用者の指示）

索引: [決定記録](README.md)｜前: [§9.596](9.596.md)｜関係: [§9.211](9.211.md)

## 経緯（利用者の言葉）

> CLAUDE.mdのUIUX改良方法を次の方法に更新(変更)してほしいです。
>
> 評価は別エージェントが行い、画面をキャプチャして現物を確認すること。
> わかりやすさ(順序、チャンク、階層化)、美しさ、統一感、使いやすさ(ステップ数、考えさせない、直感的)などUIUXに加点要素と減点要素を決め95点以上を目指してください。
> 最低5案以上出し、評価選定できない場合、必要に応じて再検討で案出しからやり直ししてください。

## 決めたこと

[CLAUDE.md](../../CLAUDE.md) の「作業の進め方」E を次の手順へ置き換えた（前の手順＝7案→組合せ→3回目までは撤回）。

1. 今の画面を撮る（1728×1152・1536×864）。画像で見えたことを根拠に悪い所を挙げ、数は C の物差しで。
2. **採点表を先に決める**: 加点要素（わかりやすさ＝順序・チャンク・階層化／美しさ／統一感／使いやすさ＝ステップ数・
   考えさせない・直感的 など）と減点要素（隠れる・切れる・重なる・同じ情報が2箇所・押せそうで押せない・色だけで言う など）。
3. 改良案は**最低5案**（方向の違う解決策も混ぜる）。案ごとに実画面へ当てて撮る。
4. **評価は別のエージェント**。案の画像を自分で開いて現物を確かめ、採点表に沿って点と理由を返す。作った本人は採点しない。
5. **95点以上**の最高点の1案を入れる（利用者に選ばせない）。無い・選べないときは評価の指摘を踏まえて**案出しからやり直す**。
6. 入れたあとも同じ採点表で別のエージェントが採点し直し、前後と各回の採点を比較のページで見せる。

## 前の手順との違い

| | 前（2026-10-12〜） | 今 |
| --- | --- | --- |
| 案の数 | 1回目7案（5＋方向違い2）、2・3回目は組合せ4＋上位3 | 最低5案。やり直しは案出しから |
| 採点する人 | 作った本人 | **別のエージェント**（画像を開いて現物で） |
| 決める点 | 80点・5点差／90点、3回目は最高点で打ち切り | **95点以上**になるまで |
| 採点の表 | 基準と重み | **加点要素と減点要素** |

作った本人が採点すると、自分の意図を画像の中に読み込んでしまい、現物で見えない所を見落とす（§9.596 では採点の重みの
控えも残せていなかった）。採点表を先に決めて別のエージェントに渡すと、表そのものが記録として残る。
