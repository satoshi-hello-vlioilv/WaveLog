# §9.128 ②測定の「丈位置くらべ」（出ていない丈の値を同じ画面で見る）

②測定は**いま選んでいる丈位置しか出さない**。頭と尾を見比べたいときは
丈を切り替えるしかなく、切り替えると今度はさっきの値が見えない。
§9.126で入力表を条数ぶんにしたことで右側に約430pxが空いたので、そこへ
**同じ項目の全丈位置**を1枚で出す。

| 決めたこと | なぜ |
|---|---|
| 縦＝条、横＝丈位置 | 入力表と同じ並び。読み替えが要らない |
| **いまの丈の列も出す**（薄く敷く） | 「切り替えた先がどこか」を同じ表の中で示せる |
| **公差外はここでも赤くする** | 見えた時点で気づけるのが、この表を出す値打ち |
| 見出しを押すとその丈へ移る | 見えた値へすぐ行ける。丈を動かす道具は`#lengthPos`の1本 |
| 1つも値が無いときは「まだ無い」と書く | 空の表だけでは、壊れているのか値が無いのか区別できない |
| **2列（20条超）のときは出さない** | 場所が無い。無理に入れると入力表が痩せる |

判定は`toleranceDetail(kind,0,項目名)`——**項目名を渡す**こと（§9.125。
渡さないと画面でいま選ばれている項目の公差が当たる）。

固定は`tests/test_msteps.js`。値を注ぎ込んで「出ていない丈の値が見える」
「公差外に印が付く」「見出しで移れる」「2列では出さない」を見る。
**公差の材料ごと注ぎ込むこと**——検証用フィクスチャには公差が無いので、
入れずに見ても壊れていても同じ結果になる。

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **②の「丈位置くらべ」は出ていない丈のためにある**（§9.128、
  `lengthCompareHtml()`）: 縦＝条・横＝丈位置で、**いまの丈の列も出す**
  （切り替えた先がどこかを同じ表で示す）。**公差外はここでも印を付ける**
  ——見えた時点で気づけるのが値打ち。判定は`toleranceDetail(kind,0,項目名)`で
  **項目名を渡す**（§9.125）。丈を動かす道具は`#lengthPos`の`change`1本で、
  ここから直接描き直さない。**2列（20条超）のときは出さない**（場所が無い）。
