# §9.532 スペーサー一体型の空きの目標と潤滑リングの切り替え（利用者の指示）

索引: [決定記録](README.md)

## 利用者の言葉

「潤滑リングは一体型の区間にも載せるとはどういう状態を想定していますか？イメージで見せてもらうことはできますか？
空きは作る作らないを空きの目標値を0で設定するか数値を入れるかの違いで判断するようにしてほしいです。」

半断面の絵（①載せない ②両端に載せる ③空きの目標 2mm）を見てもらったうえでの選択:

- 潤滑リング … **どっちも切り替えて対応できるように**
- 空きの値 … **一体型専用の値を足す**（ふつうのゴムリングの空き 2〜5mm とは別に決める）

## 測った（評価関数）

前は VER2.418.0。物差しはスクラッチの `eval_integ2.js`（一体型だけの設備で 50mm×22条・元板巾1130 を組み、44面を数える）。

| 刃組基準値に渡した値 | 前 | 後 |
| --- | --- | --- |
| 空きの目標 0（既定） | 44/44 面が空き0 | 44/44 面が空き0（変わらない） |
| 空きの目標 2mm: 空きが目標以上の面 | **22/44**（値が無いので効かない） | 44/44（端数0） |
| 潤滑リング「載せる」: 載った本数 | **0** | 44（広い側の22面×両端） |
| 目標 2mm＋「載せる」: 載った本数 | 0 | 40（2面は座のスペーサーを使い切った・断りが名指し） |

網: `test_bladesets.js` ⑥（3件）、`test_bladeset.py`（3件）、`test_partboards.js`（1件）。

## 決めたこと

- `刃組基準値`に3つ: `[一体型空き目標]`（`integGapMin`）・`[一体型空き上限]`（`integGapMax`）・`[一体型潤滑]`（`integLube`）。
  **既定は 0・0・載せない**＝§9.531 の組み方のまま。真偽の呼び名は `STANDARD_FLAG_WORDS` の1箇所（載せる／載せない）、
  切の側は `flags.OFF_WORDS` にも並べた（並べ忘れると「載せない」が入として保存される）。刃組基準値の盤は真偽の字を
  決め打ちせず、欄の選択肢から読む（`flagWord()`）。
- 一体型の帯は `holdBand(M,'integ')`。**目標と上限は別の意味**（目標0＝空きを作らない・上限0＝判定しない）——ゴムリングの帯の
  作り方（上限0なら目標にそろえる）を流用すると、目標だけ入れたとき刻みの都合で少し大きい空きまで名指しする。
- 区間は `integParts()`: 並びは「座 → 一体型 → 空き（普通のスペーサー）→ 座」。**座**は潤滑リングを載せるときだけ、広い側の区間の
  両端に普通のスペーサーで潤滑リングの幅ちょうどを作る（ふつうのゴムリング方式と同じ置き方）。一体型は「区間−座−目標」以内で、
  残りが普通のスペーサーでちょうどに作れる最大（`integFill()`）。座を作れなければその面には載せず、`fit.integSeat`が名指しする。
- 図は並びを `axisRun()` の1箇所から読む（模式図・拡大図・立体図が同じ並び）。刃組表の見出しは「目標 2・12 まで」。

## 分からないこと・残したこと

- 空きをどちらの端に置くか（いまは一体型のすぐ後ろ＝区間の終わりの側）。現場で決まりがあるかは分からない。
- 座のスペーサーが手持ちで作れないとき、別の組み合わせ（5＋5 など）まで探すのは `fillWith()` の答えに任せている。
