# §9.414 CLAUDE.md を入口だけにし、規則を `.claude/rules/` へ分ける（利用者の指示）

索引: [決定記録](README.md)

利用者の指示:

> CLAUDE.mdは、200行以下目標だそうです。`.claude/rules/` による分散管理も
> 活用したいです。（スリム化の4つのルール: ①現在のタスクと終わったタスクを
> 分離 ②コードは貼らずファイルパスだけ ③外部ドキュメントへ責務を分散
> ④AIの常識は書かない）

## 何が問題だったか

§9.335 で「規則＝CLAUDE.md の表／経緯＝`docs/decisions/`」に分け、
本文の物語は決定記録へ逃がした。それでも **CLAUDE.md は 995行・122,867バイト**
まで戻っていた——**逃がしたのは本文だけで、規則の行そのものは1枚に積み続けた**
からである（691行の表）。上限は `test_docindex.py` の `CLAUDE_MAX = 120KB` で、
**残り 13バイト**。1行足せば落ちる状態だった。

このとき「似た規則を束ねれば空く」（案C）を測ったが、**空かないことが分かった**:

| 測ったこと | 結果 |
| --- | --- |
| 完全に同じ規則 | 0件 |
| 似ている規則（Jaccard ≥ 0.42） | 4組だけ |
| 説明の括弧（削れる散文） | 16箇所・605バイト＝表の 0.6% |

つまり**表は既に絞り切られていて、削る脂肪が無い**。減らせないものを
1枚に置き続ける限り、上限との追いかけっこは終わらない。**置き場を分ける
以外に道が無い。**

## どう分けたか

- **CLAUDE.md（111行）は入口だけ**。持つのは「作業の進め方 A・B」（利用者の
  恒久指示・最優先なので**本文のまま残す**）、規則の置き場の索引、よく使う
  コマンド、参照先、Git。
- **`.claude/rules/*.md`（15枚・688行）が規則の本体。** 領域で割った——
  触る場所から1枚が決まる形にしないと、分けても結局全部読むことになる。
- `.claude/rules/README.md` が「どの場所ならどれを開くか」を持つ。

**`@` の取り込みではなくリンクにした。** Claude Code が自動で読むのは
CLAUDE.md 本体と `@path` の取り込みだけなので、

| 書き方 | CLAUDE.md の行数 | 毎回読む量 | 読み落とし |
| --- | --- | --- | --- |
| `@.claude/rules/x.md` | 減る | **変わらない** | しない |
| `[...](.claude/rules/x.md)` | 減る | **激減する** | 規律が要る |

取り込みでは**行数が減るだけで、目的（読む量を減らす）が達たない**。
リンク側を選び、「触る前に領域の1枚を開く」規律で担保する——これは
`docs/decisions/` で既に回っている形と同じ。

## 移すついでに直したもの

- **1行が `|` で割れて規則の本文が消えていた**（`| 説明文の` | — | …`）。
  §9.222 の「`**強調**` は `hintHtml()` を通す」が**表からは読めなかった**。
- **同じことを言う行が2つずつ在った**（測定の見出し／ロットの見分け方／
  `cfg()` の開き方）。束ねて、くわしくの行き先を2つ並べた。
- 「測定の見出しは1行」（§9.209・§9.234）と「2行まで」（§9.210）は
  **矛盾ではなかった**。§9.210 は「塊は2つ・塊の中は折り返さない＝窓幅で
  行数が動かない」という構造の上限で、§9.234 は「いまは1行に収まる」。
  短く書きすぎて矛盾に見えていたので、両方とも中身どおりに書き直した。
- **節の見出しの件数が実際と合っていなかった**（合計 669 と名乗って実際は 690）。
  数え直して入れ替えた。

## 網（`test_docindex.py`）

上限は**バイトから行へ**変えた（利用者が行で言ったから、かつ「一息で読めるか」は
行数で決まるから）。足したのは:

- CLAUDE.md が 200行以下
- **CLAUDE.md へ3列の規則表を書き戻していない**（入口に表が戻ると元に戻る）
- 入口からも索引からも15枚すべてへ行ける／どの1枚からも戻れる
- 表の決まり（くわしくの行き先・90字以内）は置き場が変わっても同じ
- **同じ規則を2行に持っていない**（置き場を分けると重複に気づきにくくなる）
