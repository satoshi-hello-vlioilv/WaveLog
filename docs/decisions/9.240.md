# §9.240 ロールマスタのExcel入出力・周期の見かたの既定（利用者の指示）

利用者の指示（2件）:

1. ピッチからロールを探す機能の「周期の見かた」は
   **「ちょうど1周分だけ見る」を既定に**してほしい
2. ロールマスタに **EXCELでのインポート＆エクスポート** がほしい

#### ① 周期の見かたの既定

`index.html` の `selected` と `defect-locator.js` の復元時の既定
（`d.harmonics ?? …`）の**2箇所**が持っていたので、`ROLL_HARMONICS_DEFAULT`
へ寄せた。**片方だけ変えると、記録の無いロットを開いた瞬間だけ別の値になる**
——画面は「ちょうど1周」なのに判定は倍音まで見ている、という気づけない状態。

倍音（`1/2`・`2倍`…）を見たい場面は残っているので選択肢自体は消さない。
既定を1周にしたことで、**直接一致だけが出る**のが普通になる。

#### ② Excelの持ち出し・取り込み（`backend/xlsx_io.py` 新設）

**openpyxl を入れない。** `requirements.txt` は `flask` だけの世界で、
現場のWindows端末は社内で閉じて動く（外部のアイコンフォントを取りに行けない
のと同じ前提）。端末を1台増やすたびに pip が通る保証は無く、
**入れた瞬間に「その端末では起動しない」を作れる**。

**CSVにもしない。** この機能の主目的は**利用者がExcelで作ったファイルを
取り込む**ことなので、読めなければ意味が無い。CSVだと毎回「名前を付けて
保存 → CSV」を挟ませるうえ、Excelは開いた時点で先頭ゼロを落とし日付へ
化けさせる（ロールの基準番号は先頭ゼロを持ちうる）。

`.xlsx` は ZIP + XML なので `zipfile` と `xml.etree` だけで書けるし読める
——**実証してから決めた**（`tests/test_rollio.py`）。

書く側:

- **文字列は必ず `inlineStr`。** 共有文字列表を持たないぶん少し大きくなるが、
  **先頭ゼロが数値へ落ちない**し部品が1つ減る。
- 見出し行は固定（freeze pane）、列幅は `IO_COLUMNS` が持つ。
- シート名の使えない文字（`: \ / ? * [ ]`）を落とし31字で切る。
  **落とさないとExcelがファイルごと開けない。**

読む側（**ここが本番**）:

- **Excelが吐く形をそのまま受ける。** 手で作った素直なXMLしか読めない実装は、
  利用者の実ファイルで必ず落ちる。
- 文字列は `sharedStrings.xml` 経由（`t="s"`）で来る。`inlineStr` も
  `str`（数式の結果）も来る。
- **空セルは要素ごと省略される。** `r="D4"` の座標から列位置を復元しないと、
  Bが空の行で**値が1つ左へずれる**——基準番号が径として読まれ、
  「取り込んだら別のロールになっていた」という気づけない壊れ方になる。
- 行番号も飛ぶ。1枚目のシートは `worksheets/sheet1.xml` とは限らない
  （`workbook.xml` の並び順 → rels → 実体、と辿る）。
- **壊れたファイルは例外ではなく理由を返す**（§CLAUDE 4）。

取り込みの決めごと:

- **突き合わせは自然キー (設備名, ロール名)**（§9.239 ⑥）。同じ組み合わせが
  あれば上書き、無ければ追加。**行の削除はしない**（ファイルに無い＝
  消してよい、とは限らない）。
- **IDの列は運ばない**（§9.171 と同じ理由。IDは端末ごとの連番なので、
  別のPCで取り込むと無関係な行を書き換える）。
- **見出しは名前で探す**ので、列の順番を変えても取り込める。
- **空欄の列は触らない**（§9.212 ②「送った項目だけ書く」）。書き出して
  一部だけ直して戻す往復で、触っていない値が消えない。
- **無効な行も書き出す**（`[有効]` 列で分かる）——出さないと、書き出して
  直して取り込む往復で**無効にした行が消える**。
- **既定は下見**（§9.193）。何件が追加で何件が上書きかを**書き込む前に**
  出し、「この内容で取り込む」を押すまでマスタは変わらない。
- **飛ばした行は行番号と理由つきで全部返す**（§CLAUDE 4）。「N件飛ばしました」
  だけでは直せない。

画面（`master-maint.js`）:

- 置き場は**一覧の上の帯**（モーダルを増やさない・§9.171）。
- **`excelIo:true` を1つ付けるだけで帯が出る差し替え口**にしてある——
  他のマスタが要るときも画面のコードを増やさない。
- 運ぶもの・運ばないもの（IDは運ばない・削除はしない）を**画面に書く**。

**文字のセルには「文字」の書式（`numFmtId=49`＝`@`）を当てる**（追補）。
当てないと、書き出したファイルを利用者がExcelで開いて**そのセルを直した
瞬間に**「標準」書式が働き、`007` が `7` になる——**書き出す→Excelで直す→
取り込む**という本来の使い方でちょうど壊れ、CSVを避けた理由が無に帰す。
**読めることだけを見る網では捕まらない**（こちらが書いた直後は文字のままなので
必ず通る）ので、XMLに書式が乗っていることを直に見る。
あわせて**長すぎる値は印を付けて切る**（`MAX_CELL_CHARS`＝32,767。切らないと
Excelがファイルごと開けない。**黙って切らない**）。

固定は `tests/test_rollio.py`。**素通りに注意**——自分が書いた `.xlsx` を
自分で読み返すだけでは、Excelが吐く形（共有文字列・空セル省略）を一度も
通らない。**手で組んだExcel風のファイルを必ず1本通すこと。**
