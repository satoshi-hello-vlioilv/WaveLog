# §9.62 スケジュールの仕掛パネルを本当に畳む

畳んでも一覧が消えず、幅0の列に押し込まれた破片が左端に残っていた。

原因はセレクタの詳細度。一覧を出す側の
`body.sc-mode.sc-split #grid`は(id1・class2・**要素1**)、畳む側の
`.sc-split-wrap.sc-list-collapsed #grid`は(id1・class2・要素0)で、
両方`!important`のため**要素1個分だけ負けていた**。畳む側にも`body`側の
条件を付けて上回るようにする。

あわせて畳んだときの見え方を整えた: 一覧列は0、取っ手は26pxの帯にして
上下いっぱいに広げ、縦書きで「仕掛一覧」と何が畳まれているかを示す。
`aria-expanded`も持たせる。
