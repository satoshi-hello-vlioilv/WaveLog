# §9.178 列の設定の持ち出し・取り込み（利用者の指示）

フィルタと同じ要望（§9.171「全てまたは各一覧単位で」）が列の設定にも来た。

- 置き場は**列の設定パネルの中の帯**。モーダルを増やさない——実物の一覧を見たまま
  「何が出て行くのか」を確かめられるのが値打ち。
- 対象（`target`）ごとに1件として運ぶ。**保存済みの全対象はサーバーが答える**
  （`GET /api/column-layout-master?all=1`）——`target`は画面が組み立てる文字列で、
  どんな対象が保存済みかを推測する手掛かりがどこにも無い。
- 既定は**書き出し＝この一覧だけ（いま画面に当たっている下書き）／取り込み＝
  ファイルにある全部**（選んだファイルは入れたくて選んでいる。§9.171と同じ）。
- **運ぶもの・運ばないものを画面に書く。** 運ぶのは並び・幅・表示名・書式・
  読み替えルールの**名前**・計算式・幅固定。運ばないのは「名前を付けて登録」した
  設定（列プリセット）と、読み替えルールの中身（表示ルールマスタ）。
- 取り込んで書き込んだら**キャッシュを捨てる**（`WL.columnLayout.forget()`）——
  当てた覚えの無い古い形で他の画面が描かれるのを防ぐ。
- 対象が見つからないファイルでも**書き込みは通す**（先に一覧を開かなくても設定だけ
  配れる）。当たらない列は今までどおり黙って捨て、**捨てた件数は必ず言う**。

固定は`tests/test_colio.js`。

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **列の設定もファイルへ持ち出せる**（§9.178、`GET /api/column-layout-master?all=1`）:
  置き場は**列の設定パネルの中の帯**（モーダルを増やさない。§9.171と同じ作法）。
  **保存済みの全対象はサーバーが答える**——`target`は画面が組み立てる文字列なので、
  どんな対象が保存済みかを画面からは推測できない。運ぶのは並び・幅・表示名・書式・
  読み替えルールの**名前**・計算式・幅固定で、**列プリセットと読み替えルールの中身は
  運ばない**ことを画面に書く。書き込んだら`WL.columnLayout.forget()`で写しを捨てる。
  固定は`tests/test_colio.js`。
