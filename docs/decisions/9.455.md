# §9.455 記号（A・B・C…）は文字ごとに1色／潤滑リングはゴムリングマスタの行で持つ（利用者の指示）

索引: [決定記録](README.md)

利用者の指示:

> ゴムリングマスタに潤滑リングフラグを立てて、ゴムリングのサイズや在庫数を決めるのと同じように
> 潤滑リングの設定もできるようにしてください。

> ガイダンスの刃の組み方のA,B,C,,,ラベルが色をアルファベットごとに分けてわかりやすくしたいのですが
> 変なパターンの感じで色付けされていてマウスオーバーでまた色の変化もあり、さらにわかりにくく
> なっています。普通に色分けしてほしいです。

---

## ① 記号の色——「軸で分ける」は読み違いだった

### 何が起きていたか

§9.442 で「アルファベットも少し色がわかっていると違いが出てわかりやすい」という指示を
**軸で色を分ける**（上軸＝藍 `--bs-fig-badge-up`／下軸＝青緑 `-lo`）と読んで実装していた。
刃組表の記号は灰1色、マウスを乗せるとどれも濃い青緑へ変わった。結果として:

- 同じ **A** が上軸・下軸・刃組表で**3色**になり、文字ではなく上下の縞に見えた
- 違う文字どうしが**同じ色**を持ち、色では見分けられなかった
- 重ねると色が変わり、「どの組み方か」を言っていた色がさらに崩れた

利用者の意図は最初から**文字ごとの色**だった。

### 物差し（記号 A〜D の4文字・刃組表＋模式図＋断面図）

| 物差し | 前 | 後 |
| --- | --- | --- |
| 同じ文字なのに色が2色以上 | **4/4** | 0 |
| 違う文字なのに同じ色の組 | **6/6** | 0 |
| 重ねたとき色が変わる所 | **13** | 0 |

### どう直したか

- **色の番号（`tone`）は記号を振るときに一緒に振る**（`buildRows()`の1箇所）。字面から
  推し量ると `OS` のような端部の札まで色が付く。
- 表・模式図・断面図・拡大図は同じ番号を `data-bc` で名乗るだけ。色は CSS の
  `--bs-badge-0`〜`7` の8色だけが持つ（`[data-bc="N"]` が `--bs-bc` を配る）。
- 8色は**白抜きの字が読める濃さ**（白との比 5.0〜8.0）の既存トークンから選び、
  隣り合う記号の色相が離れる順に並べた: 青・赤・緑・黄土・青緑・紅・茶・灰。
  紫は潤滑リングの色なので使わない。9つ目からは同じ順でもう一度使う（字が違うので取り違えない）。
- **重ねても塗りは変えない**。模式図は縁の太さと大きさ、断面図と刃組表は同じ色の外輪で言う。
  光らせる区間の面（淡い塗り）も記号と同じ色にした——どの文字の区間が光ったかが色でもつながる。
- 軸は**上下の位置**が言う（押した軸の拡大図が開くのは §9.442 のまま）。
- ついでに、同じファイルに2回書いていた `.bs-bdg` を1つにまとめた。

### 残した注意

条の並び・板の札の丸数字（ロット番号）は**幅ごとの色**（`--bs-w0`〜）を使っており、
記号の色と色相が重なることがある（例: ロット1＝青、記号A＝青）。形が違う（輪郭の丸数字と
塗りつぶしの札）ので分けてあるが、紛らわしければ次に直す。

## ② 潤滑リングはゴムリングマスタの行

§9.454 では寸法を `刃組基準値` に置き、在庫は持たなかった。利用者の指示で、
**ゴムリングマスタの行**として持つようにした——形も材質もゴムリングで、寸法と役目だけが違う。

- ゴムリングマスタに列 `潤滑リング`（真偽）を足した。画面は「種類」（ゴムリング／潤滑リング）で、
  綴りはサーバーの `RING_KIND_*` の1箇所。送られた呼び名は `flags.flag_of()` へ
  `ゴムリング` を「切」の側として渡して読む（§9.324 R4）。**送らなければ触らない**。
- 幅・外径・内径・保有本数・下限本数は**ゴムリングと同じ欄**。色名が空なら「潤滑」。
  潤滑リングには外径の色の周期を当てない（画面の色が空なら紫のトークン、あればその色）。
- `刃組基準値` の `lubeWidth`／`lubeOD`／`lubeBore` は外した（置き場を2つにしない）。
  空きの帯（`ringGapMin`／`ringGapMax`）は設備ごとの決まりなので基準値に残した。
- 計算は `normalize()` で**区間を埋める候補から外す**（混ぜると幅10の潤滑リングが
  「ゴムリング10」として積まれる）。寸法は `ringRule()` が行の先頭（サーバーの並び＝外径の
  大きい順）から引く——幅違いを混ぜて両端が別の幅になるのを防ぐ。
- 在庫は**ゴムリングと同じ数え方**（稼働中の台車に載っているぶんを引く・`stockPlan().lube`）。
  所要で足りなければ赤、台車差分も棚の数と比べる。下限割れは「刃の状態」の要確認に出る。
- 行が無い設備では、刃組表の上に「潤滑リングを入れられません」と、足す場所を出す
  （`fit.lubeMissing`）。
- 初期セットに1行（幅10・Φ270/Φ240）。**本数は図面に無い**ので、40条の刃組が1回組める
  80本を置いた（現物の本数はマスタで直す）。
