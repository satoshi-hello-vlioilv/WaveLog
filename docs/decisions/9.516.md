# §9.516 運用中の最新版の判定から「開発者」の端末を除く（利用者の指示）

索引: [決定記録](README.md)

## 利用者の言葉

「運用中の最新版の判定はアクセス権限の『開発者』を除いた形にしたいです。」

§9.515 で「踏みそうな罠」として書いた件——開発者の手元でまだ配っていない版を動かすと、それが
「運用中の最新版」に数えられ、全端末に「新しい版あり」が出る——を、記録を手で消す運用ではなく
判定そのもので塞ぐ。

## 測った（評価関数・直す前）

開発者の端末（未配布の 9.9.9）・一般の端末 u1（2.402.0＝この端末と同じ）・u2（2.400.0）の記録を置き、
接続状況の答え（`/api/presence`）と知らせの答え（`version_notice()`）を見た。

| 物差し | 望む値 | 前 | 後 |
| --- | --- | --- | --- |
| 運用中の最新版 | 2.402.0 | **9.9.9** | 2.402.0 |
| 最新でない端末 | u2 だけ | **u1・u2**（配った版の端末まで要更新） | u2 |
| 開発者の端末を「要更新」に数えるか | 数えない | 数えない（最大なので） | 数えない（`counted=False`・「対象外」） |
| 一般の端末（2.402.0）に知らせが出るか | 出ない | **出る** | 出ない |
| 開発者の端末に知らせが出るか | 出ない | **出る** | 出ない |
| 知らせが言う最新版 | 2.402.0 | **9.9.9** | 2.402.0 |
| 合計 | | **1/6** | 6/6 |

## 決めたこと

- **数えるかどうかは`presence.counts_for_latest(role)`の1箇所**（除く区分は`LATEST_EXCLUDED_ROLES`＝開発者）。
  接続状況の一覧（`fleet_summary()`）と古い版の知らせ（`refresh_newest()`→`version_notice()`）が同じ答えを使う。
- **区分はアクセス権限マスタの登録から引く**（在席に書かれた区分は端末の自己申告なので使わない・§9.272）。
  端末の数だけ引くので、表は1回だけ読む（`master_repo.registered_roles()`）。一致の読み方は
  `permission_flags()`と同じ`_permission_row()`の1箇所へ切り出した（2箇所に持つと、画面の区分と判定の区分が食い違う）。
  切断の判定（`_registered_role()`）も同じ口を通すようにした（前は1端末ごとに接続を開き、`with`で閉じていなかった・§9.270）。
- **区分が分からない端末（マスタを読めない）は数える**——数えないほうへ倒すと、配った版まで消えて「全部最新」に見える。
- **この端末が開発者なら、この端末の版も数えない**。
- 開発者の端末は**要更新にも最新にも数えない**（`counted=False`）。画面は版の状態を「対象外」と言い、
  理由は`title`（「開発者の端末は、運用中の最新版の判定に数えません（まだ配っていない版を動かすため）」）。
  「最新でない版だけ」にも入らない（配る相手ではない）。
- **開発者の端末には「新しい版あり」を出さない**（配る側を急かさない）。
- 出どころを言う（画面基準6）: 要約の「運用中の最新版」の下に「開発者の端末を除く」。除いた区分の名前は
  サーバーが`excludedRoles`で渡す（画面へ「開発者」を書き写さない）。
  数える端末が1台も無いときは「—」だけにせず「開発者の端末を除くと、まだ接続の記録がありません」と言う。

## 踏んだ罠
- 検証用フィクスチャのこの端末（root@vm）は**開発者**で、記録もこの端末だけ。開発者を除くと数える端末が無く、
  ハートビートの知らせは`null`になる——`test_presenceui.js` ⑧ が「応答に版が載る」を`myVersion`の有無で見ていて落ちた。
  仕様どおりの答えなので網のほうを直した（版は`/api/build`から取り、知らせは「席がある・あれば中身が正しい」で見る。
  中身の判定は`test_presence.py`の10・11が持つ）。

## 固定する網
- `test_presence.py` 11 … 開発者の版は数えない／要更新にも数えない（`counted`・区分）／除いた区分を渡す／
  開発者だけの利用者も数えない／自分が開発者なら自分の版も／区分が分からなければ数える／知らせも同じ／
  開発者は急かさない／まとめて引く区分は1件ずつの答えと同じ
- `test_presenceui.js` ⑨ … 「開発者の端末を除く」／「対象外」（接続中の表・記録の表）と理由の`title`／
  「最新でない版だけ」に入らない／数える端末が無いときの字
