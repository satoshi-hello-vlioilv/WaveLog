# §9.464 表示名を付けても元の名前で列を引ける／表示列の式と条件に文字列の抽出・変換（利用者の指示）

索引: [決定記録](README.md)

## 利用者の言葉

> 表示列の設定の中に、元の列の名前を変えると、使えなくなってしまう不具合がありました。表示列で
> 列名を変えても、元のデータを再利用したいことはあるので、表示列の名前を変更しても、元の名前の
> 列で条件を作ったり使えるようにしてほしいです。
>
> 表示列の条件の作成で、列の情報と比較する条件は多彩ですが、データの抽出などは対応できて
> いないので、文字列からの抽出や変換処理もできるように改良してください。

## ① 表示名を付けても元の名前で列を引ける

**原因（調べた結果）**

表示名は**見出しの字だけ**を変える（§9.88。行も設定も元の列名のまま）。ところが「名前から
列を引く」ところが2つあり、どちらも片方の名前しか見ていなかった。

- 作業スケジュール表の`timelineKeyByName()`は「キー → いまの見出し」だけ。`scColLabel()`は
  表示名があると元の見出しの言葉（区分・ロット番号…）を**置き換えて**返すので、表示名を付けた
  途端に`[ロット番号]`の式・`区分`の条件が**黙って効かなくなった**（§9.207で約束した
  「表示名→見出し→キー」に反していた）。
- 仕掛一覧は行を生の列名で持つので、元の名前では引けるが、**新しい表示名で書いた式・条件は
  引けない**。
- 絞り込みの列の選択肢は元の列名だけで、見出しで見ている名前で探せない。

**直したこと**

- 名前→列の答えは`WL.columnLayout.keyByName(target, keys, name)`の1箇所（元の列名 → いまの
  表示名 → 別名`aliases`：生カラム名とalias名の相互、兄弟の綴りも）。
- 仕掛一覧は、式・条件が**書いた名前のうち行に無いもの**だけを描くたびに1回当て、その名前で
  値を足した写しを式・読み替えへ渡す（`namedRow`。書いた名前が全部在れば写しを作らない）。
- 作業スケジュール表は`timelineKeyByName()`が「キー → いまの表示名 → 元の見出しの言葉
  （`scBaseLabel()`）→ 別名」の順に当てる。
- 条件の列の選択肢は「表示名（元: 見出しの言葉）」、絞り込みの列の選択肢は「表示名（元の列名）」。
- ついでに見つけた不具合: 条件の片側を「他の列」へ切り替えたとき、既定の列を**仕掛一覧の列**
  （`S.columns`）から取っていたので、スケジュール表では選択肢に無い列が入った——この窓が
  並べている列（`srcColumns()`）から取る。

## ② 文字列からの抽出・変換

**式の関数を足した**（`WL.formula`。式の列・操業データの自動項目・条件の式が同じ1つを使う）:

| 関数 | 何をするか |
| --- | --- |
| `mid(x, 何文字目, 文字数)` | 中ほどを切り出す（位置は1から・文字数を省くと最後まで） |
| `find(x, 字)` | 位置（1から・無ければ0） |
| `split(x, 区切り, 何番目)` | 区切りで分けてN番目（1から） |
| `replace(x, 字, 置く字)` | 全部置き換える |
| `regreplace(x, 正規表現, 置く字)` | 正規表現で置き換える（`$1`で組） |
| `extract(x, 正規表現[, 組])` | 正規表現で抜き出す（合わなければ空） |
| `match(x, 正規表現)` | 合えば1 |
| `contains` / `startswith` / `endswith` | 含む・始まる・終わる（1／0） |
| `hankaku(x)` | 全角の英数記号を半角へ（NFKC） |
| `padleft(x, 桁, 字)` | 桁をそろえる |

正規表現は利用者が書くので、**壊れた書き方は書いている最中に断り**（字で書いたとき）、
実行時に壊れていればその行だけ空。長さは200字まで、作った正規表現は使い回す。

**条件でも使える**: 条件の片側に「式」（`kind:'calc'`）を選べる——抜き出し・変換してから比べる
（例: `num(extract([この列],'[0-9]+'))` が 100 より大きい）。`[この列]`はこの列の値。
表示値を**`=`で始めると式**——抜き出した値そのものを出せる（例: `=extract([この列],'[0-9]+')`）。
式が見ている列は`columnsUsed()`が数える（スケジュール表が要る列だけ値を用意するため）。
読めない式の条件は「当たらない」（固定値の壊れた正規表現と同じ）。サーバーは式を解かない
（評価は画面の`WL.formula`の1箇所）——保存するときに長さ（400字）だけ見る。

## 物差し

| 物差し | 前 | 後 |
| --- | --- | --- |
| 抽出・変換の11の型（中ほど・位置・置換・正規表現で抜き出す／組・N番目・全角→半角・含む・合うか・桁・抜き出して数） | 0／11 | 11／11 |
| 表示名を付けた列を元の見出しの言葉で書いた式（スケジュール表） | 値が引けない（「★」だけ） | 引ける |
| 新しい表示名・別名で列を引く（仕掛一覧） | 引けない | 引ける |
