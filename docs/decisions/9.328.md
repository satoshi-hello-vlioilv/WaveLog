# §9.328 「黙って捨てる」をやめ、理由を1行残す（REVIEW 3-4、構造の改善の3段目、VER2.211.0）

`except Exception: pass` と 中身の無い `catch(e){}` は、**何が起きても誰にも
見えない**。§9.190で「捨て手が403を握り潰し、鍵が外れる不具合に誰も気づけなかった」
が既に起きており、§9.271（`config/local.json`が読めないことを黙っていた）・§9.317
（品質が読めないだけで測定の初回保存ごと飛んでいた）も同じ根から出ている。

**捨てること自体は禁じない。** 共有が読めなくても画面は出す、端末の覚えが壊れて
いても既定で続ける——現場で動き続けるための正しい選択で、fail-openはこのアプリの
基本方針でもある（§9.89）。要求するのは**なぜ捨ててよいのかを1行書くこと**だけ。

    画面   try{ … }catch(e){ WL.quiet.note('端末の覚えが読めない（既定で続ける）',e) }
           fetch(…).catch(WL.quiet('取れなくても画面は出る'))
    サーバー except Exception as _e: quiet('共有が読めない（写しで続ける）',_e)
           except Exception as _e: return quiet('設定が読めない（既定で続ける）',_e,{})

出す先は**画面が`console.debug`**（ふだんのコンソールを埋めない。直近200件は
`WL.quiet.log()`で読める＝実機で「何かが静かに落ちている」ときの手掛かり）、
**サーバーが`app.log`のDEBUG**。`backend/quiet.py`は**`logging`だけを読む**
——`logging_setup`をimportすると`paths`から使えない（あちらは`paths`を読む側）。
名前は`app_logger()`と同じ`'app'`なので、出る先は今までのログ1本のまま。

### 「黙っている」の定義（網が数えるもの）

**Python**: 広い except（`except:`／`Exception`／`BaseException`）の本体が
**関数を1つも呼ばず、束縛した例外名も1度も読まない**とき。`pass`・`return None`・
`return {}`・`continue`がこれに当たる。**`return False, f'{e}'` や
`return jsonify(error=str(e)),500` は数えない**——理由を呼び出し元へ返している＝
黙っていない。狭いexcept（`except FileNotFoundError:`）も数えない（**何を捨てたのかを
綴りが語る**）。

**JS**: 中身の空の`catch`と`.catch(()=>{})`。**中身がコメントだけのものも数える**
——読む人には理由が見えても、実行時には何も残らない（Pythonで`pass`の上のコメントを
数えないのと同じ扱い）。対象は`static/js`だけで**テストは対象外**（網の中の見送りは
製品の挙動ではない）。

### 直した件数と、コメントの扱い

画面193件・サーバー227件。**うち43件は、書いた本人がコメントで理由を残していた**
（「保存できなくても表示は変わる」「一覧が読めなくてもスケジュール自体の表示は継続する」）
ので、**その文をそのまま実行時の理由へ移した**（同じ文がコメントと引数に2度出ないよう、
移したコメントは畳む・§CLAUDE 8）。残りは操作ごとに書いた——「端末の覚えを書けない
（次に開くと既定へ戻るだけ）」「掴んだ印を渡せない（押す道は残る）」のように、
**何をしようとして・失敗しても何が続くか**の形にそろえてある。

### 網の作り（`tests/test_quietlint.py`、`ALWAYS`）

Pythonは**構文木**で上の定義どおりに数える（字で探すと`except Exception:`の綴り
違いを取りこぼす）。JSは**コメントと文字列を空白へ落としてから**数える——
落とさないと**説明文が規則の綴りを引用しているだけで落ちる**（§9.286 ⑦と同じ問題）。

**その字句落としで正規表現リテラルを見分けること**——`/'/` のような1文字を
見落とすと、そこから先が「文字列の中」になって**残り全部を数えなくなる**。
実際に`list-view.js`の途中で同期を失い、**46件を見落としたまま「0件」と報告した**
（緩む側に壊れるので、通ったこと自体が証拠にならない）。`/`の直前の意味のある
文字で割り算か正規表現かを決める（構文解析器と同じ見分け方）。

**理由の中身は生の行で見る**——落とした側で見ると文字列の中身が空白になり、
**どの理由も空に見える**。`WL.quiet.note('')`／`quiet('')`は数えて落とす。

窓口そのもの（`backend/quiet.py`と`base.js`の`WL.quiet`）は対象外——**ここで黙るのは
理由を出す道そのもの**。`WL.quiet`の中では`try`で包まない（包むとこの関数自身が
黙る場所になる）。

回した網: `test_quietlint`（欠陥を注いでPython2件・JS4件を数えることを確認）と
`test_pyflakes`・`test_eslint`（`no-empty`の上限は404→261へ下げた。残りはテスト側）、
サーバー側の主要な網と、触った画面の網。**フルスイートは回していない。**

## 守ること（`CLAUDE.md` から移した規則の本文）
