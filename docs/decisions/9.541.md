# §9.541 操業データ項目の入力範囲——設定窓で「試しに打つ」と数直線、盤のタイルに範囲と食い違いの札（利用者の選択 F-2＋F-5）

索引: [決定記録](README.md)

## 利用者の言葉と選んだ経緯

マスタの視覚化の候補 F「入力範囲の数直線」。F-1〜F-5（スクラッチの `mockF.js`・製品のコードではない）を見て
**「F-2とF-5の組み合わせでお願いします。」**

- F-2: 設定窓の「試しに打つ」——打った値が**記録される値**へどう直されるかを、数直線の矢印と見本で見せる。
- F-5: 盤のタイルに**範囲の1行**と**食い違いの札**。

## 決めたこと

- **打った値の整え方は `WL.opData.settleValue()` の1箇所**（`measure-opdata.js`）。測定画面の `settle()` もこれを呼ぶ
  （振る舞いは同じ。直した段ごとの `steps` を返すので、図は「どの段で直されたか」を読む）。
- **数の決まりの食い違いは `WL.opData.ruleIssues()` の1箇所**。盤の札・設定窓の札・初期値の注意（`opInitialRangeNote()`）が
  同じ答えを読む。食い違いは**止めない**（保存はできる）——言うだけ。
- 設定窓の図は**打っている途中の値**（`opFormEdits()`）で描く。保存する前に、直した最小・最大・刻みの結果が見える（§CLAUDE 15）。
  数の欄に入ると図の同じ所（最小の端・最大の端・刻みの目盛り・初期値）が光り、食い違いの札を押すと直す欄へ移る。
- 初期値の食い違いは**初期値の欄の横の1か所だけ**（試しに打つの下には重ねない・同じことを2か所に出さない）。
- 見本の値は「下限より下・上限より上・刻みから外れた値・（正の型なら）マイナス」を範囲から作り、打った値を先頭に置く。
  見本の字は3段に分けて重ねない。
- タイルの範囲の1行は「下限〜上限 単位・刻み」。マスタから引く上下限は「設備ごと」と書く（値は設備で違う）。

## 直した食い違い（振る舞いの変更）

小数桁が空の項目は、案内の字（`ruleText()`）が「小数1桁」と言うのに、整え方は `Number(null)=0` で**0桁へ丸めていた**。
答えを1つにして**1桁**へそろえた（`decOf()`）。小数桁を空のまま使っている項目では、測定画面で打った値の桁が変わる
（例: 1.26 → 前は 1、今は 1.3）。

## 分からないこと

- 小数桁が空のまま運用している項目が現場のマスタに何件あるかは分からない（この開発環境のマスタでは、小数ありの型9項目のうち0件）。
- 上下限をマスタ（設備の最大ライン速度・最大条数）から引く項目は、**いま編集しているレイアウトの設備の値**
  （`opLimitOf()`・サーバーの`limitSources[].value`）で数える。共通（すべての設備）のレイアウトでは値が引けない
  （`null`＝その端は無い）ので、その端の食い違いは数えない。設備ごとに値が違うため、ある設備では食い違い、
  別の設備では食い違わないことがある——共通のレイアウトで「食い違い 0」でも、全設備で無いとは言えない。
