# §9.560 読ませる字は 12px 以上——全画面に出る字と共通設定から（利用者の指示）

索引: [決定記録](README.md)｜前: [§9.559](9.559.md)｜関係: [§9.556](9.556.md)・[§9.508](9.508.md)・[§9.90](9.90.md)

## 経緯

利用者の指摘（§9.556）:「添付画像のアプリ起動した後の画面を見たときのまだ残っている統一基準になってない小さな文字や
冗長な表示や表現です。」——残件の一覧の A（小さな字）として渡した:
1. 左メニューの見出し（測定データ・元データ・計画・分析・管理）が 10px
2. マスタ管理の左の群の見出しが 10px・件数が 11px
3. ヘッダーの「💬 通常」が 10px（隣の札は 14px）
4. 共通設定の図の置き場の道が 9.5px・副題と「読む／書く」が 11px
5. 版の札 11.7px・件数の丸・仕掛のヘッダーの「表」・「各PCの次の起動で反映」・タブの件数が 11px
6. 仕組みの問題: 10px・11px のトークンが CSS の 811 か所で使われている

利用者の指示:「残りの小さな字の修正を進めてください」

## 決めたこと

1. **読ませる字（文字・数字を含む字）は`--fs-sm`（12px）以上**。10〜11px（`--fs-badge`／`--fs-micro`）・9.5px（`--fs-tiny`）は
   **図の中の字**（SVG／canvas の目盛り・寸法・凡例）と、開閉の印（▾）のような**記号だけ**の物に使う。紙（帳票）は用紙の寸法で決める。
2. 見張りは`tests/test_smalltext.js`（新）。画面を巡回し、見えている読ませる字のうち 12px 未満を数えて**0**を見る。
   巡回する画面: 起動直後・測定データ一覧・測定実績・仕掛一覧・作業スケジュール・マスタ管理（設備・共通設定・アプリの更新）。
3. 今回直したもの（1〜5 と、巡回で見つかった物）:
   - 左メニューの見出し・版の札・件数の丸・ヘッダーの「表」・「💬 通常」（隣の「表示」と同じ字を継ぐ）
   - マスタ管理の群の見出し・件数・タブの件数・反映の札・欄の添え書き
   - 共通設定の章ぜんぶ（`75-master-paths.css`は読ませる字だけの面なので、小さい3つのトークンを`--fs-sm`へ）
   - 作業スケジュールの列の見出し（11px → 12px）
4. **6（全体）は画面ごとに進める**。巡回に入れていない画面（マスタ管理のほかのタブ・ダッシュボード・カレンダー・測定画面・
   刃組・帳票）にはまだ残っている（下の「残り」）。直した画面は巡回へ足して、戻らないようにする。

## 撤回した案

- **小さい3つのトークンの値を 12px へ上げる**: 1か所で済むが、図の目盛り・寸法（刃組の図・公差の図・帳票の見本）まで一緒に
  大きくなり、器に入らなくなる。図の字と読ませる字を同じトークンで持っていたことが原因なので、読ませる字の側を`--fs-sm`へ移す。

## 踏んだ罠

- **§9.556 で左メニューの使用設備の札を外したとき、畳んだ左メニューで字を隠す規則まで壊していた**。
  `body.nav-collapsed .equip-badge-text{display:none}`の行を消したので、直前の選択子の並び（見出し・行き先の名前）が
  次の`{margin-left:0}`へつながり、**畳んでも字が出たまま**になっていた（`test_nav.js`が2件落ちていた・名前を指定して回して
  いなかったので気づかなかった）。並びを`{display:none}`へ戻した。
