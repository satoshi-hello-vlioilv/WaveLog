# §9.486 起動アイコンが作れない——作る側だけ用途（MAKE）を渡していなかった／「表示」を開き直すと「確認しています…」で止まる（利用者の報告）

索引: [決定記録](README.md)

## 経緯

利用者の報告「表示のメニューから、ショートカット作成しようとしても確認していますと出て使えません。
作成もうまくいかなかったので、正常に機能しているかも含めてチェックと修正をお願いします。」

別々の2つの不具合が重なっていた。どちらも網が**通らない道**に居た。

## ① 作成が必ず失敗していた（サーバー・§9.446から）

§9.446 で補助スクリプト（`make_shortcut.vbs`）を「作る／読む」の1枚にし、**1つ目の引数を用途**
（`MAKE`／`READ`）にした。読む側（`link_target()`）は`READ`を渡すよう直したが、**作る側（`create()`）は
直し忘れ**、引数が1つずつ前へずれていた:

| スクリプトが読む位置 | 期待 | 実際に届いていた物 |
| --- | --- | --- |
| `a(0)` 用途 | `MAKE` | ショートカットの置き場 |
| `a(1)` 置き場（`.lnk`） | `…\測定伝送システム.lnk` | `Start.vbs`の道 |
| `a(5)` 説明 | 説明文 | （無い＝範囲外） |

`CreateShortcut`は`.lnk`で終わらない名前を断るので、**VER2.344.0 以降、Windows では1度も作れなかった**。
しかも`cscript //B`（バッチモード）で動かしていたため VBScript の断りが1字も出ず、画面は
「終了コード 1」しか言えなかった。網（`test_shortcut.py`）は補助スクリプトの**字面**
（`READ`と`lnk.Save`を含むか）しか見ておらず、**渡す並びと読む位置の突き合わせ**が無かった。

直したこと:

- `create()`は`MAKE`を渡す。
- `//B`を外す（`cscript`は窓を出さずに断りを標準エラーへ書く。失敗の理由がそのまま画面まで届く）。
- 絵が無いときは空の引数でなく`NO_ICON`（`-`）を渡す。WSH は空の引数（`""`）を数えないことがあり、
  数えなければ後ろが前へずれる——**位置で読む引数に空を置かない**。
- `cscript`の出力は`errors='replace'`で読む（`_run_text()`の1箇所）。端末の言語設定と違う字が混ざると
  `text=True`だけでは`UnicodeDecodeError`で作成そのものが500になる。

## ② 「表示」を開き直すと「確認しています…」で止まる（画面・土台）

`base.js`の「表示」のメニューは、**器を文書に付ける前に**各節の`render(host)`を呼んでいた。
ショートカットの節は面が2つ（「表示」と共通設定）あるので、自分の器を`document`から
（`[data-sc-state]`・`#lnkPanel`）探して塗る。1回目は答えを取りに行くあいだに器が付くので塗れるが、
**2回目以降は答えを覚えているので同期で塗りに行き、まだ付いていない器を見つけられない**。
字は初期値の「確認しています…」のまま、作るボタンを含む本体も伏せたままになる。

網（`test_uisize.js`）は毎回**再読込してから**開いていたので、この道を1度も通っていなかった。

直したこと: **器は文書に付けてから渡す**（`render(host)`の約束として`WL.lookSettings`の説明にも書いた）。
節ごとに「付いていなければ待つ」を書くのではなく、土台の順番を正す——節が何本増えても同じ約束で済む。

## ③ 「参照…」でメニューごと閉じる（画面・土台）

絵の「参照…」（場所選び）と上書きの確認は、メニューの**上に重ねて**開く窓（`.record-modal`）。
メニューの外クリックの判定がその窓の中のクリックも「外」と数えていたので、窓を押しただけで
下のメニューが消え、**選んだファイルの行き先が無くなっていた**。重ねた窓の中は「外」と数えない。

## 測った

評価関数: ①は`cscript`へ渡す並びを WSH が読むとおり（空の引数を落とす厳しいほう）に組み立て、
補助スクリプトが`a(i)`で読む位置と突き合わせる。②③は「表示」を再読込せずに5回開き直し、
状態の答えと作るボタンが出たかを数える／「参照…」の窓を押したあとメニューが残るかを見る。

| 物差し | 前 | 後 |
| --- | --- | --- |
| 作るときの引数が読む位置と合う（既定の絵あり／絵なし） | 0/2 | 2/2 |
| 作成が成功として返る（同上・`cscript`は差し替え） | 0/2 | 2/2 |
| 開き直して「確認しています…」のまま止まった回 | 4/5 | 0/5 |
| 開き直して作るボタンが出なかった回 | 4/5 | 0/5 |
| 「参照…」の窓を押したあとメニューが残る | いいえ | はい |

## 分からないこと

- **この環境は Windows ではないので、実機の`cscript`で`.lnk`が作れることは確かめていない。**
  確かめたのは「渡す並びが読む位置と合う」までで、Windows での最終確認は利用者に頼む。
- WSH が空の引数を数えないかは端末によって違うかもしれない（確かめていない）。どちらでも
  ずれないよう`NO_ICON`を渡す形にした。
