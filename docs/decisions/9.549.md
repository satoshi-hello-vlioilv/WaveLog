# §9.549 起動画面の字を、いまの起動の事実へ言い換える——ブラウザ版・Webサーバー・引数 desktop を言わない（利用者の指示）

索引: [決定記録](README.md)｜設計: [`docs/DESKTOP_MIGRATION_DESIGN.md`](../DESKTOP_MIGRATION_DESIGN.md)｜前: [§9.548](9.548.md)｜次: [§9.550](9.550.md)

## 利用者の言葉

「言い換えてください」——§9.548 で残した「`#appBoot`の段の名前（『Webサーバーを起動』）」などの、ブラウザ版のころの字について。

## 決めたこと

- **起動の画面の字は、いまの起動で実際に起きることを言う**。ブラウザ版の起動の道は§9.548で外したので、
  「ブラウザ版でも開けます」「Start.vbs に『desktop』を付けて」は**無い道へ案内する**字になっていた。
- 段の名前（`boot_status.STEPS`・`#appBoot`の帯）:

  | 鍵 | 前 | 後 | 起きていること |
  | --- | --- | --- | --- |
  | `env` | 実行環境を確認 | Python を探す | 窓（Rust）が PATH から Python を探す（起動画面の①と同じ言葉） |
  | `instance` | 起動中のアプリを確認 | 二重起動を確かめる | 窓の単一起動（`tauri_plugin_single_instance`）。2つ目は前の窓を前へ出す |
  | `app` | アプリを読み込み | アプリの中身を読み込み | 窓口（`program/sidecar.py`）が Flask の中身を読み込む |
  | `server` | Webサーバーを起動 | 画面との窓口を開く | 標準入出力の枠で画面と話し始める（ポートは開かない） |

  鍵（`env`など）は`base.js`・`index.html`が名乗るので変えない。`packages`・`data`と画面の4段は事実のままなので触らない。
- 窓の起動画面（`desktop/splash`）と窓が出す失敗の理由（`desktop/src/locate.rs`）:
  - Python の出どころは「ブラウザ版（Start.vbs）と同じ」→「**update.bat と同じ**」（同じ PATH の順で選ぶ・§9.546）。
  - Python が無いときの次の一手は「ブラウザ版が動く PC なら…」→「Python を入れて PATH に通してから開き直す・分からなければ管理者へ」。
  - 中身の場所が分からないときは「Start.vbs に『desktop』を付けて」→「**exe を直接開かず、Start.vbs（またはデスクトップの起動アイコン）から**」。
  - 失敗の1行目は「…ブラウザ版（Start.vbs）でも開けます」→「直したら、この窓を閉じて起動アイコンから開き直してください」。

## 測った（評価関数・前→後）

物差し: 起動画面（`desktop/splash`）・`#appBoot`・段の名前・窓の失敗の理由に、外した起動の道を言う字
（`ブラウザ版`／`Webサーバー`／`「desktop」を付け`／`「desktop」から`）がいくつあるか。

| 物差し | 前 | 後 |
| --- | --- | --- |
| 外した道を言う字（出現数） | 6（5種） | 0 |
| 網 | — | `test_boot` 12/12（⑤を足した）・`cargo test` 6/6 |

欠陥注入は4件（起動画面へ「ブラウザ版」・段の名前を両側そろえて「Webサーバー」・帯の名前だけ旧い字・`locate.rs`へ「desktop を付けて」）を全部拾う。

## 踏んだ罠

- **コメントを消す正規表現が、ファイルの残りを丸ごと消していた**。`re.S`を付けた`^\s*//.*$`は`.`が改行にも当たるので、
  `locate.rs`の最初の`//`行からファイルの終わりまでが消え、網は窓の失敗の理由を1文字も見ていなかった（注入が素通りして分かった）。
  行コメントは`[^\n]*`で1行に限る。**見張る網は、見張る先に欠陥を入れて落ちることまで確かめる**。

## 並列の網どうしの競合（`--pure`で見つけた・この版で直した）

この版の確かめに`--pure`（並列8）を回すと、**回ごとに違う本が1本だけ落ちた**（3回で`test_eslint`の FAIL・
全部通る・`test_ddllint`の FATAL）。どれもこの版の変更とは別の、**網どうしが同じ場所を取り合う**競合だった。

| 落ちた本 | 仕組み | 直し方 |
| --- | --- | --- |
| `test_eslint` | `test_faststart`が本物の`program/setup_app.py`（update.bat の中身）を回し、その片付け（`run_for_update`）がソースの隣の`__pycache__`を消す。eslint は`tests/`を歩く途中でフォルダが消え、ENOENT で止まる | `eslint.config.mjs`の`ignores`に`**/__pycache__/**`（JS は無いので歩かない） |
| `test_ddllint` | `test_body`が網の試しの源を本物の`backend/routes/_body_probe.py`へ書いて消す。`backend`を歩く ddllint が一覧を取った直後に消え、読めずに止まる | 試しの源は文字列のまま読む（ファイルを書かない・§9.504） |
| （起きうる・未観測） | `test_routesplit`も本物の`backend/routes/masters/`へ試しのファイルを書く。同じ形の競合 | `scan()`／`unresolved()`へ根を渡し、一時の置き場に同じ形の木を作る（§9.504） |

測った: 競合を人工的に起こす物差し（`tests/__pycache__`を作っては消し続けながら eslint を15回）で、**落ちた回数 10/15 → 0/15**。
`--pure`で1本でも落ちた回は、**直す前 3回中2回 → 直したあと 5回中0回**（1320/1320）。欠陥注入: `scan()`が根を無視する形に戻すと`test_routesplit`が落ちる。

## 分からないこと
