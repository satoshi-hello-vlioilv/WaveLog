# §9.326 標準の静的解析を網にする（REVIEW 3-1、構造の改善の1段目、VER2.209.0）

`docs/REVIEW_2026-09.md`の3-1。利用者の指示は「推奨順かつ構造の改善案を優先して
実施」「画面の見た目が変わるものは都度確認して少しずつ」——これは振る舞いを
1つも変えない段。

### 評価関数（前 → 後）

| 物差し | 前 | 後 |
|---|---|---|
| pyflakes（直接実行の4本＋`backend/`＋`tests/`） | 77件 | 0件（副作用のimport 8件は`noqa`＋理由で除く） |
| eslint 'error' 55規則（`no-redeclare`ほか） | 5件 | 0件 |

### 何が出てきたか

- **同じファイルの中の同名関数**——`report-dashboard.js`の`fmtMin`が同じIIFEに2つあり、
  関数宣言は巻き上げで**後の側が勝つ**ので、先の定義（`H時間M分`）は一度も実行されて
  いなかった。稼働状況の「見込」「最大の遅れ」「経過」は後の定義（`N分`）で出ている。
  `tests/test_patchlint.py`は**別ファイルからの全置換**しか見ないので、この形は素通りする。
  直したのは**死んだ側を消す**ことだけ（見え方は1文字も変わらない）。「`2時間30分`の形へ
  戻すか」は画面の変更なので REVIEW §4-4 の 17 として確認待ち。
- **使っていないimportは読む側に嘘を語る**——`masters.py`は先頭で`set_path_config`を
  importしながら、使う関数の中で**改めてimportし直して**いた（pyflakesは「redefinition」と
  言う）。`cols`／`cfg`／`path_config_rows`／`master_repo`の16個も同じで、`masters.py`が
  何に依存しているかを先頭から読めなかった。
- **使っていない変数は「書いたつもりの処理が無い」合図**——`rne_extract.py`の`last=e`は
  最後の失敗を控えていたが、誰も読まない（保留へ逃がす道が別にあるので要らなかった）。
  `report_block_repo.py`の`basic = rec.setdefault(...)`は**副作用だけが要る**行だった
  （`setdefault`は残し、束縛だけ外した）。

### 約束

- **規則は`eslint.config.mjs`の1箇所**——網とエディタが別の規則を持つと「エディタでは
  赤いのに網は通る」が作れる。
- 'error'＝**0件に固定**する規則は「書いた本人の意図と違うことが黙って起きる」形だけ
  （二重定義・到達しない文・危ない正規表現・`==`の取り違え…）。`no-undef`と
  「最上位の関数が使われていない」は**この構成では意味を持たない**——JSは`<script>`を
  順に読む素のグローバルで、別ファイルから使われている（§CLAUDE「`window.*`への新規公開」）。
  `no-func-assign`は拡張ファイルのラップ（`fn=function(){...base()...}`）の形そのもの。
- 'warn'＝**ファイルごとに今の件数を上限**に固定する（`tests/fixtures/eslint_baseline.json`）。
  増えたら落ちる・減ったら`python3 tests/test_eslint.py --update`で下げる。
  **上げる更新はできない**（`--update`も増えた側は断る。最初の1回だけ書き下ろせる）。
  全体の合計で見ないのは、1本のファイルが減ったぶんで別のファイルが増えるのを許さないため。
- **副作用のためのimportは`# noqa: F401 理由`をその行に書く**（`import _pycache_bootstrap`＝
  `.pyc`の置き場を決める・`atomic_io.cloud_sync_hint`＝名前の引き継ぎ）。pyflakes自身は
  `noqa`を読まないので**網が読む**。理由の無い`noqa`は網が落とす（黙って除かない）。
- **道具が無い環境では落とす**（`pip install -r requirements-dev.txt`／`npm i -g eslint`）。
  `requirements.txt`へは足さない（現場の端末に要らないものを入れに行かせない・§9.268 ⑥）。
- **網そのものが素通りしないことを毎回確かめる**——`tests/_pyflakes_probe.py`／
  `tests/_eslint_probe.js`へ欠陥を1つ書いて数えられることを見てから消す（§9.200）。
  上限の網は「1件増やすと落ちる」ことも欠陥注入で確かめた。

回した網: `test_pyflakes`・`test_eslint`（新設）と、`ALWAYS`の静的検査、触ったモジュールの
網（サーバー側の数十本と、触ったJSを見る画面の網）。**フルスイートは回していない。**

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **標準の静的解析（pyflakes／eslint）は網の一部。規則は`eslint.config.mjs`の1箇所**（§9.326、
  REVIEW 3-1）: `tests/test_pyflakes.py`が「使っていないimport・変数・二重定義」を**0件**に、
  `tests/test_eslint.py`が'error'の規則（`no-redeclare`・`no-unreachable`等55本）を**0件**に固定し、
  'warn'の2本（局所の`no-unused-vars`・`no-empty`）は**ファイルごとに今の件数を上限**に固定する
  （`tests/fixtures/eslint_baseline.json`。減ったら`--update`で下げる。**上げる更新はできない**）。
  どちらも`ALWAYS`（どのファイルを触っても回る）。**副作用のためのimport**
  （`import _pycache_bootstrap`）は`# noqa: F401 理由`と**その行に理由を書いて**除く——理由の無い
  `noqa`は網が落とす。**道具が無い環境では落ちる**（黙って通さない・§4）——入れ方は
  `pip install -r requirements-dev.txt`と`npm i -g eslint`。`requirements.txt`は増やさない（§9.268 ⑥）。
  **同じファイルの中の同名関数は後の宣言が勝つ**——`report-dashboard.js`の`fmtMin`は先の定義
  （`H時間M分`）が一度も実行されずに稼働状況が`N分`で出ていた（`test_patchlint`は別ファイルからの
  全置換しか見ないので素通りした）。**JSの最上位の関数は`no-unused-vars`で数えない**
  （`vars:'local'`）——`<script>`を順に読む素のグローバルなので、別ファイルから使われている。
