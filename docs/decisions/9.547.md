# §9.547 この端末の起動のしかた（ブラウザ版／デスクトップ版）——端末ごとの切り替えと、exe 起動への一本化の段（利用者の指示）

索引: [決定記録](README.md)｜設計: [`docs/DESKTOP_MIGRATION_DESIGN.md`](../DESKTOP_MIGRATION_DESIGN.md)｜前: [§9.546](9.546.md)

## 利用者の言葉

問い「デスクトップ版への切り替えを、共通設定に端末ごとのスイッチとして置きますか」に
「良いですが最終的にはexe起動に一本化したいです。」

## 決めたこと

- **どちらで起こすかを決めるのは Start.vbs**（Python が動く前に決まるので）。Start.vbs は**引数なし**なら
  この端末の手元の設定を読む。引数`desktop`／`browser`はその場で上書きする（逃げ道）。
- **答えは`backend/launch_mode.py`の1箇所**（顔ぶれ・字・既定・置き場・exe の有無）。画面は答えをそのまま出す。
- **置き場は Python と WSH の両方から見える2つ**:
  `%LOCALAPPDATA%\WaveLog\runtime\launch_mode.txt` と `%USERPROFILE%\.wavelog\runtime\launch_mode.txt`。
  Microsoft Store 版の Python で1つ目が**このアプリからしか見えない写し**になるなら2つ目へ書く
  （`paths.msix_private_copy()`で見分け、写しの書きかけは消す・§9.318・§9.496）。
  Start.vbs も Python も**新しいほう**を採り、書いたらもう1つの古い設定は消す。
  アプリ本体の隣（`APP_ROOT/runtime`）は使わない——共有（Box）の上なので**端末ごと**にならない。
- **既定は1つ**: Python の`DEFAULT`＝Start.vbs の`Const DEFAULT_MODE`（いまは`browser`）。網が2つの一致を見張る。
- **exe が Start.vbs の隣に無ければデスクトップ版は押す形にしない**（札の中に置き場つきの理由）。サーバーも 400 で断る。
- **いま動いている版は問い合わせの宛先で分かる**（デスクトップ版の窓口は`wavelog.localhost`宛てで組み立てる・§9.544）。
  選んだ版と違えば「次に起動アイコン（Start.vbs）から起動すると〜で開きます」と**いつ効くか**を書く。
- **入口は「表示」の節「起動のしかた（この端末）」**（どのモードからも開ける・§9.445 と同じ理由）。
  札は「文字の大きさ」と同じ選択肢の札。共通設定（この端末）には状態と行き先だけ（「起動: ブラウザ版」）。
- 書く口（`POST /api/app/launch-mode`）は**3モードとも通す**（この端末の起動にしか触らない・ショートカットと同じ）。
- **CI は引数なしの Start.vbs で起こす**: アプリの部品で「デスクトップ版」と残してから`cscript Start.vbs`
  （毎日の起動アイコンと同じ道）。

## exe 起動への一本化の段（利用者の指示「最終的にはexe起動に一本化」）

| 段 | すること | 変える所 |
| --- | --- | --- |
| 1（この版） | 端末ごとに選べる。既定はブラウザ版 | — |
| 2 | 既定をデスクトップ版にする（選んでいない端末も exe で開く）。ブラウザ版は選べば使える | `DEFAULT`と`Const DEFAULT_MODE`の2つ（網が一致を見張る） |
| 3 | ブラウザ版の起動の道を外す（Start.vbs は exe を写して起こすだけ）。ポートのための仕組みも外す（設計書 P5） | Start.vbs・`start_app.py`・待機画面 |

段を進める合図は利用者が決める。

## 撤回した案

- **ショートカットの引数（` desktop`）を切り替えにする**——Start.vbs を直に開いた起動が設定に従わない。
  「この端末の起動」はどの道から起こしても同じであるべき。
- **共有のマスタ（パス設定マスタ）に残す**——端末ごとにならない（共有の上に置かれうる）し、Python が動く前の
  Start.vbs から読めない。
- **`paths.browser_dir()`をそのまま使う**——候補の最後がアプリ本体の隣（共有の上）で、端末ごとにならない。

## 踏んだ罠

- **`write_text`は Windows で改行を直す**——`'desktop\r\n'`が`desktop\r\r\n`になり、Start.vbs の`ReadLine`が
  `desktop\r`を読んで字が合わず、**黙って既定（ブラウザ版）へ倒れる**。Linux では起きないので手元の網は通り、
  CI の Windows で「書いた字は Start.vbs が読める形」が落ちて見つかった。書くのは**バイト**（`write_bytes`）、
  Start.vbs も行末の CR を落として読む（どちらか片方が崩れても読める）。

## 分からないこと

- Windows 実機（Store 版の Python）で、2つ目の置き場（`~\.wavelog`）へ回る道。網は写しを模して確かめたが、
  本物の Store 版では測っていない。
