# §9.421 読み込み中の見せ方を選べるようにする（loaders.css を同梱）（利用者の指示）

索引: [決定記録](README.md)

利用者の指示:

> loaderを変更したいです。
> https://connoratherton.com/loaders ／ https://github.com/ConnorAtherton/loaders.css
> このサイトにある読み込み時のloaderを使えるようにしてください。
> 設定で切り替えて選べるようにしてほしいです。

## ① 同梱する（CDNへ取りに行かない）

**オフラインの端末でも動く必要がある。** この画面は現場のPCで動き、外へ
出られない端末がある——`loaders.css` を CDN から読む形にすると、その端末
だけローダーが消える。だから**写して同梱する**（`static/css/89-loaders.css`）。

例外は three.js だけで、あれは**押したときだけ**取りに行き、読めなければ
「模式図はそのまま使えます」と字で断る（§9.377）。ローダーは断りようが
無いので、例外にしない。

許諾（MIT）の全文は `static/vendor/loaders/LICENSE.txt` に置いた——
第三者のものは `static/vendor/<名前>/LICENSE` に置く、という既にある並びに
そろえる（three.js・Font Awesome と同じ）。

## ② 写すときに直した3点（元のままでは使えない）

| | 元 | WaveLog |
| --- | --- | --- |
| 色 | `#fff` 固定 | **`currentColor`**（地が白の器では元のままだと消える） |
| 大きさ | 15px／35px の決め打ち | **`--wl-ld` の1つから作る**（13pxの小さな器にも36pxのオーバーレイにも同じ物を置く） |
| 動きの名前 | `scale`／`rotate` | **`wl-ld-` の印を付ける** |

3つめが罠だった。`loaders.css` は `@keyframes scale` と `@keyframes rotate`
を**別々の中身で何度も**定義している（アニメーションごとのファイルを1枚に
束ねているため）。そのまま持ち込むと、**後の定義が前を上書きする**——
`ball-pulse` の `scale` と `ball-clip-rotate-pulse` の `scale` は中身が違う。

## ③ 並びは1つ。種類が変わってもDOMを作り直さない

器は `.wl-ld`、中の `<i>` は**常に5つ**。どの種類でも同じ形を出しておき、
使わない `<i>` はその種類の規則が伏せる（`ball-pulse` なら3つ、`line-scale`
なら5つ、`ball-clip-rotate` なら1つ）。

こうしておくと、**設定を変えても `html[data-loader]` が変わるだけ**で、
動いている最中に切り替えても飛ばない。並びを作るのは `WL.loader.html()` の
1箇所——呼ぶ側が自前の形を書いていると、種類を足すたびに全部の呼び出しを
探すことになる（実際、直すまえは `.mini-spinner` が4箇所に直書きされていた）。

## ④ 入口は「表示」バッジの3つめの節

文字の大きさ（§9.132）・時間の書き方（§9.341）と同じ「**この端末の見え方**」
なので、入口を増やさない（§9.207）。ヘッダーの一等地は有限で、常設の物を
1つ増やすたびに主役の一覧が狭くなる。

札には**見本そのもの**を出す（§9.200「選ばせるものは選ぶ前に見える」）。
`ball-pulse`／`line-scale` という名前だけでは、どう動くのかは選ぶ前に
分からない。札自身が `data-loader` を名乗るので、**いま選んでいるものと
並べて**見比べられる。

## ⑤ 網が「節は2つ」と決め打ちしていた

`test_uisize.js` に「1つのバッジに**2つの**節が名前つきで並ぶ」という行が
あり、**正しい位置へ3つめを足しただけで落ちた**——§9.389 で書いたはずの
「群の顔ぶれを文字列で丸ごと固定しない」を、自分で踏んだ。

数ではなく**前後関係**で見るよう直した（どれも名前を持つこと、文字の大きさが
先頭、時間の書き方が2番目）。「この端末の見え方」はこれからも増える。
