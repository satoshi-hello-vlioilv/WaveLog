# §9.49 マスタ入力支援(マウスだけで入力を終える)

現場の端末はキーボードが使いにくい場所に置かれていることがあり、また手入力は
表記ゆれ(全角/半角・余分な空白)をそのままマスタへ持ち込む原因になる。
`buildFieldControls()` に型を足し、`bindInputHelpers()` が配線する。

| type | 見た目 | ねらい |
|---|---|---|
| `number` | `[−][ 1,500 ][＋] 単位` | 右づめ・3桁区切り・押しっぱなしで連続増減 |
| `date` | `input[type=date]` + 「今日」 | 標準カレンダー。表記ゆれが原理的に入らない |
| `time` | `input[type=time]` | 同上 |
| `master-combo` | 別マスタからの選択 + 「＋ 新しく追加…」 | 選ぶだけで済み、無い値は連動登録(§5.3.1) |
| `path` | 入力欄 + 「参照…」 + ドロップ | 実パスをマウスで選ぶ |

守ること:

- **最終的な値は `data-field` を持つ要素の value**。型を増やしても
  `submitMaint()` の読み取りは変えない。`master-combo` は hidden input が
  値を持ち、select と「新規入力」欄はその見た目にすぎない。
- **数値は表示と値を分ける**。3桁区切りが入ったままだと打ち直せないので、
  フォーカス時に素の数値へ戻し、blur で整形し直す。送信前は `numRaw()` で
  区切りを外す(`submitMaint` と `savePathConfigMaint` の両方)。
- **空欄からの「＋」は1目盛**。`min`を起点にすると「押したのに0のまま」に
  見える(min=0のとき)。
- CSS は `.mm-field input` より**特異度を上げて**書く。既存の
  `.mm-field input{min-width:200px}` に負けると右づめも幅も効かない
  (実際に踏んだ。`.mm-field .mm-num-input` で上書きしている)。

**パス参照ダイアログ**: ブラウザのファイル選択は安全上、完全なパスを返さない
(名前だけ)。本アプリは利用者自身の端末で動くローカルサーバーなので、
**サーバー側でディレクトリ一覧を返して辿らせる**(`GET /api/browse-path`)。
共有(UNC)も同じ経路で辿れるため `\\server\share\...` もマウスだけで選べる。
読み取り専用(一覧のみ・中身は返さない)で、待ち受けは127.0.0.1だけ。

ドラッグ&ドロップは `text/uri-list` → `text/plain` → `files[0].path`
(Electron等)の順に見る。エクスプローラーからのドロップは `file:///C:/...`
形式で入ることが多い。**どれも取れなかったときは黙って捨てず**、
「参照…から選んでください」と伝える(名前だけ入れると誤った設定になる)。
