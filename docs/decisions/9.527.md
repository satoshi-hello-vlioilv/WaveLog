# §9.527 フィンガーの材質で図の色を変える——材質は保持方式の表が決める（利用者の指示）

索引: [決定記録](README.md)

## 利用者の言葉

「フィンガーの材質で図の色を変えるも行ってください。」

利用者の選択: 材質は**保持方式の表で決める**／アルミニウムの色は**青みの銀（藍の淡色）**。

## 測った（評価関数）

同じ在庫（初期セットのベークライト14幅＝790本に、同じ幅のアルミニウムを3本ずつ＝42本足す）で、
板厚0.5（フィンガー）・50mm×22条を組んだ。前は 57df91e（VER2.413.0）。

| | 前 | 後 |
| --- | --- | --- |
| 在庫として数えた本数 | **832（材質を合算）** | 使う材質だけ（アルミ42／ベークライト790） |
| 区間の押さえが名乗る材質 | 無い（計算に材質が存在しない） | 使う材質（`hold.mat`） |
| 模式図のフィンガーの色 | 茶の1色（#7a5232） | 材質の色（アルミ #b0bae4） |
| 断面図・立体図の材質 | `holdf`の1つ（茶） | `holdffinger-al`（#b0bae4） |
| 説明の名前 | 「フィンガー」 | 「フィンガー（アルミニウム）」 |

網: `test_bladesets.js` ⑤（14件）。色の答えを茶へ固定する欠陥を入れると4件落ちることを確かめた。
`test_bladeset.py` に表の材質の往復（2件）。

## 決めたこと

- **1回の刃組で使うフィンガーの材質は1つ**。答えは`holdPick()`の`material`（当たった行の
  `フィンガー材質`・空欄は既定＝語彙の先頭のベークライト）。`fingerMaterial()`はその写し。
- `保持方式マスタ`に`フィンガー材質`の列。フィンガーの行だけが持ち、ゴムリングの行・知らない字は
  空欄（`_hold_material()`の1箇所）。盤の「→ 保持方式」は**方式×材質の1つの選択**
  （フィンガー（ベークライト）／フィンガー（アルミニウム）／ゴムリング）——答えの列を2つに割らない。
- 在庫は**材質ごと**に幅でまとめる（`IX.fingerByMat`・`fingerWidthsOf()`）。記録（稼働中の台車）の
  フィンガーは同じ材質のときだけ数える（記録に`fingerMaterial`を残す・無い古い記録は既定の材質）。
- 色の鍵は`fingerTone()`の1箇所（材質→`--bs-fig-*`の名前）。値は CSS のトークン
  （`--bs-fig-finger-al`＝`--rs-indigo-border`）。模式図・拡大図・断面図・立体図が同じ鍵を引く。
  フィンガーのときはゴムリングと潤滑リングが出ないので、見分ける相手はスペーサーの灰（#b3bfc5）。
  明るさは近いので**色相（青紫寄り）で離し**、縁は図の墨で締める。
- 画面の名前は`holdLabel()`（「フィンガー（アルミニウム）」）。`holdName()`は方式だけのまま
  （記録・判定の鍵を変えない）。
- 「足りない部材」は**使う材質の行**があるかで見る（ほかの材質だけ在っても組めない）。

## 分からないこと・残したこと

- 使う材質の在庫が足りないとき、ほかの材質で補うことはしない（混ぜない）。補う運用があるかは分からない。
