# §9.245 帳票ブロックの中身をマトリクスで並べる（利用者の指示）

> 帳票ブロックマスタにブロックレイアウト機能を実装してください。ブロックごとに
> データの配置をどのようなマトリクスに並べるか視覚的に調整できる機能が欲しいです。

これまで自作の塊は「ラベルと値の並びを N 列へ流す」だけで、**どの項目が
どこに来るか**は列数から推測するしかなかった。

#### 保存の形は変えない（後ろに足すだけ）

§9.226 ⑥の「保存の形は`ラベル=出どころ`のまま」を守り、**後ろに`|`で
横に使うマス数**を足せるようにした。

```
ロット番号=basic.lotNo|2   … 横2マスぶん使う
検査番号=basic.inspectionNo … 1マス（今までどおり）
|1                        … 空きマス（何も出さずに場所だけ取る）
```

- **`|`の無い行は今までどおり1マス**——既に登録してある塊はそのまま読める
- **1マスの項目に`|1`を足さない**——足すと、何も変えていない塊まで
  保存のたびに形が変わる
- 空きマスは**道もラベルも持たない行**。場所を取ることが役目なので
  **読む側で落とさない**（落とすとマトリクスが1マスずつ詰まって崩れる）
- 区切りに`,`と`、`を使っているので、**マス数の区切りは`|`**
- **読み方はサーバー（`parse_content`）と画面（`fbParse`）で同じにすること**
  ——2通りあると、設定画面で組んだ形と紙が食い違う

#### 盤は「紙のその塊そのもの」

「載せる項目」の縦1列の一覧を、**紙と同じマトリクス**へ変えた（見出しも
「紙での並び」へ）。縦の一覧では、何列になるのか・どこで折り返すのかが
読めない。

- 各マスに**横に何マス使うか**のつまみ（1〜列数）
- **列数は「内訳の列数」の欄が持ち主**（§CLAUDE 8。盤の列数ボタンはその欄を
  書き換えるだけ——同じ数を2箇所に持つと片方だけ直した状態が作れる）
- 「空きマス」ボタンで整列用のマスを足せる（§9.227 ③の空きカードと同じ
  斜線の地で出す）
- マス数の選択肢は**列数まで**（列数より広いマスは作れない）

固定は `tests/test_blockbuild.js`。
