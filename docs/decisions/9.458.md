# §9.458 拡大図の字は部材の中へ貼る——入らなければスペーサーは軸へ、保持層は外へ（利用者の指示）

索引: [決定記録](README.md)

利用者の指示:

> 拡大図のラベル、フィンガーやゴムリングもその材料の中に数値ラベル貼れるとおもうので、
> 極力貼って無理やり軸にラベル貼らず、軸に近いスペーサーで書ききれない場合は軸に、
> ゴムリングやフィンガーで書ききれない場合は軸と反対の外側に今と同じようにラベルを線を
> 同じように引っ張って書いてください。

---

## 何が起きていたか

拡大図の字は 13px 固定で「横に入る → 縦に入る → 軸の帯の中へ引き出す」の順だった。
フィンガーの帯は高さが約12pxしかなく、13px の字は**1枚も入らない**。そのため
**フィンガーの字は全部が軸へ引き出され**、軸の上に保持層の値が並んでいた。

## 物差し（3つの材料・両軸・全区間の拡大図・`probe8`）

| 物差し | 前 | 後 |
| --- | --- | --- |
| 保持層の字を軸へ引き出した数（104.9×11・フィンガー） | **12** | 0 |
| 保持層の字を中へ貼れた数（同） | 0 | 12 |
| 保持層の字を軸へ引き出した数（279.8×4・ゴムリング） | 4 | 0 |
| 保持層の字を中へ貼れた数（同） | 28 | 32 |

## どう直したか

- 中へ貼るのを先に試す: 13px 横 → 13px 縦 → **字を読める下限（9px）まで小さくして横**。
  縦を先に試す——縦なら13pxのまま入る部材の字まで小さくしない（最初は逆にして、
  `test_bladeui`「広い側でも縦に貼る」が1件落ちた）。
- それでも入らない字は**層で引き出し先を分ける**。スペーサー（と刃）は今までどおり
  軸の帯の中の段へ、保持層（ゴムリング・フィンガー・潤滑リング）は**部材のいちばん外より
  さらに外**の段へ。段の振り分け（`x`順）・線は字のきわから対象の中心へ・終端の点、は同じ作法。
- 外の段は白地の上なので、軸の地に合わせた淡い段の色では線が消えた。外の段だけ
  **濃い字と白い縁取り**にし、1段に入るなら1段にそろえる。器からはみ出すぶんは器を広げる。
- 引き出し線は `data-zl`（shaft／outer）と `data-layer`（core／hold）を名乗る——網が向きを数える。

いまの材料では保持層の字は全部中へ入るので、外の段は出ない。外の道は、下限を一時的に
99px にして確かめた（フィンガー12件・潤滑リング4件が外へ出て、線は外向き・白地で読める）。

## 網（`test_bladeui.js`）

- 全区間・両軸の拡大図で: 保持層の字を軸へ引き出した数＝0／線の向き（軸の段は軸へ・
  外の段は外へ）が逆の本数＝0／中へ貼った数値の字は9px以上／字は図の器からはみ出さない

フルスイートは下の§9.461と合わせて回す（利用者の指示）。
