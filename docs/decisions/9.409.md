# §9.409 終了ボタンが読めない／終了したらタブも閉じる（利用者の指摘）

## 利用者の言葉

> アプリ終了ボタンが**マウスオーバーの際に視認できないコントラスト**に
> なっているので修正してください。アプリ終了ボタンで終了時、**タブに残らず、
> そのままスッキリ終了**させてください。

## ① 明るい地用のトークンを、濃い地へ載せていた

```css
.nav-foot .nav-item--quit:hover{ background:var(--danger-bg,#5b2b2b); color:#ffd7d7 }
```

`--danger-bg` は**明るい地の上で危険を示すための面**（`#fdeaea`）。左ナビは
濃い紺（`--nav`＝`#173842`）なので、**淡いピンクの面に淡いピンクの字**が
載っていた。フォールバックの `#5b2b2b` は濃い地を想定した値だが、
**トークンが定義されているので一度も使われない**。

実測（重ねた結果の色で測る）:

| 状態 | 直す前 | 直した後 |
| --- | --- | --- |
| 重ねたとき | **1.1 : 1**（字が消える） | **8.86 : 1** |
| 素のとき | **2.55 : 1** | **4.64 : 1** |

**素のほうも割っていた。** `color:var(--muted)` も明るい地用で、濃いナビに
載せると 2.55:1。**控えめに置くこと（§CLAUDE 5 危ない操作を主要動線に
置かない）と、読めないことは別**なので、こちらも直した。

直した形は**トークンを足す**こと（16進をCSSの宣言へ書かない・§CLAUDE 7）:

| トークン | 値 | 使う場所 |
| --- | --- | --- |
| `--nav-ink-2` | `#84a3a9` | 濃い地の上の控えめな字（左メニューの管理系が持っていた値を昇格） |
| `--nav-danger-bg` | `#5b2b2b` | 濃い地の上の「危ない操作」の面 |
| `--nav-danger-fg` | `#ffd9d9` | その字 |
| `--nav-danger-border` | `#8a4141` | その縁 |

### 網は「目で見る」のをやめて測る

`tests/test_theme.js` が**実際に重ねて測る**（4.5:1＝WCAG AA の本文の線）。
測るときの落とし穴が2つあり、どちらも踏んだ:

- **`transition` を持つ値は当てた直後に読むと途中の値**（§9.386）。
  最初の実測は `rgba(91,43,43,0.345)`＝遷移の途中だった。**同じ値が2回続くまで**
  待ってから読む。
- **半透明の面はアルファを捨てて測ってはいけない。** 手前の面を奥の地へ
  重ねて（source-over）畳んでから測る。捨てると、薄い面を濃い面として数える。

## ② タブを閉じる

`window.close()` が通るのは**スクリプトが開いた窓**だけ。毎日の入口
（`Start.vbs` → 既定のブラウザ）で開いたタブは**ブラウザが開いた**ものなので、
断られる端末がある。**断られたかどうかはその場では分からない**——閉じられれば
その先は1行も動かないので、**少し待って（350ms）まだ生きていたら断られた**と
読む。そのときだけ今までの「終了しました」の画面を出す。

字も直した。以前は「このタブは閉じてかまいません」とだけ書いてあり、
**閉じるつもりだったのかどうか**が読めなかった:

> このタブは**自動で閉じられませんでした**（ブラウザが開いたタブは、ページから
> 閉じられないことがあります）。**このタブは閉じてかまいません。**

**「閉じました」と言わない**——言った直後に閉じなければ、その字そのものが嘘に
なる。閉じられた端末ではこの画面自体が一瞬も出ない。
