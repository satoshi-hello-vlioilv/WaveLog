# §9.145 基本情報カードのタブと条の設計モーダルの廃止（実装）

#### 品質規格はタブの裏（1回の操作で必ず出せる場所）

品質規格は「測る前に1回だけ確かめる」もので、マスを1つ使うほどではない。
基本情報カードの頭に`基本情報 / 品質規格`の2枚のタブを置き、`bindBasicTabs()`が
`[data-basicpanel]`を出し分ける。**②③ではタブごと消す**（測っている最中に
規格の表へ切り替える場面が無い）。

#### 条の設計の専用モーダルを廃止

利用者の指示「常時表示かつ、条の並び替え、公差の判定位置との連動など、今まで
実装していた機能をそのまま専用モーダルから移植する形で。機能をすべて移植し、
専用モーダルは廃止する」。`#splitModal`はDOMごと削除し、中身は2枚のカードへ
分けた——**上＝並べ替える帯**（横に長いほど掴みやすい）、**右下＝子ロット候補と
条割プレビュー**（縦に読むもの）。別の問いなので別のカードにする。

「この内容で条割を実行」ボタンも消した。**`renderSplit()`の`#applySplit`参照には
nullガードを置くこと**——消した瞬間に`Cannot set properties of null`で描画が
止まる。リアルタイム反映の配線は未接続で、次の段の作業。

状態パネルは1行に切り詰めた。以前は候補の表・開くボタン・履歴（既定open）を
全部持っており、**カードから214pxはみ出していた**。表とボタンは編集面が持って
いるので消し、履歴は畳んだ。実測: はみ出し 214px → **0px**。
