# §9.175 適用中のフィルタを個人単位で覚える（利用者の指示）

利用者の指摘は「閉じた後、再起動するとフィルタを適用した内容が外れてしまいます。
フィルタ適用状態も個人(PC)単位で保存するようにしてください」。

一覧を切り替えたときは戻るのに、アプリを開き直すと外れる——という食い違いだった。
控え（`activeFilterStateCache`）が**メモリのオブジェクトだけ**で、読み込み直すと
消えていた。`localStorage`（`MeasurementFilterActiveV1`）へ移す。

- **利用者ごとの入れ物**に分ける。同じPCを別の人が使うと相手の絞り込みが当たる
  （§9.172でデフォルト・鍵の印を個人単位へ移したのと同じ理由）。利用者IDは
  `/api/whoami`から**後から届く**ので、**読み書きのたびに引く**こと——起動時に
  1回だけ束縛すると空のIDのまま固定される。
- 覚える単位は今までどおり`db::table::mode`。**鍵付きの必須条件は覚えない**
  （`applyDefaultFiltersFor`が毎回導出し直す）。
- **0件の一覧は行ごと消す。** 空配列を残すと、覚えている一覧の数だけが増えていく。
- 書くのは`renderGenericFilterBar()`の1箇所。条件が変わる経路は多い（追加・削除・
  全解除・登録フィルタの適用・設定画面からのやり直し）が、**全部がここを通る**。
  経路ごとに書くと必ずどれかを書き忘れる。
- **覚えていることを画面に書く。** 黙って復元すると「勝手に絞り込まれている」と
  読まれる。登録フィルタ一覧の見出しに件数を出し、**忘れさせる手立て（覚えを消す）
  も同じ場所**に置く。

固定は`tests/test_filteractive.js`。

  固定は`tests/test_filteractive.js`。
