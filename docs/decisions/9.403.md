# §9.403 ICASコピーの「ルールなし」は区切らずにつなぐ（利用者の指示）

## 利用者の言葉

> ICASコピー機能の修正
> **ルール無しの場合、区切り無しの連結が良いです。**

## 何を変えたか

`WL.lotCopy.PLAIN`（ルールが1本も無いときの素のつなぎ方）の区切りを
**半角スペース1つ → 無し**にした。名前も
`ルールなし（半角スペースでつなぐ）` → `ルールなし（区切らずにつなぐ）`。

```
いままで  A1 A2 A3
これから  A1A2A3
```

## なぜ間違っていたか

§9.400でこの行を入れたとき、区切りを半角スペースにした理由をこう書いていた:

> 区切りは**半角スペース1つ**——「ICASコピー」という名前のとおり貼り先が
> 求める形で、区切り無しの棒つなぎ（`A1A2A3`）は貼っても使えないため。

**利用者の言葉より、こちらの推測を優先していた。** もとの依頼はこうだった:

> ルールなしの場合コピーは**ロットナンバーだけの連結コピー**になるなど、
> ルールがないとしてコピーができないではじくみたいなことのないように

「ロットナンバーだけの連結」と書いてあるのだから、**区切りを足さないのが
字のとおり**。貼り先が区切りを求めるなら、それは**ルールを1本作る**話で、
「ルールなし」の中身を勝手に決める話ではない（§9.367「利用者が入れた設定を
『保存されていない既定』にしない」と同じ筋）。

なお**例（seed）の2本は変えていない**——`ICAS（半角スペース）`と
`半角スペース＋10件ごとに改行`は今までどおり最初から入っていて、
そのまま使えるし直せるし消せる（§9.400）。区切りが要る人は例を使えばよく、
`PLAIN`はあくまで**1本も無いときの素の形**。

## 変えていないこと

- **「ルールが無い」をコピーを断る理由に使わない**（§9.400の要点）。
- `PLAIN`は**一覧に出さない**（出すと§9.367で撤回した「触れない既定」に戻る）。
  状態は**名前で言う**ので、メニューにも結果にもそのまま出る。
- つなぎ方の答えは`WL.lotCopy.joinLots()`の1箇所（§9.368）。

## 固定する網

`tests/test_lotcopy.js`:

- **ルールが1本も無ければ区切らずにつながる**（`A1A2A3`）
- ルールが1本も無くても**つなぎ方は必ず1つ決まる**（名前に「ルールなし」）
- ルールが1本も無くても**コピーがはじかれない**
- 子メニューは「ありません（押せない）」で手を止めない

欠陥注入で確かめた: `PLAIN`の区切りを`space`へ戻すと1件落ちる（`A1 A2 A3`）。

## 回した網

`tests/run_all.sh test_lotcopy` ＝ **42/42 PASS**。
このあと利用者の指示でフルスイートを回し、mainへ入れる。
