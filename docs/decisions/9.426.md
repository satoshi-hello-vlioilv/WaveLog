# §9.426 通しで1回だけ落ちた本を追えるようにする（`WAVELOG_TEST_LOGDIR`）

索引: [決定記録](README.md)

利用者の指示「赤の追跡して」。

## ① 何が起きたか

main へ入れる前の通し（1回目）で `test_choicelinkui.js` が **1件だけ FAIL**。
ランナーが最後に単独で回し直すと緑で、「順番・状態への依存」と出た。

**どの判定が落ちたかは残っていない。** 通しの出力を `tests/run_all.sh 2>&1 | tail -60`
で受けていたため、**失敗の行が切り落とされていた**（ランナーは本ごとの要約の下に
`FAIL:` の行を出すが、そこは60行より前にあった）。**捕り方の失敗**であって、
ランナーは必要なことを出していた。

## ② 切り分けたこと

| 疑い | 結果 |
| --- | --- |
| 他の本の置き土産（共有マスタ） | **無い。** ランナーは1本ごとに `restore_master` でマスタDBを**ファイルごと**戻す |
| この本が自分で残した親子を数えている | **無い。** `links()` は自分の `TAG` で絞っている |
| 本そのものが不安定 | **無い。** 単独で10回回して10回とも緑、値も毎回同じ |
| 再現するか | **しない。** 通しをさらに2回（生ログ付き）回して **7035/7035 PASS** が2回 |

したがって残るのは**時間・負荷に依存する競合**だが、**どの判定かを言えない。**
§9.200 のとおり「再実行で緑になったから」で片付けない——分かっていないと書く。

## ③ 次に出たとき、1回で分かるようにする

ランナーには**本ごとの生ログを残す口**がある（`run()` の中）:

```sh
WAVELOG_TEST_LOGDIR=<フォルダ> tests/run_all.sh
```

付けると `<フォルダ>/test_xxx.js.log` に**その本の出力がまるごと**残る。
**通しを回すときは必ず付ける。** そして**出力を `tail` で切らない**
（切るならファイルへ残してから切る）。

## ④ 次に見るべき順（緑のときの実測値つき）

疑う順は「**余白のいちばん小さい判定**」から。緑のときの値は:

| 判定 | 緑のときの値 | 余白 |
| --- | --- | --- |
| ⑩ 器からはみ出さない | `[0,0]`（許容 `≤1`） | **ゼロ**。1〜2pxで単独で落ちる |
| ⑥-a 落とし込みのあと帯の字が変わる | `… を結びました。`（30秒待ち） | 保存が遅れると単独で落ちうる。**この本は以前に15秒で1回切れている**（§9.352 追補） |
| ③ 木のほうが入れ物より広い | 木853 / 入れ物308 | 大きい |
| ②⑤⑦⑨⑧-b | 文字列 | 大きい |

⑩は単独10回では1pxも動かないので、**通しでだけ動く何か**（他の本が残した
`body` の印・窓の大きさ・字の読み込み）を疑うことになる。
**ただし、これは当たりを付けただけで、確かめていない。**
