# §9.609 推奨の更新の札と、使っている人への控えめな知らせ・版の管理を LotScope の型に（利用者の指示）

索引: [決定記録](README.md)｜前: [§9.608](9.608.md)｜関係: [§9.555](9.555.md)・[§9.556](9.556.md)・[§9.584](9.584.md)・[§9.515](9.515.md)・[§9.516](9.516.md)・[§9.597](9.597.md)

## 経緯（利用者の言葉）

> 配布する版に推奨アップデートの札を付けられるようにして、そのアップデートの版が配布されたら、表示を邪魔しない程度に使用中ユーザーに
> アップデートを促す通知を出すようにしてください。アップデートの版の管理するUIをLotScopeのようなUIにしてほしいです。
>
> UIUX改良の評価合格基準を見直し、1回目95点以上変わらず、2回目90点以上、3回目以降80点以上を基準に変更し案を決定できることにします。

## 1. 推奨の札（サーバー・`backend/app_update.py`）

- 札は置き場の直下の `recommend.json`（版ごとに `{note, setAt, setBy}`）。**版の属性**なので版ごとに持つ（配る版を戻して選び直しても残る）。
  窓（Rust）が読む `release.json` には入れない——窓の読む物を変えない・書き手は Python だけ（§9.563）。
- 付ける・外す口は `/api/app/update/recommend`（`set_recommend()`・置いてある版だけ・一言は80字で切る）。版を消すと札も消える。
- 知らせの答えは `notice_of(release, marks, mine, dev)` の1箇所: 配る版に札があり、この PC の版と違うときだけ（戻した版なら向き down）。
  開発の作業ツリー（`.git`・窓の `update::peek()` と同じ見分け方）では出さない——開き直しても配る版にそろわない。
- 届け方はハートビートに相乗り（`body.update`）。共有を読むのは裏で1分に1回（`notice_soon()`）、ハートビートは待たない。
- 古い版で動いている PC の台数は `presence.behind_release()`（開発者を数えない・在席があれば在席の版）。口は `/api/presence/release-spread`
  （接続状況を見られる区分だけ）。`routes/core.py` は共有の層を読み込まない（`test_portdep`）ので、在席の口に置いた。

## 2. 使っている人への知らせ（画面・`WL.updateNotice`）

- 閉じた形は**ヘッダーの状態の札1つ**（`#updateNotice`）。縁・地・値は中立、★だけ琥珀（琥珀は推奨の更新の意味にだけ使う。隣の
  「使用設備 未設定」の橙と取り違えない）、▾ で押せると言う。なぜ（一言）は `title`。
- 押すと小さな面（`.wl-menu.update-pop`・`WL.popMenu`）: なぜ・この PC → 新しい版・データはそのまま・「あとで｜開き直して更新」。
  窓の外（開発の入口）では「開き直して更新」を出さず、×で閉じて開き直すと書く。
- 「開き直して更新」は失うもの（`WL.closeGuard`）を先に確かめ、窓の `/__desktop/restart` へ頼む。窓は**いまの exe** を `--after-pid` で
  起こし直して終わる（`launch::restart()`）。新しい窓は起動のときに配る版へそろえる（§9.555・exe が変われば `relaunch()`）。
- 札が出ている間は「新しい版あり」（§9.515）を伏せる（同じことを2箇所で言わない）。

## 3. 版の管理（共通設定 → アプリの更新・LotScope の型）

- 流れ ①②③ は**上の太い線**で状態を言う（済み＝灰・決めた＝青緑・待ち＝薄い青緑の点線）。面は塗らない。③が古い版の PC の台数を言う。
- 版の表は角丸の外枠・34px の見出し・42px の行・淡い地に濃い字の丸い札（配っている＝緑・前に配った＝灰・★ 推奨の更新＝琥珀・この PC＝青緑）。
- 新しい版は塗りの「この版を配る ▾」、古い版は縁取りの「この版に戻す ▾」。▾ で「★ 推奨の更新として配る」（一言を聞いて、配る→札の順）。
  配っている版の行は「★ 推奨にする／推奨を外す」（外すのは1手）。消す道は今までどおり「版を整理する…」の中だけ（§9.584）。
- 左の段の「更新待ち」は中立（待てば済む・琥珀を推奨に取っておく）。
