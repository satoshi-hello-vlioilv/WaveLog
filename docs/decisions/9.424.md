# §9.424 台車は設備の持ち物にする（台車マスタ）（利用者の指示）

索引: [決定記録](README.md)

利用者の指示（この順に届いた）:

> 台車マスタは、A台車、B台車を登録しておいてください。設備ごとですが
> スリッターがない設備もあるので。
>
> 刃組ガイダンス使う設備＝台車マスタ必要
>
> ごくまれにスリッターがある設備でも、台車なしというパターンがありました。
> 自動で組み込む必要はないですが、スケジュール上の選択肢として使えるように
> してください。

## ① 何が壊れていたか

台車の札は**画面のHTMLに直に書いてあった**:

```html
<button class="bs-chip is-on" data-car="A">A</button>
<button class="bs-chip"       data-car="B">B</button>
```

このため、

- **3台あるラインを登録できない**（2台に決め打ち）
- **呼び名を変えられない**（現場は「A台車」と呼ぶのに画面は「A」）
- **台車を使わないラインを表せない**（必ず2台あることになっている）
- 既定が `carriage: 'A'` なので、**A台車の無いラインでも「A」で記録できて**しまう

サーバー側も `carriage_state()` が `len(out) >= 2` と書いており、同じ決め打ちが
2箇所にあった。

## ② 台車マスタ（設備ごと・1台1行）

| 列 | 何を持つか |
| --- | --- |
| 設備名 | どのラインの台車か（**「すべての設備」は無い**・§9.377と同じ） |
| 台車名 | 現場の呼び名。**これが記録（`刃組履歴マスタ.台車`）に残る値** |
| 備考 | 資産番号など |
| 表示順・有効 | 並びと入切 |

**専用の画面は作らない。** マスタ管理の「テーブル」から編集できる
（§9.249 ②の汎用CRUD）ので、4本のルートを足す理由が無い——
`backend/routes/masters/bladeset.py` は16ルートあり、1段20ルートの約束
（§9.333）にも近い。

**行を持つのは刃組ガイダンスを使う設備だけ**（利用者の言葉「刃組ガイダンス
使う設備＝台車マスタ必要」）。入れ方は**初期セット**（`seed_standard_parts`）に
畳んだ——部材を入れる操作と同じ1回で `A台車`・`B台車` が入る。スリッターの
無い設備では初期セットを押さないので、1行も作られない。

**`replace=True`（入れ替え）でも台車は消さない。** 部材を入れ替えても台車
そのものは同じ物で、記録が**名前で**結び付いている——消すと差分の相手を失う。

## ③ 台車なしのラインは「1行足せば選べる」

**初期セットには入れない**（利用者の指示「自動で組み込む必要はない」）。
めったに無い形なので既定で3枚目の札を出すと、ふつうのラインの選択肢が増える。
綴りだけをサーバーが持ち（`CARRIAGE_NONE = '台車なし'`）、台車マスタへ1行
足せばそのまま札に出る。**どこへ何を足すかは画面が言う**（記録できないときの
`title` に、初期セットで入る顔ぶれと「台車なし」の綴りを両方書く・§CLAUDE 4）。

### 台車が1つのラインでは、直前の刃組が組み替える相手

2台を交互に使うラインでは、直前の刃組（履歴の先頭）は**ラインで稼働中**なので
飛ばし、その次に見つかる同じ台車の記録と比べる。**台車が1つならこれが逆**
——いま機械に載っているのが直前の刃組そのもので、それが組み替える相手。

飛ばしたままだと2つ壊れる:

1. **1つ古い記録と比べる**（差分が事実と違う）
2. 「稼働中なので外せない」という**嘘の断り**が出る（外して使う台車なのに）

そこで比べ始める位置を `台車の数 > 1 ? 1 : 0` にし、「稼働中で外せない」の
断りも**別の台車のときだけ**出すようにした。

## ④ 呼び名を重ねない

台車名そのものが「A台車」になったので、画面の字から添え字の「台車」を外した
（「台車 A台車」と読ませない）。直した先は刃組ガイダンスの差分・履歴・記録の
確認窓と、作業スケジュールの台車チップ・状態の窓。

## ⑤ 網（`test_bladeset.py` / `test_bladeui.js`）

- 初期セットで `CARRIAGE_SEED` のとおり入る／2度押しても増えない／
  `replace` でも消えない／別の設備へ混ざらない／空の名前は断る
- 「台車なし」は**初期セットに入らない**
- 画面の札は**器（`#bsCarPick`）の中だけ**——器の外に `data-car` があれば
  マスタを通っていない札なので落とす
- **台車マスタへ1行足すと札も増える**（2台の決め打ちではない）
- 台車が1つなら直前の刃組と比べ、「稼働中」と断らない

欠陥注入で確かめた（1件ずつ入れてその場で戻す・§9.399）:

| 入れた欠陥 | 結果 |
| --- | --- |
| 台車が1つでも直前の刃組を飛ばす | 2件 FAIL |
| 札の顔ぶれをマスタでなく決め打ちで作る | 3件 FAIL |
