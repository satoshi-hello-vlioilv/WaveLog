# §9.4 並べ替え操作

`static/js/measure/lot-split.js` の条割ドラッグ(単一ジェスチャー + ゴースト挿入位置表示)で
確立した操作語彙をそのまま使う。新しい操作を覚えさせない。

- ドラッグ&ドロップで並べ替え → 離した時点で `reorder` をPOST
- キーボード操作も用意する(`Alt+↑/↓` で選択中カードを上下移動)。
  キーボード動線の監査を一度通した経緯があるため、新規UIも同水準を保つ。
- 楽観更新はしない。POSTの応答(再展開済みの予定一覧)で描き直す。
  並べ替えると後続の全時刻が変わるので、サーバー計算結果で塗り替える方が
  ローカルで再計算するより安全かつ単純。
- ドラッグ対象は `reorderable:true` の予定のみ(§7.5)。着手中・完了・
  固定開始日時が現在時刻より前の予定は掴めないようにする(掴んだ瞬間に
  ドロップを弾かれる方が、ドロップ後にエラー表示される体験より分かりやすい)。
