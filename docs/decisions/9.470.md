# §9.470 基準面の切り替え（OS／DS）を外す——基準面は駆動側の DS に固定（利用者の指示）

索引: [決定記録](README.md)

## 利用者の言葉

> 基準面をOSに切り替えるという機能は不要になり、ラベルをどうするかの機能があれば解決します。
> また、右と左を入れ替えて表示する機能もあるので事足ります。

§9.466 の「分からないこと」（基準面を OS にしたとき立体図のシートをどちらの端に描くか）への答え。
§9.466 で確かめた実機の事実は「ギアボックス側DS(基準面)、スタンドハンドル付きの外れる方がOS」
「基準面は駆動側」——**基準面を OS にする運用は実機に無い**。見せ方の左右は「基準原点を左／右」の札と、
その呼び方（刃組基準値の`viewLabelLeft`／`viewLabelRight`・§9.463）が受け持つ。

## 外したもの（§9.461 で入れた切り替え）

| 物差し（切り替えの口） | 前 | 後 |
| --- | --- | --- |
| 刃組基準値の編集窓の欄「基準面（基準原点）」 | 1 | 0 |
| 保存の鍵（`datumSide`・列「基準面」）と読み分け（`datum_side()`） | 1 と 1 | 0 と 0 |
| `datumOf()`がマスタを読む | 読む | 読まない（常に DS） |
| 切り替えを確かめる網 | 7件 | 0（代わりに「無いこと」を3件） |

- `datumOf()`は**1箇所の答えのまま残す**（`DATUM='DS'`）。組む順・中心の測り方・シートの端の説明は
  「基準面」という考えで書いてあり、同じ答えを見る——分岐を消して`'DS'`を書き散らすと、答えが
  散らばる（§CLAUDE「答えは1箇所に持つ」）。
- **すでに在る DB の列「基準面」は残す**（読み書きしない）。消すと古い版へ戻したとき列が無くなる。
- **古い記録の互換は残す**: OS 基準のときに記録した刃組は、中心を DS からの距離へ読み替える
  （`applyRecord`の`s.datum`）。
- 「板の中心」の欄の名前を「（基準面から）」→「**（DSから）**」に（測る端がいつも同じになったので言い切る）。

## 固定する網

- `test_bladeset.py` … 既定値に基準面の鍵が無い／送っても保存しない
- `test_bladeui.js` … 古いマスタに OS が残っていても基準面は DS・シートは OS 端／中心は DS から測る
- `test_stdmodal.js` … 編集窓に「基準面」の欄が無い（選ぶ欄の見本は「図の基準原点の位置」へ）
