# §9.476 「☰ 表示」パネルを整える——表示列の編集をいちばん上・アイコン付きに、字と欄の大きさを1つに（利用者の指示）

索引: [決定記録](README.md)

## 利用者の言葉

> 仕掛の表示のポップオーバーメニュー内の文字のサイズの統一感やUIUXのわかりやすさ、使いやすさを意識して
> 設計、整理してください。他にも表示関係で共通仕様の部分があれば合わせて調整・修正、改良してください。
> 整列した感じや美観にもこだわって必要な機能をスマートに使いやすくしてください。
> また、表示列の編集はよく使うので、アイコンを設定したりして特にわかりやすくしてほしいです。

## 測った（1728×1030・`scratchpad/test_zprobeview.js`）

| 物差し | 前 | 後 |
| --- | --- | --- |
| パネルの中の字の大きさ（ボタンの字も含む） | 4種（10・11・12・13px） | 1種（12px＝`--fs-sm`） |
| 欄の高さ（行の中） | 26px と 30px | 30px（`--ctl-h-sm`） |
| 値の欄の左端 | 1種 | 1種（保った） |
| 表示列の入口 | 「列」の行の小さな札（3357px²・アイコン無し） | いちばん上の主ボタン（14622px²・`fa-table-columns`・何ができるかの一言つき） |
| 並びの行 | 2段（49px。「指定なし」と「いつも使う並び」が割れる） | 1行（30px） |

字が割れていた元: 帯の`.list-pagesize>span`（付随情報の寸法 `--fs-badge`）が、パネルの`.lvp-k`より詳細度が
高く勝っていた（表示件数の名前だけ 10px）。選ぶ欄も帯の`--ctl-h-xs`（26px）のまま。

## 決めたこと

- **表示列の編集はいちばん上・いちばん大きく**: アイコン＋「表示列を編集」＋「出す列・並び・幅・書式・読み替え」
  ＋行き先の矢印。塗りは主な操作の色（teal）——パネルの中で「次にすること」を1つだけ指す（§CLAUDE 画面基準 2）。
  「列」の名前の行は無くした（ボタンが名乗る）。
- 下の行（行間・並び・表示件数・子ロット）は**同じ字の大きさ・同じ高さ・同じ左端**（名前の列は固定幅）。
  パネルの規則は`.lt-view-panel`で名乗る（帯の規則に負けない）。
- **字の大きさはパネルの中で1つ**（利用者の追補「表示件数が他より小さくないですか？UI内の文字列も含めて
  文字サイズの統一感」）。表示列の編集の名前と説明も同じ 12px で、差は**太さと濃さ**で付ける。
- 行間は**いまの値を字でも言う**（いちばん詰める／詰める／ふつう／広め／いちばん広い）。つまみの位置だけで
  推測させない（§CLAUDE 画面基準 6）。
- 並びは1行（いまの並び＋いつも使う並び）。メニューは行の下いっぱいに開く（パネルの中・§9.201）。
- **表示列の入口は画面をまたいで同じ印**（`fa-table-columns`）: スケジュール表は元から、実績データの一覧に足した。
