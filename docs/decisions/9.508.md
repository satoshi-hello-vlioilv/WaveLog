# §9.508 ヘッダーの状態の札を「名前 値」の1行に——字は隣の操作と同じ1つ、画面名は縮ませない（利用者の指示）

索引: [決定記録](README.md)

## 利用者の言葉

§9.505〜§9.507（一覧の上部メニューを「1面1サイズ」に）のあと、残る候補として「ヘッダーの札（『モード』『使用設備』の 9.5px）」を
挙げたところ:

> 進めて

## 測った（評価関数）

ヘッダー（`main>header`）の1行目の右側（状態の札＋操作ボタン）の**字の大きさの種類**、札の名前の**白地とのコントラスト**、
題（`.hd-context`）の**切れた字・はみ出し**。5つの画面（仕掛一覧・品質データ・データ一覧・実績・作業スケジュール）×
表示サイズ3段×画面幅（1100／1180／1200／1280／1366／1536／1728／1920px）。

| 物差し | 前 | 後 |
| --- | --- | --- |
| 右側の字の大きさ（中） | **3種**（札の名前9.5・値13・ボタン14px） | **1種**（14px＝`--fs`） |
| 札の名前のコントラスト | **2.61〜2.91:1**（`#8a9aa0`・目安の4.5に届かない） | **5.87:1**（`--ink-3`） |
| 状態の札の幅（中・3枚） | 276px | 479px（＋203px） |
| 画面名が切れる組み合わせ（1100px・3段×5画面） | **4**（中の実績、大の仕掛・データ一覧・実績） | **0** |
| 題が札の下へはみ出して重なる組み合わせ | 0 | **0**（途中の案では1100pxで最大76px・下の「踏んだ」） |
| 1280px以上で切れる字 | — | 出どころの1行だけ（画面名は切れない） |

1536px以上（利用者の常用の1728pxを含む）では、どの画面・どの表示サイズでも何も切れない。

## 直したこと

- **札を「名前 値」の1行に**。名前は細く薄く（500・`--ink-3`）、値は太く濃く（800）——一覧の帯の「元データ 9/17 10:14」
  「読込 23:14」（§9.506）と同じ書き分け。字は隣の「表示」「画面を印刷」と同じ`--fs`（ヘッダーの標準の操作の寸法）。
  札の色（編集＝緑・閲覧＝灰・スケジュール＝青・未設定＝橙）は変えていない。色のリテラルが1つ減った（`#8a9aa0`）。
- **画面名は縮ませない**（`#fileName{flex-shrink:0}`）。幅が足りないときに譲るのは出どころの1行（案内）だけ（§9.229 ⑤
  「縮んでよいのは案内だけ」）。前は2つが同じ割合で縮み、「測定実…」と画面名まで切れていた。
- **1180px以下では札の名前を畳み、値だけにする**（`.hd-chip-key{display:none}`）。名前は3枚とも説明（`title`）が持つ
  （「編集モードです…」「現場段取り: …」「この端末で使用する設備を…」）。一覧の帯が狭い器で字を畳む（§9.505）のと同じ作法。

## 踏んだ

1行の「名前 値」は2段組より横に広い（中で＋203px）。題の器（`minmax(0,1fr)`）が狭くなり、画面名を縮ませないようにした
ところで、**1100pxでは題が器からはみ出して札の下へ重なった**（中の仕掛一覧18px・大で最大76px）。網の「1100pxでも1行目が
1行」は重なりを見ないので通っていた。1180px以下で名前を畳んで0pxにした。

## 分からないこと

- 1181〜1279pxの幅は1200／1280pxで測った（重なり0・画面名の切れ0）。その間の全部の幅は測っていない。

## 固定する網

- `test_headbar.js`
  - 右側（状態の札・操作）の字は1種／札の名前は地に対して4.5:1以上（描かれた色を札の地と重ねて測る）
  - 1100pxでは札の名前を畳み、どの札も説明（`title`）を持つ
  - 880px（題の器に中身が入りきらない幅）・中と大で、画面名が切れず、題が札に重ならない。前提として出どころの1行が
    実際に譲っていることも見る。**1100pxで見ないのは**、網の状態（札2枚・使用設備「LS4」）では余りが中219px・大178px
    あり、欠陥を入れても通ったため。
- 欠陥注入で確かめた（1件ずつ入れてその場で戻す）: 名前の字を9.5pxへ戻す／色を`#8a9aa0`へ戻す／狭い窓で名前を畳まない
  （2件落ちる）／画面名を縮ませる——どれも落ちる。

## 回したもの

- 札の変更（網を足す前）で、**全件が走った**（7748/7748 PASS・名指し0・2258秒）。`--changed`の後ろにテスト名を並べたため、
  それが「変更ファイルの名前」として読まれ、どの規則にも当たらず全件へ倒れた——**利用者の指示の無い通しで、誤り**。
  `--changed`の後ろに置けるのはファイルの名前だけ。
- 網を足したあと: 名前指定の15本（464/464）、`--pure`。
