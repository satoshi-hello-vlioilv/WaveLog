# §9.354 globals は実物から作る。ファイルを閉じたら網が「外から呼んでいる」を教える

`docs/REVIEW_2026-09.md` §6.3 3-17「旧5本のグローバル関数を名前空間へ」の**土台**。
閉じる作業そのものはまだしていない——**閉じたときに漏れを機械が教える**ようにした。

## 何が起きていたか

画面のJSは `<script>` を順に読む素のグローバルで、**5本のファイルが 458 の関数を
グローバルに置いて**いる（records-store 119・list-view 106・base 85・measure-view 78・
measure-input 70）。これを1本ずつ IIFE で閉じるのが 3-17 だが、
**閉じたときに「外から呼んでいた箇所」を見つける手立てが無かった**。

`eslint` の `no-undef` は「この構成では意味を持たない」として off にしてあった
（別ファイルから使われるだけの名前が全部 undefined になるので）。

## 決めたこと

1. **globals を実物から作る**（`eslint.config.mjs`。設定は `.mjs` なので Node が
   ファイルを読める）。「どのファイルのトップレベルに何があるか」を走査して
   `languageOptions.globals` にする。手で並べた一覧は腐るが、これは腐らない。
2. **IIFE で閉じたファイルからは `window.x=` の公開だけを採る。** だから
   **閉じた瞬間にその名前は globals から外れ**、外から呼んでいれば `no-undef` が出る。
3. `no-undef` は**画面のJSだけ** `error`（テストは Node で動き `require`/`process` を持つ）。
   `no-redeclare` は `builtinGlobals:false` にする——globals は自分たちの名前なので、
   定義した本人が「グローバルと同じ名前だ」と怒られてしまう。見たいのは
   **同じファイルの中の二重定義**（§9.326 の `fmtMin`）。
4. `test_eslint` に自己検査を3つ: 無い名前の呼び出しで `no-undef` が出る／
   **IIFE で閉じたファイルの中身を外から呼ぶと落ちる**／注いだ二重定義を数える。

## 見つけた本物の不具合（1件）

`report-dashboard.js` の印刷の失敗時、

```js
if(typeof toast==='function')
  toast('帳票だけの書類を作れなかったので、画面ごと印刷します（'+e.message+'）','warn');
```

**`toast` という関数は無い**（`showToast`）。`typeof` で囲ってあるので例外にはならず、
**断りの一言が一度も出ていなかった**——「黙って落とさない」と書いた本人が黙っていた
（§9.328 の趣旨に反する）。`showToast('画面ごと印刷します', 理由)` に直した。

**`typeof x==='function'` のガードは、名前を間違えても黙る。** 網が無いと見つからない。

## 閉じたときの見積もり（この網で測った）

| 閉じるファイル | 外からの呼び出し（`no-undef`） |
| --- | --- |
| `list/list-view.js` | **20**（`load` 12・`renderGrid` 3・`listLayoutTarget` 2・`selectDb` 2・`init` 1） |
| `measure/measure-input.js` | 25 |
| `measure/measure-view.js` | 64 |
| `measure/records-store.js` | 74 |
| `core/base.js` | 4,681（`esc` 1865・`$` 1019・`S` 680・`showToast` 439・`api` 204） |

REVIEW は「records-store（ほかから呼ばれる面が最小）」から始める順にしていたが、
**実測では list-view が最小**（20 対 74）。順番は測ってから決める。

## 踏んだ罠

- 最初は「行頭にある `function` はトップレベル」という近似だけで globals を作った。
  IIFE で包んでも**元の行の字下げは変わらない**ので、包んだファイルの関数が globals に
  出続け、**5本すべて「閉じても no-undef が 0 件」**になった（網が黙った）。
  字下げではなく**ファイルの先頭が `(function(){` かどうか**で見分ける。
- 「網が緑だから守れている」ではなく、**わざと閉じてみて数が出るか**を確かめる。
