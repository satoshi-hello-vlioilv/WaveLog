# §9.482 断面図の寸法の字は5段から選べる——既定は1段上（11px）、段は文字サイズのトークン（利用者の指示）

索引: [決定記録](README.md)

## 経緯

利用者の指示「刃組図の断面図について、寸法のラベルが小さいので1サイズ上げてほしい。小さく見たい時と大きく
したい時もあると思うので、今のサイズを小さいサイズの下限として、4段階くらい上げられるように調整機能搭載
できますか？今あるトークンに合わせての設定でよいので使えそうな規格があればそれに応じて段階設定して」。

前は`blade-3d.js`の`DIM_FS = 9`（px の直書き・トークンの刻みの外・表示サイズ`--ui-scale`も効かない）。

## 段の決め方

文字サイズのトークンは小さい順に`--fs-tiny` 9.5／`--fs-badge` 10／`--fs-micro` 11／`--fs-sm` 12／
`--fs-base-sm` 13／`--fs-title` 15（px・表示サイズ「中」）。

- **下限は`--fs-tiny`（9.5px）**——前の 9px にいちばん近いトークン。
- **`--fs-badge`（10px）は段にしない**——tiny と 0.5px しか違わず、押しても変わって見えない（押しても
  何も起きないように見えるボタンを作らない）。
- 残りを小さい順に4段: 11／12／13／15px。**既定は1段上の 11px**（「1サイズ上げて」）。
- 段は**トークンの名前**で持ち、描く器へ`font-size:var(--fs-…)`を当てて**計算された px を読む**。字の幅の見当
  （置けるかどうかの判定）も同じ値から出す——値を2箇所に書かない。表示サイズ（小／中／大）も効く。
- 段は**この端末に覚える**（`localStorage`・人ごとの見やすさなので共有しない。読めなければ既定）。
- 操作は断面図の下の帯に「寸法の字 − 11px ＋」の1組（数で決まる設定は「− 数 ＋」・§9.247）。端の段では
  押せない。字を描くのは断面図だけなので、群も断面図のときだけ出す。

## 測った

物差しは断面図の寸法の字——① 字の px ② 中へ書けた数 ③ 引き出した数 ④ 置けなかった数（割合）
⑤ 字どうしの重なり ⑥ 器からのはみ出し。材料は両の端（§9.418）。

| 段 | 字 | 既定の材料（81件）置けず | 50mm×22条（192件）置けず | 重なり | はみ出し |
| --- | --- | --- | --- | --- | --- |
| 前 | 9px | 10（12%） | 22（11%） | 0 | 0 |
| 1 | 9.5px | 10（12%） | 23（12%） | 0 | 0 |
| **2（既定）** | **11px** | 18（22%） | **74（39%）** | 0 | 0 |
| 3 | 12px | 23（28%） | 108（56%） | 0 | 0 |
| 4 | 13px | 25（31%） | 109（57%） | 0 | 0 |
| 5 | 15px | 25（31%） | 111（58%） | 0 | 0 |

**字を大きくするほど置けない字が増える**（器の大きさは同じで、字の数は変わらないため）。置けなかった数は
これまでどおり図の帯が「寸法 N 件は入りきらない（記号を押すと拡大図）」と言い、拡大図では全部読める。

## 決めたこと

- 「置けないのは2割まで」（§9.443）は**いちばん小さい段で**守る約束に言い直す——全部を見たいときは下げれば
  出る。既定の 11px では混んだ材料で4割が拡大図送りになる。これは**利用者が決めること**（既定を9.5pxに
  戻すか・置き方の作りを広げるか）として報告した。
- 重なり0・数え落とし0（中＋外＋置けず＝全部）はどの段でも守る。

## 網

`test_bladeui.js`「断面図の寸法の字は既定で1段上（2／5段・11px）…」「いちばん小さい段は…9.5px…」
「寸法の字は5段（9.5→11→12→13→15px）で、どの段でも数え落とさず重ねない…」「段を戻せる」。
「置けなかった寸法はごく一部（2割まで）」はいちばん小さい段で見る。
