# §9.410 デスクトップの起動ショートカットを作る／アイコンも選べる（利用者の指示）

## 利用者の言葉

> デスクトップにWaveLogの**起動ショートカットを作成する機能**が欲しいです。
> **アイコンも設定できますか？**

答えは「できます」。2つから選べる——**アプリのマーク**（このアプリが描く
`.ico`）と、**利用者が指定したファイル**（`.ico` / `.exe` / `.dll`）。

## 行き先は毎日の入口1本

作るのは `.lnk` 1本で、行き先は `Start.vbs`（§9.405「入口の名前は
いつ押すかを言う」・§9.406 で直下に残した1本）。**別の起動路
（`start_app.bat` 等）を選べるようにしない**——入口が2つになると、現場の
ショートカットだけが古い入口を指したまま残る。

## なぜWSH（`cscript`）で作るか

`.lnk` はただのファイルではなくシェルのオブジェクトなので、COM越しにしか
作れない。**道は1本にする**:

| 選択肢 | 採らなかった理由 |
| --- | --- |
| PowerShell（`WScript.Shell` COM） | 工場の端末は実行を止めていることがある。WSHと2本持つと、片方だけ直した状態が作れる |
| pywin32 等の追加依存 | `program/requirements.txt` は `flask` だけ（§9.268） |
| **WSH（`cscript`）** | **この端末では毎日 `Start.vbs` が動いている**＝WSHは必ず使える |

補助スクリプト（`make_shortcut.vbs`）は端末ごとの `runtime_dir()` へ置き、
**中身が違うときだけ**書き直す。**ASCIIだけで書く**——WSHはBOMの無い`.vbs`を
ANSIとして読むので、日本語を入れると端末の言語設定によっては化けて落ちる。

## デスクトップの場所はレジストリから

`%USERPROFILE%\Desktop` で決め打ちしない。OneDriveを使っている端末では
デスクトップがそこではなく、決め打ちすると**画面に出ないショートカット**が
できる。`HKCU\…\Explorer\Shell Folders` の `Desktop` を先に見て、読めなければ
既定の場所へ落ちる。

## アイコンは同梱せずコードで描く

アプリのマークは**起動待機画面（`program/loading.html`）のSVG**が原本。
`.ico` をリポジトリへ置くと**同じ絵が2箇所**になり、片方だけ直した状態が
作れる。`backend/app_icon.py` が同じ形・同じ色を**コードで描いて** `.ico` を
組み立てる（`zlib` と `struct` だけ＝標準ライブラリ）。

| 決めたこと | 理由 |
| --- | --- |
| 大きさは 16/24/32/48/64/128/256 | Windowsが使うのは16/32/48/256。中間も入れて拡大の粗を避ける（全部で40KB） |
| **256だけPNG、それ以外はDIB** | 古いシェルは小さい寸法のPNG入り`.ico`を読まないことがあり、そこだけ絵が消える |
| 作り直すのは `ICON_VERSION` が変わったときだけ | 実測 0.26秒／4寸法。毎回描くと設定画面を開くたびに待たされる |
| 置き場は端末ごとの `runtime_dir()` | アプリ本体は共有に置かれる運用がある（§9.225と同じ理由） |

画面の**見本も実物と同じ絵**にした（§9.374）——`GET /api/app/icon.png` が
`app_icon.render()` をそのまま返すので、CSSで似た絵を描き直さない。

## 断り方

**作れないときは理由を返し、ボタンを出さない**（§CLAUDE 4）:

- Windows以外の端末 … 「この機能はWindowsでだけ使えます（この端末は linux）」
- 入口が見つからない … 「起動ファイル（…\Start.vbs）が見つかりません」
- 指定のアイコンが無い・使えない拡張子 … **黙って既定へ落とさない**（§9.231）。
  落とすと、選んだファイルが無いことに気づけないまま違う絵で作られる。

## モードでは塞がない

`core.app_shortcut_create` は3モードとも通す（`_ENDPOINT_EXTRA_MODES`）。
**この端末のデスクトップに`.lnk`を1本置くだけ**で、共有にもマスタにも測定
データにも触れない。むしろ現場の端末（スケジュールモード）・閲覧専用の端末
こそ入口のアイコンが要る。ここを開け忘れると、押しても403で黙って弾かれる。

## 画面の置き場

共通設定 ＞ **この端末**（§9.208 ⑨で作った章立て）。PC名・ログインID・モードと
同じ「この端末の話」なので同じ章に置く。作成先（`…\Desktop\測定伝送システム.lnk`）と
起動するもの（`…\Start.vbs`）を**押す前に読める場所へ**出す（§CLAUDE 6）。

既定の名前は `測定伝送システム`——**画面で名乗っている名前**にそろえる
（デスクトップに `WaveLog` とだけ出ても、現場は何のアイコンか分からない）。
名前は変えられる。
