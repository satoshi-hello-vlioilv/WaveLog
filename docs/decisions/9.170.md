# §9.170 まとめて予定へ入れる／まとめて予定から外す（利用者の指示）

利用者の指示は「仕掛データからD&D操作でスケジュールを作成するときに複数選択で
一括D&Dスケジューリング、逆もしかりで一括スケジュール除外機能も」。

入れる側（仕掛一覧のチェック→まとめてドラッグ／まとめて投入）は§9.5・§9.10で
既にあった。**戻す側が1件ずつだった**——入れるのは一度に何件でもできるのに、
外すのは行ごとに🗑を押して確認を押す、では釣り合わない。

#### 外す側（タイムライン）

- **選ぶ道具は取っ手の列へ同居させる。** `.sc-row-head`と`.sc-row-line`は
  **同じグリッド定義を共有している**のがこの表の土台なので、列を1本足すと
  定義が2通りになり、片方だけ直した状態が作れる。1列目の幅を
  `--sc-handle-col`で持ち替え、チェックと⠿を並べる（`#scTimeline.sc-pickable`）。
- **チェックが出るのは`removableEntry()`が通す行だけ。** 実施中・完了・計画外・
  追加中には出さない——出しておいて落としたら断る、では選んだ手間が無駄になる
  （受け皿と同じ約束、§9.116）。全選択の分母も「外せる予定」だけ。
- **件数と対象は文字で出す**（`#scPickBar`）。仕掛一覧の選択件数バー
  （`plan-select-bar`）と同じ形・同じ言葉・同じ並び順にする。行の面の色だけでは
  何件選んだか数えることになる。
- **確認は1回だけ。** 20件外すのに20回押させると、読まずに押す癖が付く。
  件数・ロット番号・戻り先（仕掛一覧）・消えないもの（測定データ）をまとめて言う。
  1件のときは今までどおり`deleteEntry()`を通す（確認の作法を2つに増やさない）。
- **まとめて掴んでいる間は並べ替えない。** 動かせるのは掴んだ1行だけなので、
  通り過ぎた位置に1行だけ置き去りになる。掴んだ一式は`scState.dragIds`に入れて
  `dragId`と見分ける（`dragId`だけを見ている既存の経路を壊さない）。
- **受け皿は件数を言い直す**（「選んだ3件をまとめて外します」）。「この予定を
  外します」のままだと1件だけ外れると読める。
- **消えた行のidを持ち続けない。** 描くたびに`removableEntry()`で今ある行へ絞る
  ——外したあと・設備を切り替えたあとに件数だけ合わない状態を作らない。

#### 入れる側（仕掛一覧）で足したこと

- **運んでいる行を全部そう見せる。** ブラウザが作るドラッグの写しは掴んだ1行
  だけなので、印が1行にしか付いていないと「1件しか運んでいない」と読める。
- **ボタンに「どこへ何件」と書く**（「テスト設備Aへ3件追加」）。「設備へ追加」
  だけでは、選んだ全部なのか今の行だけなのかが読めない。

固定は`tests/test_scpick.js`。

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **まとめて入れる／まとめて外すは対で持つ**（§9.170、`#scPickBar`）:
  仕掛一覧はチェックで複数選んでまとめて投入できる（§9.5・§9.10）。**戻す側にも
  同じ操作を置く**——入れるのは一度に何件でもできるのに外すのは1件ずつ、では
  釣り合わない（利用者の指示「逆もしかりで」）。**選ぶ道具は取っ手の列へ同居**
  させる（`--sc-handle-col`を持ち替える）——`.sc-row-head`と`.sc-row-line`は
  **同じグリッド定義を共有**しているのが土台なので、**列を1本足さないこと**
  （定義が2通りになり、片方だけ直した状態が作れる）。チェックを出すのは
  `removableEntry()`が通す行だけで、**全選択の分母も「外せる予定」**
  （出しておいて断るのでは選んだ手間が無駄。§9.116と同じ）。件数と対象は
  **必ず文字で**選択バーへ出し、**確認は1回だけ**まとめて出す（20件外すのに
  20回押させると読まずに押す癖が付く。1件のときは今までどおり`deleteEntry()`）。
  **まとめて掴んでいる間は並べ替えない**（`scState.dragIds`。動かせるのは掴んだ
  1行だけなので、通り過ぎた位置に1行だけ置き去りになる）。受け皿の文言も
  「選んだN件」へ言い直す。**消えた行のidを持ち続けないこと**——描くたびに
  今ある行へ絞る。仕掛一覧側は**運んでいる行を全部そう見せる**（ドラッグの写しは
  掴んだ1行だけなので、印が1行だと「1件しか運んでいない」と読める）。
  固定は`tests/test_scpick.js`。
