# §9.589 断面図の有効長の寸法線は線ぜんたいも席を取り、下の軸の字の段のすぐ下に置く（`test_bladeui`の落ちる原因・利用者の指示）

索引: [決定記録](README.md)｜前: [§9.588](9.588.md)｜関係: [§9.418](9.418.md)・[§9.420](9.420.md)・[§9.443](9.443.md)・[§9.482](9.482.md)

## 経緯（利用者の言葉）

> test_bladeuiの落ちる原因を調べて直してください

`test_bladeui.js`の「スペーサーとゴムリングの字が同じ高さに混ざらない」は、main（`0a23e0a`）でも単独で回しても
毎回落ちていた（スペーサー 81／ゴムリング 84）。§9.588 の作業では「原因は調べていない」と書いて残した。

## 1. 原因（2つ重なっていた）

失敗の字に「同じ高さに来た字そのもの」を出すようにして測った（寸法の字は最小の段・9.5px、材料 50mm×22条）。

| 見たもの | 値 |
| --- | --- |
| ゴムリングの字と同じ高さ（y=555）に来た「スペーサーの字」 | `有効長 1599.6`（`is-span`）だけ——**部材の字ではなかった** |
| 有効長の寸法線の線・立て線の上に乗っている字 | **18件**（下の軸のゴムリングの外の段の「10」すべて） |

1. **網の数え方の誤り**: `is-ring`でない字を全部「スペーサー」に数えていたので、有効長の寸法線の字まで入っていた。
2. **本物の欠陥（網が見ていなかった）**: 寸法線（§9.420）の席は`dimRoom()`が**字の箱だけ**取り（§9.443）、
   **線は取っていなかった**。高さも`h - 54`の決め打ちで、器の高さと下の軸の字の段の深さに関係なく置いていた。
   下の軸のゴムリングの字は輪の外へ2段（`hit + 13`・`hit + 13 + 字 + 4`）出るので、2段目がちょうど線の高さに来て、
   **線が18件の字を貫いていた**（画像で確かめた）。

## 2. 直したこと

- `dimRoom()`が**線ぜんたい**（両端の間・太さ±1.5px）と**両端の立て線**（±`SPAN_TICK`）も席として取る（`k:'span'`）。
  置けない理由の内訳（`why`）に`span`を足した。
- 線の高さは**下の軸の字の段のいちばん下＋字の半分＋立て線の半分＋2px**。器の下の帯（`dimBot`）を越えるときは帯の上で止める
  （そのときは線の席がふさがるので、字は別の段へ回るか、置かずに数える＝§9.443 の`off`）。
- 立て線の半分の長さは`SPAN_TICK`の1つ（描く`dimSpan()`と席を取る`dimRoom()`が同じ値を見る）。
- 網: 有効長の字（`is-span`）はスペーサーに数えない。新しく「**寸法の字は有効長の寸法線の線に乗らない**」を足した。

| 物差し | 直す前 | 直した後 |
| --- | --- | --- |
| 寸法線の線の上に乗る字（9.5px・50mm×22条） | 18件 | 0件 |
| 「スペーサーとゴムリングの字が同じ高さに混ざらない」 | 落ちる（有効長の字を数えていた） | 通る |

## 3. 撤回・見送ったこと

- 寸法線を上へ移す案は取らない（上は左上の帯（§9.437）が使っている）。
- 線を字の所で途切れさせる案も取らない（寸法線は1本でつながっていないと区間が読めない・§9.420）。
