# §9.420 `<s>` は取り消し線／同じ寸法は「×枚数」／有効長を寸法線で言う（利用者の指摘）

索引: [決定記録](README.md)

利用者の指摘・指示:

> スペーサーの表示は、数段で表示する場合、アルファベットに干渉しているので、
> もう少しスペーサーに寄せて。アルファベットにも干渉しないように注意して。
> 複数枚の場合、×枚数とかで、スペースを有効活用しながらわかりやすく表現して。
> また、有効長がどの区間か、視覚的にも表示を追加して。
> **キャプチャのこの取り消し線みたいな表示はなんでしょうか？**

> スペーサー等の計算式は今回の正しく計算した式にすべて統一できているか
> 確認してください。

## ① 取り消し線の正体は `<s>`

利用者が見つけた「取り消し線みたいな表示」は、**本物の取り消し線**だった。

この図の添え書きは `<s>`（薄い字）と `<i>`（値）で組み立てている。`<s>` は
**取り消し線の要素**なので、`.bs-o3 s{text-decoration:none}` で線を消していた。
§9.418 追補で器を1つ増やした（`.bs-len3`）とき、**その1行を一緒に増やして
いなかった**——新しい器の中だけ、地の取り消し線がそのまま出ていた。

**意味の無い要素を「見た目」で使うと、こうなる。** 薄い字が欲しいだけなら
`<s>` である必要は無い。既存の作法にそろえたので `<s>` のままにしたが、
**器を増やしたら打ち消しの1行も一緒に増やす**ことを規則に書いた。

## ② 同じ寸法が続くぶんは「×枚数」

`100` を4つ並べるより **`100×4`** の1つのほうが、場所も要らず「4枚要る」と
いう事実もそのまま読める。まとめるのは**隣り合って・同じ軸で・同じ寸法**の
ものだけ——離れた同寸法をまとめると、どこの話か分からなくなる。

字が減ったぶん、**引き出し線も減る**（利用者の指示「引き出し線だらけに
ならないためにも」）。

## ③ 字は記号（A・B…）から離す

区間の記号は**軸の中心**に置いてある（§9.417）。スペーサーの字の段を
軸の半径の 0.28／0.62 に置いていたため、内側の段が記号とぶつかっていた。
**軸の外寄り**（0.52／0.80）へ寄せ、記号の席と重ならないようにした。

## ④ 有効長は寸法線で言う

「有効長 1599.6」と字で出していても、**どこからどこまでか**は図の上で辿れ
ない。端の立て線2本と、そのあいだの線、真ん中に値——**寸法線**で言う。
足元の帯（表示の切替・視点）の上へ置く（重ねると線が札の裏へ隠れる）。

## ⑤ 計算は1箇所。直すのは**字のほう**が残る

利用者の確認依頼（「計算式はすべて統一できているか」）に対して調べた結果:

**刃の位置を計算しているのは `buildLayout()` の1箇所だけ**だった。区間長
（`A.zones`）・部材の割り付け（`planZones`）・模式図・断面図・拡大図・
刃組表は、すべてそこが返す `A` から引いている。`clr` を使っている他の場所は
**既定値の計算（`clearanceFor`）と画面へ出す字**だけで、位置の計算は無い。

**直し漏れていたのは「字」のほうだった**——計算を §9.419 で直したのに、
それを説明している文がまだ古い話をしていた:

| 場所 | 直すまえ |
| --- | --- |
| 設定の説明文 | 「軸方向に**クリアランスのぶんだけ**ずれます…中間の区間でクリアランス×2」 |
| `#bsDVal` | クリアランスの値（0.13）を出していた |
| 拡大図の札 | 中心間の距離に「クリアランス」と名付けていた |
| 拡大図の足元 | 「クリアランスは見える幅まで離して描いています」（もう誇張していない） |
| `knifePx()` の注 | 「クリアランスは 0.07px になり見えない」 |
| `blade-core.js` の冒頭 | 幾何モデルの説明が古いまま |

**計算を直したら、その計算を説明している字も直す。** 字は網にかからない
ので、**直し忘れても赤くならない**——だからこそ、1箇所ずつ数えて確かめる。
