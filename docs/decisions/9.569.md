# §9.569 影を役割の5つにそろえる——浮き（2段）・焦点と選択の二重の輪・縁・帯（利用者の指示・5案を比べて案 F）

索引: [決定記録](README.md)｜前: [§9.568](9.568.md)｜関係: [§9.562](9.562.md)・[§9.564](9.564.md)・[§9.449](9.449.md)・[§9.350](9.350.md)

## 経緯

§9.562（字の太さ）・§9.564（字の灰色）に続く統一感の3つ目（利用者の指示「画面の統一感の続きを進めてください」・
迷う所は5案を画面で比べて採点し、良い物を選ぶ）。

## 測った（前）

`box-shadow`は CSS 全体で:

| 物差し | 前 |
|---|---|
| 値の種類 | **133** |
| 色の字面（リテラル） | 175 |
| 形の種類（色を外して数える） | **70** |
| 影のトークン | `--shadow-pop` 1つ（使われていたのは一部） |

同じ役目の物が別々の値を持っていた——浮きの影（ぼかしを持つ外側の影）だけで**ずれ×ぼかしの組が 41通り**
（`0 4px 12px`・`0 20px 60px`・`0 12px 28px`…）、輪の太さは 1／1.5／2／3／3.5／4／5px と色の濃さがばらばら
（淡い色の輪は地との比が 3:1 に届かない物があった）、色の帯は 2／3／4px、全ボタンに 1px の影
（`button{box-shadow:0 1px 2px …}`）が付いていて、押せる物と読むだけの物の見分けを影が受け持っていなかった。

## 役割で分けた

影が言っていることは5つしか無かった:

1. **浮いている**（メニュー・ポップオーバー・窓）——段は2つ: 面（`--elev-pop`）と窓（`--elev-modal`）。
2. **焦点・選ばれている**（輪）。
3. **縁**（枠線の代わりに引いた内側の線）。
4. **帯**（左／上下の色の帯＝分類の印）。
5. **図の形**（ラジオの点・印の白縁・ランプの光）——これは影で描いた絵なので役割の外。そのまま残す。

## 5案（画面に当てて撮って比べた）

浮きメニュー・窓・焦点・設備マスタ・操業データ項目・作業スケジュールの6画面へ、案ごとの値を当てて撮った
（一時の調べ・コミットしていない）。

| 案 | 浮き（面／窓） | 輪 | 縁 | 帯 | 採点（25） |
|---|---|---|---|---|---|
| A | 淡い3段 | 3px 淡色 | 1px | 3px | 17 |
| B | 黒の2重の影（Material 風） | 2px 実色 | 2px | 4px | 18 |
| C | 面と窓の2段だけ（地の影なし） | 2px 実色 | 1px | 3px | 22 |
| D | 影を使わず枠だけ | — | — | — | 13（濃い左メニューで輪が見えない・最下位） |
| E | 淡い3段 | **二重の輪**（地2px＋色2px） | 1.5px | 3px | 22 |
| **F（C＋E の複合）** | **面と窓の2段** | **二重の輪** | **1.5px** | **3px** | **24** |

- 採点は5項目×5点: 輪の見え方（地との比 3:1 以上）・浮きの段の読みやすさ・種類の少なさ・墨の量（画面の影の濃さの合計）・
  濃い地（左メニュー）での見え方。
- 輪の見え方: A と D は 3:1 に届かない場面があった。濃い左メニューの上で見えたのは**二重の輪（E・F）だけ**
  （内側の地の色の輪が、どんな地の上でも外側の色の輪を切り離す）。
- 地の影（1px）は C・F で外した——押せる物は形と色が言っており、影はどの画面でも見分けに効いていなかった
  （墨の量は C・F が最少）。つまみ・スライダーの玉・乗せたとき（`:hover`）の持ち上げだけは `--elev-1` を残した
  （1px 持ち上げ・§9.396 の「押せることを動きで言う」と同じ役目）。

## 決めたこと（案 F）

トークンは `00-base.css` の1か所:

| トークン | 値 | 役目 |
|---|---|---|
| `--elev-1` | `0 1px 2px` 墨 .16 | つまみ・乗せたときの持ち上げ |
| `--elev-pop` | `0 4px 14px` 墨 .14 | メニュー・ポップオーバー（`--menu-shadow`もこれ） |
| `--elev-modal` | `0 18px 48px` 墨 .20 | 窓 |
| `--ring-gap`／`--ring-w` | 2px／4px | 二重の輪（`0 0 0 var(--ring-gap) var(--surface),0 0 0 var(--ring-w) 色`） |
| `--edge-w` | 1.5px | 内側の縁（`inset 0 0 0 var(--edge-w) 色`） |
| `--bar-w` | 3px | 色の帯（`inset var(--bar-w) 0 0 色`） |

- 焦点の輪の色は `--teal`、選ばれた札（`.is-pick`・`.selected`・`.active` など）は実色。
- 残した物: 図の形（点・印・ランプ・線・案内の揺れ）、`@keyframes`の中、内側の影（`inset 0 7px 9px -9px`＝
  スクロールの影）。どれも役割の外の絵。
- `--shadow-pop`は消した（`--elev-pop`へ）。中身が空になった規則（`button{}`など）も消した。

## 踏んだこと: トークンの定義を落とし、影が全部消えた

書き換えを一度戻してやり直したとき、手で足したトークンの定義（`--elev-*`・`--ring-*`・`--edge-w`・`--bar-w`）が
`00-base.css`から落ちた。**定義の無い`var(--x)`は宣言ごと無効**なので、影は全部消えた——それなのに CSS の網は
全部通った（字面しか見ていない）。気づいたのは画面の網（`test_theme`の「未選択は左の帯で合図する」）だけ。

- `test_csslint.py`に「CSS が使うトークンはどれも定義されている」を足した（代わりの値を持つ`var(--x,…)`は数えない・
  JS が`setProperty`で置く物は定義に数える）。
- 足した見張りが、**前から定義の無かった 5つ**を見つけた。どれも名前から意図が読めるので、在るトークンへ寄せた:
  `--fs-base`→`--fs`（見出し3つ）・`--ok-fg`／`--ok-bg`→`--success`／`--success-bg`（操業データ項目の盤の「保存しました」等）・
  `--ctl-h-md`→`--ctl-h`（作業スケジュールの1つ）・`--pad-cell`→`--pad-row`（測定の表の1つ）。
  いままでは値が効かず、親の字の大きさ・色を受け継いでいた（意図した見た目ではなかった）。

## 網
