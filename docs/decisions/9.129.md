# §9.129 測定画面の見栄え: 重ねない・そろえる・囲みすぎない

利用者からの指摘は3つ——**同じ情報が重複している／情報欄がそろっていない／
何重にも枠で囲われている**。どれも「言葉で気を付ける」では次に足す人へ
伝わらないので、**実測してから直し、数で固定した**。

#### 重ねない

| 何が | どこに出ていたか | どうしたか |
|---|---|---|
| 進捗「N/M 項目」 | ヘッダー・操作レール・段ナビの**3箇所** | 操作レールの進捗ブロックを廃止し、ヘッダーは**バー（割合）だけ**に。数字は段ナビの1箇所 |
| `IndexedDB使用 0.0MB / 上限目安 0.8GB` | ②の測定中ずっと | 半分を超えたときだけ「残り少ない」と言う |
| 「実績板厚・板幅が…比較できません」 | ①で必ず（§9.127で対応済み） | 測ってから出す |

操作レールの進捗は、③に完了前の確認表（§9.125）、②に丈位置くらべ
（§9.128）ができた時点で役目を終えていた。**`railHtml()`ごと消す**——
使われない組み立てを残すと、次に読む人が「どこかで使っているはず」と
探すことになる。

#### そろえる

`.field`のラベル列が`auto`だったため、**項目ごとに値の左端がずれていた**。
固定幅（6em）にして、左列・右列それぞれ1本の縦線にそろえた。コースの
3項目だけ3.2emで、そこだけ39px左に出ていたのも同じ幅へ寄せた（全幅の行
なので、ラベルを広げても値へ渡せる幅は他の項目の倍近くある）。

①の選択項目は6列×span2で1行3つだったため、4つある「使う機材」が
3＋1 に割れていた。**12列×span3**にして4つずつそろえた。

#### 囲みすぎない

枠が「まとまり」ではなく「装飾」になっていた箇所を落とした。

| どこ | 前 | 後 |
|---|---|---|
| 基本情報の値 | **入力欄そっくりの枠＋白地**（読み取り専用なのに押せそうに見える） | 枠なし。そろえた列と文字の強さで構造を出す |
| 作業時間の項目 | パネル枠 → 項目枠 → 入力欄枠の**3重** | 項目の枠を外す。**状態の色は残す**（要記録・記録済み・誤り） |
| ②の公差カード・数直線・丈位置くらべ | ブロック枠の中にそれぞれ枠 | 地色と細線1本で分ける |
| 受信の帯 | 1語のために2pxの枠と40pxの箱 | 左3pxのアクセント＋薄い地色 |
| 寸法表・ブロック見出しの状態 | セルごとに枠／バーの中に白い箱 | 内側の細線だけ／文字だけ |

**`.work-time-item`は30-measure.cssと50-master.cssの両方にあり、後者が
勝っていた。** 片方だけ直しても見た目は変わらない（実際に一度そうなった）。

#### 数で固定する

「まとまりの枠」＝四辺に線があり、**中身を囲っている**器（120×32px以上）。
kbdや凡例の小さな四角は数えない。

| 段 | 前 | 後（上限） |
|---|---|---|
| ①準備 | 9 | **4** |
| ②測定 | 21 | **4** |
| ③確認 | 11 | **6** |

**深さだけでは足りない。** 最初は「枠の入れ子は2段まで」だけを見ており、
公差カードに枠を戻す欠陥を注入しても**深さは2のままで素通りした**
（横に並ぶ枠が増えても深さは変わらない）。数を上限で固定して初めて
落ちるようになった。

固定は`tests/test_msteps.js`（90件）。3つの欠陥（枠を戻す／ラベル列を
autoへ戻す／ヘッダーへ数字を戻す）を注入し、それぞれ落ちることを確かめて
ある。**最初に書いた「N/M」の正規表現は予定日（08/14）を拾って誤検知した**
——網そのものも実測で直している。

## 守ること（`CLAUDE.md` から移した規則の本文）

CLAUDE.md には見出しの1行だけを残してある。ここが本文。

- **見栄えは「重ねない・そろえる・囲みすぎない」を数で固定する**（§9.129）:
  **同じ数字を画面に2つ出さない**（進捗はヘッダーのバー＝割合、数字は段ナビの
  1箇所。操作レールの進捗は`railHtml()`ごと廃止した）。**情報欄のラベル列は
  固定幅**——`auto`だと項目ごとに値の左端がずれる。**枠は「まとまり」だけに
  使う**——読み取り専用の値へ入力欄風の枠を付けない（押せそうに見える）、
  パネル枠の中に項目枠を作らない、ブロックの中で枠を重ねない。
  **枠の数は段ごとに上限で固定**（①4 / ②4 / ③6。前は9/21/11）。
  **深さだけを見る網では捕まらない**——横に並ぶ枠が増えても深さは変わらず、
  公差カードに枠を戻す注入が素通りした。**同じセレクタが2ファイルにある**
  ことに注意（`.work-time-item`は`50-master.css`が勝っていた。片方だけ直しても
  見た目は変わらない——§9.324 R6で死んだ側を消し、いまは1箇所）。固定は`tests/test_msteps.js`。
