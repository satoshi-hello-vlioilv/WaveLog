# §9.490 表示列の設定を開き直したら絞り込みは全部外す——列名の欄が漏れていた／絞っていることを字で言う（利用者の報告）

索引: [決定記録](README.md)

## 経緯

利用者の報告「作業スケジュールの表示列の計算式を追加するときに列の部分をフィルタをかけて、計算式を登録して
保存したら、再度編集しようとしたときに編集できる対象の列が一気に見えなくなって2つしか列の編集対象の表示が
なくなりました。実際の列の項目は変化ないように感じますが、編集できなくなったので困ります。」

画像では、絞り込み欄に「次工程」が入ったまま、札は「すべて 2」、足元は「21 / 299 列」だった——**列は減って
いない**。列の設定の窓は使い回しで、§9.248 ④ で「開くたびに外す」としたのは**出どころの札と状態の札の2つだけ**。
**列名の欄（`#lcFilter`）が漏れていた**。札の件数は絞った後の数なので、「すべて 2」が「列が2つしか無い」と読めた。

## 決めたこと

- 絞り込みを外すのは**`clearFilters()`の1箇所**（出どころ・状態・列名の3つ）。開くたびに通す。
  絞り込みの軸を足したらここへ足す。
- **列名で絞っている間は字で言う**（利用者の判断「推奨の通りで」）: 札の並びの右端に
  「『次工程』で絞り込み中（299列中2列）」と「× 外す」。誤りではないので警告の色は使わない（語の強調は主色）。
  「× 外す」は列名の欄を空にして焦点を欄へ戻す。
