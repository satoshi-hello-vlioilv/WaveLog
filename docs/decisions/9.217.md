# §9.217 帳票の塊を行のグリッドへ載せ、パレットからD&Dで出し入れする（利用者の指示）

  「帳票のブロックのレイアウトの自由度を上げるため、縦方向にはブロックが
   干渉回避のため行単位でのレイヤーが設けてありますが、下方向に余白がある
   場合は以降のレイヤーにも跨いで表示できるようにしたいです。そのために
   ブロックごとに既定の高さを設定してその既定の高さでブロック高さを計算して
   配置させる必要があります。…これら帳票の項目は、規格化してブロック(カード)
   サイズとイメージと共に一覧で管理し、帳票内に表示させるときに項目からD&Dで
   表示(ゴーストが出て配置可能な部分がわかりやすいように)、D&Dで非表示などで
   きるようにしてください。内部データについても各項目ごと設計できるように、
   編集追加などできるようにすることで設計の自由度を上げることができます。」

---

#### ① 高さを「行数」で持ち、下の段へ跨がせる

以前の`.rp-blocks`は列だけのグリッドで、行は**暗黙**だった。暗黙の行は
その行でいちばん背の高い塊に合わせて伸びるので、**1つ背の高い塊がいると
その段ぜんぶがその高さになり、隣に空白が残る**——これが利用者の言う
「行単位でのレイヤー」。

行の高さを`--rp-row`（24px）で固定し、塊が`grid-row: span R`で何行ぶんかを
占める形にした。`grid-auto-flow:row dense`と合わせると、背の低い塊が
**下の段へ跨いだ塊の横へ回り込む**。

**既定の行数は中身から測る**（`rpFitRows()`）。決め打ちにすると、ロットに
よって中身の量が変わる塊（測定表・丈別データ）が必ずどちらかで崩れる。
利用者が決めた行数（`行数:<塊>`）があればそちらが勝つ。

- **測る前に前回の割り当てを外すこと。** 付いたまま測ると、一度低くなった
  塊は二度と高くならない（§9.210 ④で条の図のラベルが踏んだのと同じ罠）。
- **外すのと測るのは別のまわしにする**——1つずつ外して測ると、その都度
  グリッド全体が組み直されて遅い（塊は20枚以上ある）。
- 旧いpxの高さ（§9.174の`高さ:<塊>`）は**行数へ読み替える**。読み替えないと、
  行の仕組みへ変えた瞬間に現場の設定が全部「中身なり」へ戻る。行数を触った
  時点で旧いpxは捨てる（両方残すとどちらが効いているのか決まらない）。
- 保存先は今までどおり**列レイアウトマスタの`widths`**で、幅と同じく
  `×RP_SPAN_UNIT`（§9.169。pxとして40〜900へ丸められるため。15行が上限）。

#### ② 出していない塊はパレットに置き、D&Dで出し入れする

**紙の外**に`#rpPalette`を置く（紙の中へ入れると刷り上がりに混ざる）。
出していない塊が名前と**規格の大きさ**（何マス×何行）つきで並ぶ。

- 掴んで紙へ落とすと出る。**落ちる場所は実物大の枠（ゴースト）で見せる**
  ——線1本では「どこへ何マスぶん入るのか」が読めない。ゴーストはグリッドの
  子として実際に挿し込むので、**置いたらどうなるか**がそのまま見える。
- 紙の塊をパレットへ落とすと外れる。
- **押すだけでも出せる**（§4）。掴めない環境・タッチでも行き止まりにしない。
- 塊と塊のあいだ・紙の余白へ落としたら末尾。落とせる場所を「塊の上だけ」に
  絞ると、掴んだまま行き場を探すことになる。
- 並びと「出す/出さない」は**1回の保存で決める**——別々に保存すると、
  途中で切れた場合に片方だけ効いた状態が残る。

---

#### ③ 塊そのものをマスタで足せる（帳票ブロックマスタ）

中身の作り方が仕事になっている塊（測定表・条の図・異常位置判定）は
コードの側のまま。**「ラベルと値の出どころを並べただけの塊」だけ**を
現場が足せるようにした。

`帳票ブロックマスタ`は1行＝1つの塊で、`[内容]`に`ラベル=出どころ`を並べる。
出どころは測定レコードの中の道（`basic.lotNo` / `settings.measureType` /
`settings.opData.運転方式` / `workTime.startAt`）で、**操業データの項目も
そのまま使える**（§9.216 ②で項目名が鍵になっているため）。

- **幅と行数は規格の中から選ぶ**（3/4/6/8/12マス、2/3/4/6/8/12行）。自由に
  入れさせると、増えるたびに紙の割り付けが崩れる（§9.135と同じ理由）。
- **同じ設備に同じ名前を2つ置かない**——塊の並び・幅・高さは名前を鍵に
  列レイアウトマスタへ入るので、2つあるとどちらの設定か決まらない（§9.113）。
- **壊れた行は1行だけ落とす**（§9.88の読み替えルールと同じ）。1行の書き
  間違いで塊ごと消えると、どこが悪いのか分からなくなる。
- 作った塊は**既定では紙に出さない**。組み換えの「出していない塊」から
  紙へ落として初めて出る（勝手に紙が増えない）。
- 描く側は自作かどうかを区別しない——`RP_BLOCKS`と同じ形へ包んでから混ぜる。

固定は`tests/test_rplayout.js`（行のグリッド・跨ぎ・パレット・ゴースト・
自作ブロック）と`tests/test_rpblocks.js`（今までの見せ方が変わっていないこと）。
