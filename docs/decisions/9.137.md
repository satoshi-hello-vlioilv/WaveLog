# §9.137 測定画面の骨子（確定・横4×縦3の割り付け）

利用者とワイヤーフレームで合意した割り付け。**面積を先に決め、中身は後から
入れる**。実装で迷ったらこの表に戻る。

| 段 | カード | 形 | 中身 |
|---|---|---|---|
| ① | 基本情報 | `1×2` | 識別・製品・材・**分割ロット**・**公差の値**（下限/基準/上限） |
| ① | 準備の入力 | `1×2` | 誰が測るか／測定表の形／使う機材／いつもと同じ設定／**作業時間**（カテゴリは縦に積む） |
| ① | 品質情報＋品質規格 | `2×2` | 品質情報の本文（②から移設）＋品質規格の縦4×横3の表 |
| ① | 条の設計 | `4×1` | 幅の割り付けの帯（**分割の有無によらず常時**） |
| ② | 基本情報 | `1×2` | ①と同じ位置・同じ中身 |
| ② | 入力内容 | `1×2` | **板厚と板幅は別項目**（板幅=40条×丈位置、板厚=丈ごとに中央/エッジOS/エッジDSの3点） |
| ② | 条の設計 | `2×1` | ①と同じ部品。**位置は変えない** |
| ② | 測定 | `2×3` | 左＝公差と測定値の**縦**グラフ（選択中の丈位置のみ）、右＝丈位置×条の表 |
| ③ | 完了前の確認 | `4×1` | 測定／公差外／作業時間／対象外の4枚（**同じ大きさ**） |
| ③ | 記録の壁 | `1×2`×4 | 基本情報／記録した値／作業時間／測定データ分析 |

#### ②の表の約束

- **横＝丈位置、縦＝条**。列見出しが丈位置の選択を兼ねる（選択リストは廃止）。
- **条は1列で40行まで。2段に折らない。** 丈は最大10列なので横は足りる。
  行の高さ21px・文字11pxで縦を使い切る——**文字を小さくして詰めない**。
- 列を切り替えても**表は動かない**（アクティブが移るだけ）。
- 公差の**図**は測定カードの左（いまどうか）、公差の**値**は基本情報カード
  （規格はいくつか）。**別の問いなので別の場所に置く**。
- セル背景で公差内の位置を示す案は**却下**（ノイズが増える）。公差外の赤だけ。
