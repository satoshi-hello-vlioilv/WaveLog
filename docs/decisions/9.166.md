# §9.166 効いている公差と進捗の数値（利用者の指摘）

利用者の指摘は2つ。「入力内容の進捗状況表示の数値は少し小さい」「確認して完了の
画面の測定データ分析の欄は、特に効いている公差の部分が余裕がなくきつい」。

**進捗の数値**（`.type-chip-state`）は項目名より1段小さかった。チップの中で
いちばん**読みに来ている**値なので、`font-size:inherit`で名前と同じにする
（狭い画面で器ごと小さくする規則にも追随する）。

**効いている公差**は6列の表（項目・出どころ・基準・公差＋・公差−・判定範囲）を
実測430pxのカードへ詰めており、`3.000 +0.130 -0.130 2.870 ～ 3.130`が隙間なく並んで
どこまでが1つの数字か読めなかった。**縦は余っていた**（表の下に空白）ので、
**1項目1枚**にして読む順に2行へ分ける。

1. 項目名 と **判定範囲**（確認の面でいちばん読みに来る値）
2. その根拠（基準・公差・出どころ）を小さく淡く

共通の文字は見出しごと落とす——表全体が「効いている公差」なので、列見出しの
「公差＋／公差−」も繰り返さない。**左右対称の公差は`±`1つにまとめる**（実データは
対称が多く、2欄に分けると同じ数字を2度読ませたうえで桁がそろわない）。
**出どころが差し替わったこと**（指定の公差がデータに無くて製造公差へ落ちた）は
根拠の行に書く——黙っていると、別の公差で判定していることに気づけない。

固定は`tests/test_msteps.js`。
