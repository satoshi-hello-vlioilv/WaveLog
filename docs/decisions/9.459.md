# §9.459 フローティングシートを図面から3Dで描く——端の青い印の代わり（利用者の指示）

索引: [決定記録](README.md)

利用者の指示:

> 刃組ガイダンスの上下軸のDSエンドを青のオブジェクトではなくフローティングシートを図面から
> 3Dで再現し、青のオブジェクトから変更してください。

（§9.461 で基準面を切り替えられるようにしたので、シートの載る端は「基準面の反対」になった。
既定は DS 基準なので **OS 端**。）

## 図面から読んだ寸法（§9.457 で受け取った図面・写真）

| 部位 | 寸法 |
| --- | --- |
| 本体 | 外径 Φ269・内径 Φ200・幅 70（(2)＋5＋63） |
| フローティングピストン | 等分18-Φ15（シリンダ Φ20）・P.C.D230・1本目は真上から10° |
| 加圧装置 | 2か所（中心から左右へ113.5・外周の下寄り）・加圧スクリュウ M22×P1.5 |

**分からないこと**:
- 寸法 (2)・5・63 の並び順（どちらが押さえ板か）は図面から読み切れなかった。
  板を押す面（有効長の側）＝押さえ板5、次にピストンの逃げ2、本体63 の順で組んだ。
- 2枚目の図面（14-Φ23 深さ23・P.C.D235）は寸法がこの輪に収まるが、**どの部品の穴かは
  分からない**ので入れていない。
- OS端にシートが載るときの機械まわりの寸法（ギヤボックスとの間隔）は図面に無い
  （図面 SL-1458-01S の OS 側の間隔30はシートの無い形）。軸受・ギヤボックスを
  シートの幅ぶん外へ逃がした**概寸**。

## どう直したか

- `blade-3d.js` の `floatSeat()`。**軸の上の部品**なので断面図にも出す（`g`へ置き、
  切り口の面も置く）。押さえ板の面は `fit.floatSeat`（押さえている量）だけ有効長の内側へ
  出る——ピストンがそのぶん伸びている。
- 断面図で本体の穴が**空洞に見えた**ので、シートの幅ぶん軸も通す（内径Φ200＝軸径）。
- 色は `--bs-fig-fseat`（深い青緑）。**灰の系統を使わない**——軸・スペーサー・端数・刃が
  すでに灰の4段を使っており、最初に当てた濃い灰（`--rs-slate`）は断面図で軸と見分け
  られなかった。青は印の色なので避けた。立体図は機械の見た目のまま（鋼の灰）。
- 立体図では、シートの側の軸受がシートを隠していた（有効長の端から10mm内側まで被って
  いた）ので、軸受をシートの外へ置いた。
- シートは有効長の外に載る部品なので、「有効長と青い印より外に物が残っていない」の
  見張り（`strayCount`）からは外し、幅は図面の70で別に見る。

## 網（`test_bladeui.js`）

- 断面図の青い印は基準面の端だけ（2個）／シートは上下軸に1つずつ・Φ269・幅70・ピストン36本／
  シートは基準面の反対の端／押さえ板の面は押さえている量だけ内側（押さえ代0.95以内）
