# §9.511 LotDsp のタブは番号と中身の名前で言う（利用者の指示）

索引: [決定記録](README.md)

## 利用者の言葉

「ロット問い合わせの時に初期表示で開くタブの表示を、画像の『ICAS情報』『進度情報』『製造情報』...の補足情報を
Tab0，Tab1の後ろに補助情報『Tab0：ICAS情報』みたいな感じで補助として付け加えてわかりやすくしてください。」

## 測った（評価関数）

使用設備の設定の②「ロット№を押したときに開くタブ」（`#lotDspTabSetting`）。

| 物差し | 前 | 後 |
| --- | --- | --- |
| 中身の名前を持つ選択肢 | **0/8**（「Tab 0」〜「Tab 7」——どの画面が開くか思い出させる） | 8/8 |
| いちばん長い字が要る幅 / 欄の幅 | 68 / 210px | 168 / 210px（切れない） |
| URLへ渡す値 | 0〜7 | 0〜7（変えない） |

## 決めたこと
- 顔ぶれ（番号と名前）は`WL.lotDspTab.TABS`の1箇所。字は`label(n)`、選択肢は`optionsHtml()`から作る
  （欄を組み立てる`records-store.js`は呼ぶだけ）。名前は LotDsp の画面に並んでいる見出しそのまま:
  0 ICAS情報・1 進度情報・2 製造情報・3 試験情報・4 品質情報・5 クラッド情報・6 焼鈍情報・7 引当情報。
- 区切りは全角の「：」（利用者の書いた形）。

## 固定する網
- `test_eqsetup.js` … 値は番号のまま／字は「Tab N：名前」／いちばん長い名前も欄に収まる
